# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through GitHub:
[report a vulnerability](https://github.com/KingDasWinx/Templum/security/advisories/new).

We aim to acknowledge reports within a week. Once a fix ships, the advisory is published with credit to you,
unless you prefer to stay anonymous.
