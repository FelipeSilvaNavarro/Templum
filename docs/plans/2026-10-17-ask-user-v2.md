# `ask_user` v2: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `ask_user` takes AskUserQuestion's shape (several questions, header, options with description and preview,
multiSelect, Other, a note) and answers JSON, keeps today's calls working, waits without a deadline unless the person
or the agent sets one, survives a client that stops waiting, and tells the person with a sound, a notification and an
alert.

**Architecture:** Everything the question is, parsed, answered and picked lives headless in `templum-mcp/src/ask.rs`
(`Ask`, `Form`), unit-tested. The app keeps a question's GPUI fields and handlers in `workspace/questions.rs`, its
wait's life (deadline, cancel) in `waits.rs`, and draws it in `balloon.rs`. The sound is the platform's own player
spawned by `chime.rs`. The clients' timeouts (Codex, Gemini CLI, Claude Code) go to seven days where Templum sets
them.

**Tech Stack:** Rust 2024; `serde_json`; GPUI (gpui-fast 0.1.8) through gpui-kit `=0.7.3`: `div`, `InputState`
(`InputEvent::{Change, PressEnter}`), `Notification` (`id1`, `autohide`), `BackgroundExecutor::now()` (the fake clock
in tests); `std::process::Command`.

**Spec:** [docs/specs/ask-user.md](../specs/ask-user.md) (read it first: copy, layout and rules are there and not
repeated here), building on [connections.md](../specs/connections.md#requests-from-agents).

## Global Constraints

- Only `crates/templum` depends on gpui-kit; `ask.rs` has no UI type and is tested headlessly.
- No new dependency (`cargo deny check` unchanged). No `unsafe`.
- Zoom scales like a photo: every size in the dialog is a world size × `z`, fields and the preview's font included.
  Question and label text 14, descriptions, header chip and preview 12 world units.
- Today's shape (`question`, `options` as strings, `timeout`; `templum ask`) keeps today's dialog (buttons, or a field
  and Send; no Other row, no note) plus Dismiss, and answers plain text.
- `HEADER_MAX = 12` characters (longer: cut, then "…"); the preview column 45% / 55%, at most 18 lines tall.
- `TOO_SOON = 500 ms` after the dialog first shows a request; `chime::GAP = 2 s`.
- The clients' timeouts: seven days, `604800` s for Codex, `604800000` ms for Claude Code and Gemini CLI.
- `[connections] question_timeout`: minutes, 0–1440, default 0 (no deadline); `[connections] sound`: default true.
- The deadline is the shorter of the call's `timeout` (seconds, 1–3600 as today) and the setting when not 0; neither:
  none. `connect` keeps `ASK_WAIT` (1800 s).
- Exact copy (spec): "Give question or questions, not both.", "The person dismissed the question without answering.",
  "The agent stopped waiting: your answer will be typed into its terminal.", "Asks you: …" with "(and N more)",
  "Pick any", "Other", "Note (optional)", "No preview", "Dismiss", "Send".
- Balloon element ids (`balloon::part(n, what)`): `q{q}-option-{i}`, `q{q}-other`, `q{q}-preview`, `note`, `send`,
  `dismiss`, `stopped`, plus today's `waiting`, `count`, `allow`, `deny`.
- Each commit passes `cargo fmt --all && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`,
  on `development`, titled as CLAUDE.md says. A task that changes a spec's behavior updates its lines in the same commit.

## Review Focus

1. **Text from the agent in a preview** (tabs, `\r`, ANSI escapes, other control characters, 2000 lines): drawn as
   clean text, tabs as 4 spaces, the pane scrolls. Task 5 pins it.
2. **Two calls from one block at once** ("1 of 2"): each keeps its own picks, Other text and note; answering the first
   doesn't fill the second. Task 4 pins it.
3. **Other with only spaces**: not an answer (Send stays off); with spaces around: trimmed. Task 2 pins it.
4. **The setting changed while a question waits**: that question keeps the deadline it got. Task 4 pins it.
5. **A cancelled question whose agent then quits or whose block closes**: withdrawn, nothing typed anywhere. Task 7
   pins it.
