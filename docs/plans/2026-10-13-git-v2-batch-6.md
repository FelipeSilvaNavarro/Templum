# Git block v2, batch 6: commit messages from an agent — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate ✨ beside a Git block's summary asks an AI agent (Claude Code, Codex, or any agent given a
generate command) for the commit message; Settings ▸ Git chooses the agent, its model, its limits, the user's rules
and the request, with Try it; the agents dialog gets a Commit messages part.

**Architecture:** `templum-git` gains `message.rs` (UI-free): the request built from a template filled in one pass,
what a commit would take read from the repository, the agent's command run through the user's login shell with a
timeout and a cancel (reusing `repo.rs`'s `until_cancelled`, which gains a deadline), and the answer split into a
summary and a description. `templum` wires it: `config.rs` reads `[git.commit_message]`,
`[git.repositories."<root>"]` and `[agents]`'s `generate` and `models`, and `config::Edit` writes nested tables;
`agents.rs` gives Claude Code and Codex their presets (Codex's models from its own cache) and resolves the agent
Generate runs (`CommitAgent`, kept in the workspace with whether its program is installed);
`workspace/git_message.rs` runs Generate in the background beside the block's command queue, asks once before
sending anything, and never replaces a message changed meanwhile. The commit form gets ✨ and ⚙, the settings
panel a Git section, the agents dialog its part.

**Tech Stack:** Rust 2024, GPUI through gpui-kit `=0.7.1`, `toml_edit` 0.25 (already a dependency), `serde_json`
(already a dependency of `templum`), the user's own agent CLIs run through their login shell.

**Spec:** `docs/specs/git.md` — section 7 (all of it), Configuration (`[agents]`'s `generate` and `models`,
`[git.commit_message]`, `[git.repositories]` and the rules under the block), Architecture (`message.rs`;
`config.rs`, `settings/`), Error handling (a generate command that fails, times out, or answers nothing), Testing
(`message.rs`; Generate with a fake agent command, its timeout and failure, the first-use confirmation written
once; the settings' Try it), Delivery, batch 6. Batches 1 and 2 are `docs/plans/2026-10-13-git-v2-batch-1.md` and
`-batch-2.md` (shipped on `development`).

## Review Focus

1. **The person types in the summary or the description, or commits, while the agent writes:** what they typed
   stays; the agent's answer is left out and a notification says so ("Kept your message: it changed while … was
   writing one"). The spec's success criterion 2 (no action loses work silently) applied to Generate. Pinned in
   Task 6 (`a_second_click_cancels_and_a_message_changed_meanwhile_is_kept`).
2. **A diff whose text looks like a placeholder** (`{files}` in a template file, `format!("{name}")` in Rust): it
   reaches the agent as written, never filled in. Pinned in Task 2 (`placeholders_are_filled_in_one_pass`) and
   Task 8 (`settings_git_chooses_the_agent_and_tries_it`, the sample's `{name}`).
3. **An agent that hangs, or a second click on the spinning ✨:** the command is stopped at the timeout or at once,
   the button stops spinning, a cancel says nothing, and nothing is committed. Pinned in Task 3
   (`a_command_that_hangs_is_stopped_at_the_timeout_or_on_cancel`) and Task 6
   (`an_agent_past_its_timeout_is_stopped`, `a_second_click_cancels_and_a_message_changed_meanwhile_is_kept`).
4. **A repository whose root has dots, spaces or a drive letter** (`C:/Users/u/my proj`, `/home/u/my.proj`): its
   `[git.repositories."…"]` table is one quoted key, read back as written, and removed alone. Pinned in Task 1
   (`a_repositorys_table_is_one_quoted_key`).
5. **Nothing staged, changes and new files in the tree** (the button says Commit all changes): the request has
   every change, the new files' text included, as `git add --all` will commit them; with something staged, only
   what is staged. Pinned in Task 3 (`the_changes_are_the_staged_ones_or_every_one`).

/// `[git.commit_message]`: how Generate ✨ asks an agent for a commit message.
#[derive(Clone, Debug, Deserialize, PartialEq)]
#[serde(default, deny_unknown_fields)]
pub(crate) struct CommitMessage {
    /// An agent's id; None: the first agent with a generate command.
    pub agent: Option<String>,
    /// None: the agent's recommended model, the first of its list.
    pub model: Option<String>,
    /// Seconds the agent has to answer.
    pub timeout: u64,
    /// The diff sent is cut past this many KB.
    pub max_diff_kb: u64,
    /// The user's commit rules, sent with each request.

    /// The first-use question was answered: the diff may be sent.
    pub confirmed: bool,
    /// The request's template; None: `templum_git::message::PROMPT`.
    pub prompt: Option<String>,
}

impl Default for CommitMessage {
    fn default() -> Self {
        Self {
            agent: None,
            model: None,
            timeout: 60,
            max_diff_kb: 60,
            instructions: String::new(),
            confirmed: false,
            prompt: None,

/// One change to config.toml: `table.key` set to a value, or removed (back to its default).
#[derive(Clone, Debug)]
pub(crate) struct Edit {
    /// A TOML key: `font`, or a table inside another, `git.commit_message`,
    /// `git.repositories."/home/u/proj"` (see `repository_table`).
    pub table: Cow<'static, str>,
    /// Fixed for a setting; an agent's id under `[agents]`.
    pub key: Cow<'static, str>,
    pub value: Option<toml_edit::Value>,
}

impl Edit {
    pub fn set(
        table: impl Into<Cow<'static, str>>,
        key: impl Into<Cow<'static, str>>,
        value: impl Into<toml_edit::Value>,
    ) -> Self {
        Self {
            table: table.into(),
            key: key.into(),
            value: Some(value.into()),
        }
    }

    pub fn remove(
        table: impl Into<Cow<'static, str>>,
        key: impl Into<Cow<'static, str>>,
    ) -> Self {
        Self {
            table: table.into(),
            key: key.into(),
            value: None,
        }
    }
}

/// The table `path` names (a TOML key, see `Edit::table`), made when missing with `make` (a
/// parent made on the way is implicit: `[git.commit_message]` gets no empty `[git]` line before
/// it), else None.
fn table_at<'d>(
    doc: &'d mut DocumentMut,
    path: &str,
    make: bool,
) -> Result<Option<&'d mut dyn toml_edit::TableLike>, SaveError> {

            .get_mut(name)
            .and_then(|item| item.as_table_like_mut())
            .ok_or_else(not_a_table)?;
    }

}

/// What a request holds besides its template.
pub struct Request<'a> {
    /// The user's commit rules.
    pub instructions: &'a str,
    /// Every changed file, one per line ("M src/x.rs"), whole even when the diff is cut.
    pub files: &'a [String],
    pub diff: &'a str,
    /// The last commits' summaries, newest first.
    pub recent: &'a [String],
    /// The diff past this many bytes is cut, at a line's end.
    pub max_bytes: usize,
}

/// `template` with its placeholders filled: `{instructions}`, `{files}`, `{diff}`,
/// `{recent_commits}`, and `{truncated}`, a sentence when the diff was cut (else nothing).
pub fn request(template: &str, r: &Request) -> String {
    let (diff, was_cut) = cut(r.diff, r.max_bytes);
    let truncated = if was_cut {
        "The diff was cut: the list of files above is complete."
    } else {
        ""
    };
    fill(
        template,
        &[
            ("instructions", r.instructions),
            ("files", &r.files.join("\n")),
            ("recent_commits", &r.recent.join("\n")),
            ("truncated", truncated),
            ("diff", diff),
        ],
    )
}

/// `template` with each `{name}` of `values` replaced, in one pass: a value's own text is never
/// read for placeholders (a diff can hold "{files}"). Other braces stay as they are.
pub fn fill(template: &str, values: &[(&str, &str)]) -> String {
    let mut out = String::with_capacity(template.len());
    let mut rest = template;
    while let Some(i) = rest.find('{') {
        out.push_str(&rest[..i]);
        let after = &rest[i + 1..];
        let found = values
            .iter()
            .find(|(name, _)| after.strip_prefix(name).is_some_and(|r| r.starts_with('}')));
        match found {
            Some((name, value)) => {
                out.push_str(value);
                rest = &after[name.len() + 1..];
            }
            None => {
                out.push('{');
                rest = after;
            }
        }
    }
    out.push_str(rest);
    out
}

/// `diff` up to `max` bytes, cut after the last whole line that fits (never inside a
/// character), and whether it was cut.
fn cut(diff: &str, max: usize) -> (&str, bool) {
    if diff.len() <= max {
        return (diff, false);
    }
    let end = diff.as_bytes()[..max]
        .iter()
        .rposition(|b| *b == b'\n')
        .map_or(0, |i| i + 1);
    (&diff[..end], true)
}

/// An agent's answer as a summary (its first line) and a description (the rest), without the
/// code fences an agent may add anyway. None when it has no summary.
pub fn split(answer: &str) -> Option<(String, String)> {
    let text = answer
        .lines()
        .filter(|l| !l.trim_start().starts_with("```"))
        .collect::<Vec<_>>()
        .join("\n");
    let text = text.trim();
    let (summary, description) = text.split_once('\n').unwrap_or((text, ""));
    let summary = summary.trim();
    (!summary.is_empty()).then(|| (summary.to_string(), description.trim().to_string()))
}

/// Why an agent gave no message.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Failure {
    /// Reading the repository failed.
    Git(GitError),
    /// The shell couldn't start, or the request couldn't be written.
    CouldntRun(String),
    /// The command ended with an error: its exit code (None: stopped by a signal) and stderr.
    Failed { code: Option<i32>, stderr: String },
    /// It ran past the timeout, and was stopped.
    TimedOut(Duration),
    /// It ended well, with no answer.
    Empty { stderr: String },
    /// The person stopped it.
    Cancelled,
}

impl fmt::Display for Failure {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Failure::Git(e) => write!(f, "{}", e.first_line()),
            Failure::CouldntRun(why) => write!(f, "Couldn't run the agent's command: {why}"),
            Failure::Failed {
                code: Some(code), ..
            } => write!(f, "The agent's command failed (exit code {code})"),
            Failure::Failed { code: None, .. } => {
                write!(f, "The agent's command was stopped by a signal")
            }
            Failure::TimedOut(t) => {
                write!(f, "The agent didn't answer within {} s", t.as_secs())
            }
            Failure::Empty { .. } => write!(f, "The agent answered nothing"),
            Failure::Cancelled => write!(f, "Cancelled"),
        }
    }
}

impl Failure {
    /// What Details shows: the sentence, then what the command wrote to stderr (git's command
    /// and stderr for a git error).
    pub fn details(&self) -> String {
        let more = match self {
            Failure::Git(e) => format!("{}\n{}", e.command, e.stderr),
            Failure::Failed { stderr, .. } | Failure::Empty { stderr } => stderr.clone(),
            _ => String::new(),
        };
        if more.trim().is_empty() {
            self.to_string()
        } else {
            format!("{self}\n\n{}", more.trim_end())
        }
    }
}

/// Runs `command`, a generate command, through the user's login shell in `folder`: `{model}`
/// is `model`; `request` is its standard input, or the file `{prompt_file}` names; the answer is
/// its standard output, or what it wrote to the file `{output_file}` names. Stopped past
/// `timeout`, or as soon as `cancel` is set.
pub fn run(
    command: &str,
    model: &str,
    request: &str,
    folder: &Path,
    timeout: Duration,
    cancel: &AtomicBool,
) -> Result<String, Failure> {
    if cancel.load(Ordering::Relaxed) {
        return Err(Failure::Cancelled);
    }
    static NEXT: AtomicU64 = AtomicU64::new(0);
    let n = NEXT.fetch_add(1, Ordering::Relaxed);
    let file = |what: &str| {
        std::env::temp_dir().join(format!("templum-{}-{n}-{what}.txt", std::process::id()))
    };
    let (prompt_file, output_file) = (file("request"), file("answer"));
    let result = (|| {
        std::fs::write(&prompt_file, request)
            .map_err(|e| Failure::CouldntRun(format!("couldn't write the request: {e}")))?;
        let line = fill(
            command,
            &[
                ("model", &quote(model)),
                ("prompt_file", &quote(&prompt_file.to_string_lossy())),
                ("output_file", &quote(&output_file.to_string_lossy())),
            ],
        );
        let stdin = if command.contains("{prompt_file}") {
            Stdio::null()
        } else {
            Stdio::from(
                File::open(&prompt_file)
                    .map_err(|e| Failure::CouldntRun(format!("couldn't read the request: {e}")))?,
            )
        };
        let (shell, args) = login_shell();
        let mut c = Command::new(&shell);
        c.args(args)
            .arg(&line)
            .current_dir(folder)
            .stdin(stdin)
            .stdout(Stdio::piped())
            .stderr(Stdio::piped());
        // No console window flashing behind the app.
        #[cfg(windows)]
        {
            use std::os::windows::process::CommandExt as _;
            c.creation_flags(0x0800_0000); // CREATE_NO_WINDOW
        }
        let out = match until_cancelled(&mut c, cancel, Some(Instant::now() + timeout)) {
            Err(e) => return Err(Failure::CouldntRun(format!("{shell}: {e}"))),
            Ok(None) if cancel.load(Ordering::Relaxed) => return Err(Failure::Cancelled),
            Ok(None) => return Err(Failure::TimedOut(timeout)),
            Ok(Some(out)) => out,
        };
        let stderr = String::from_utf8_lossy(&out.stderr).into_owned();
        if !out.status.success() {
            return Err(Failure::Failed {
                code: out.status.code(),
                stderr,
            });
        }
        let answer = if command.contains("{output_file}") {
            decode(std::fs::read(&output_file).unwrap_or_default())
        } else {
            decode(out.stdout)
        };
        if answer.trim().is_empty() {
            Err(Failure::Empty { stderr })
        } else {
            Ok(answer)
        }
    })();
    let _ = std::fs::remove_file(&prompt_file);
    let _ = std::fs::remove_file(&output_file);
    result
}

/// The user's login shell and how it takes a command line, as a terminal would run it (PATH,
/// aliases, version managers): `$SHELL -l -c`, `/bin/sh` without `$SHELL` (an app opened from
/// a desktop menu may have none); PowerShell on Windows.
// ponytail: on Windows a native program's standard input through `-Command` and its real exit
// code (PowerShell reports 1) are unchecked; append `; exit $LASTEXITCODE` and test on Windows
// if a Windows user's agent needs them.
fn login_shell() -> (String, &'static [&'static str]) {
    if cfg!(windows) {
        (
            "powershell".to_string(),
            &["-NoLogo", "-NonInteractive", "-Command"],
        )
    } else {
        let shell = std::env::var("SHELL")
            .ok()
            .filter(|s| !s.trim().is_empty());
        (
            shell.unwrap_or_else(|| "/bin/sh".to_string()),
            &["-l", "-c"],
        )
    }
}

/// `s` as one word for `login_shell`'s shell: single quotes, each quote inside escaped its way
/// (sh, bash, zsh and fish take `'\''`; PowerShell `''`).
fn quote(s: &str) -> String {
    if cfg!(windows) {
        format!("'{}'", s.replace('\'', "''"))
    } else {
        format!("'{}'", s.replace('\'', r"'\''"))
    }
}

/// An answer's text: UTF-8 (a byte-order mark dropped), or UTF-16 with its byte-order mark, what
/// Windows PowerShell's `>` writes.
fn decode(bytes: Vec<u8>) -> String {
    match bytes.as_slice() {
        [0xFF, 0xFE, rest @ ..] => String::from_utf16_lossy(
            &rest
                .chunks_exact(2)
                .map(|p| u16::from_le_bytes([p[0], p[1]]))
                .collect::<Vec<_>>(),
        ),
        [0xEF, 0xBB, 0xBF, rest @ ..] => String::from_utf8_lossy(rest).into_owned(),
        _ => String::from_utf8_lossy(&bytes).into_owned(),
    }
}

/// What a request is about.
#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct Changes {
    /// Every changed file, "M src/x.rs" ("R old -> new" for a rename), whole even when the diff
    /// is cut.
    pub files: Vec<String>,
    pub diff: String,
    /// The last 10 commits' summaries, newest first; none before the first commit.
    pub recent: Vec<String>,
}

/// What the next commit would take: the staged changes; with `all`, every change as Commit all
/// changes takes them (`git add --all`), the tracked files against HEAD, then each new file's
/// text. A new file is listed but not read once the diff is past `max_bytes` (the request cuts
/// it there anyway), or when it is past `DIFF_LIMIT` itself.
pub fn changes(repo: &Repo, all: bool, max_bytes: usize) -> Result<Changes, GitError> {
    // Before the first commit there is no HEAD to compare with: what is staged is all there is.
    let against = if all && repo.head().is_ok() {
        "HEAD"
    } else {
        "--cached"
    };
    // As the diff panel reads it: names as themselves, the usual prefixes, no external diff.
    let diff = repo.run(&[
        "-c",
        "core.quotePath=false",
        "diff",
        "--no-color",
        "--no-ext-diff",
        "--src-prefix=a/",
        "--dst-prefix=b/",
        "-M",
        against,
    ])?;
    let mut diff = String::from_utf8_lossy(&diff).into_owned();
    let names = repo.run(&["diff", "--name-status", "-z", "-M", against])?;
    let mut files: Vec<String> = parse_name_status(&names)
        .iter()
        .map(|f| match &f.from {
            Some(from) => format!("{} {from} -> {}", f.change.letter(), f.path),
            None => format!("{} {}", f.change.letter(), f.path),
        })
        .collect();
    if all {
        let status = repo.status()?;
        for entry in status
            .entries
            .iter()
            .filter(|e| e.unstaged == Some(Change::Untracked))
        {
            files.push(format!("A {}", entry.path));
            let path = repo.root.join(&entry.path);
            let size = std::fs::metadata(&path).map_or(0, |m| m.len());
            if diff.len() > max_bytes || size > DIFF_LIMIT as u64 {
                continue;
            }
            let bytes = std::fs::read(&path).unwrap_or_default();
            diff.push_str(&if bytes.iter().take(8 * 1024).any(|b| *b == 0) {
                new_binary_diff(&entry.path)
            } else {
                new_file_diff(&entry.path, &String::from_utf8_lossy(&bytes))
            });
        }
    }
    let recent = repo
        .run(&["log", "-n10", "--format=%s"])
        .map(|out| {
            String::from_utf8_lossy(&out)
                .lines()
                .map(str::to_string)
                .collect()
        })
        .unwrap_or_default();
    Ok(Changes {
        files,
        diff,
        recent,
    })
}

pub(crate) struct CommitAgent {
    pub id: String,
    pub title: String,
    /// Its generate command.
    pub command: String,
    /// Its models, the recommended one first.

    pub ready: bool,
}

impl CommitAgent {

/// The agent `settings` chose among `agents` (none chosen: the first with a generate command),
/// with its model. None when that agent has no generate command or is gone: Generate never
/// sends a diff to another agent than the one chosen. `installed`: whether a program can run
/// (`templum_terminal::installed`).
pub(crate) fn commit_agent(
    agents: &[AgentEntry],
    settings: &CommitMessage,
    installed: impl Fn(&str) -> bool,
) -> Option<CommitAgent> {
    let agent = match settings.agent.as_deref() {
        Some(id) => agents.iter().find(|a| a.id == id)?,
        None => agents.iter().find(|a| a.generate.is_some())?,
    };
    let command = agent.generate.clone()?;
    let model = settings
        .model
        .clone()
        .filter(|m| !m.trim().is_empty())
        .or_else(|| agent.models.first().cloned())
        .unwrap_or_default();
    let mut chosen = CommitAgent {
        id: agent.id.clone(),
        title: agent.title.clone(),
        command,
        models: agent.models.clone(),
        model,
        ready: false,
    };
    chosen.ready = installed(chosen.program())
        && !(chosen.model.is_empty() && chosen.command.contains("{model}"));
    Some(chosen)
}

/// The table Generate's settings live in.
const TABLE: &str = "git.commit_message";

/// `[git.repositories]`'s key for a repository: its root with `/` on every OS, as
/// `git rev-parse --show-toplevel` prints it.
pub(crate) fn repository_key(root: &Path) -> String {
    root.to_string_lossy().replace('\\', "/")
}

impl Workspace {
    /// Generate ✨: the first time, asks whether the diff may go to the agent; then writes the
    /// message in the background. A click while it runs stops it.
    pub(crate) fn generate_message(
        &mut self,
        id: BlockId,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(git) = self.space.git(id) else {
            return;
        };
        if let Some(cancel) = &git.generating {
            cancel.store(true, Ordering::Relaxed);
            return;
        }
        let Some(title) = self
            .commit_agent
            .as_ref()
            .filter(|a| a.ready)
            .map(|a| a.title.clone())
        else {
            return;
        };
        if self.config.git.commit_message.confirmed {
            self.generate_now(id, window, cx);
            return;
        }
        let entity = cx.entity();
        prompt::confirm(
            format!("Send your changes to {title}?"),
            format!(
                "Generate sends the diff of what you commit to {title}, which sends it to its \
                 provider and uses your account. Templum asks this once."
            ),
            "Generate",
            move |window, cx| {
                entity.update(cx, |ws, cx| {
                    ws.edit(
                        Edit::set(TABLE, "confirmed", true),
                        |c| c.git.commit_message.confirmed = true,
                        cx,
                    );
                    ws.generate_now(id, window, cx);
                })
            },
            window,
            cx,
        );
    }

    /// Reads what the commit would take, builds the request and runs the agent, off the UI
    /// thread and beside the block's own commands (it only reads, so they don't wait for it).
    fn generate_now(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let Some(agent) = self.commit_agent.clone() else {
            return;
        };
        let at = self.here(id);
        let settings = self.config.git.commit_message.clone();
        let repositories = &self.config.git.repositories;
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        let Some(repo) = git.repo().cloned() else {
            return;
        };
        // This repository's own rules win over Settings ▸ Git's.
        let instructions = repositories
            .get(&repository_key(&repo.root))
            .and_then(|r| r.commit_instructions.clone())
            .filter(|i| !i.trim().is_empty())
            .unwrap_or(settings.instructions);
        let all = git.commit_all();
        let before = (
            git.summary.read(cx).value(),
            git.description.read(cx).value(),
        );
        let cancel = Arc::new(AtomicBool::new(false));
        git.generating = Some(cancel.clone());
        cx.notify();
        let template = settings
            .prompt
            .unwrap_or_else(|| message::PROMPT.to_string());
        let max_bytes = settings.max_diff_kb as usize * 1024;
        let timeout = Duration::from_secs(settings.timeout);
        let title = agent.title.clone();
        cx.spawn_in(window, async move |ws, cx| {
            let answer = cx
                .background_executor()
                .spawn(async move {
                    let changes =
                        message::changes(&repo, all, max_bytes).map_err(Failure::Git)?;
                    let request = message::request(
                        &template,
                        &Request {
                            instructions: &instructions,
                            files: &changes.files,
                            diff: &changes.diff,
                            recent: &changes.recent,
                            max_bytes,
                        },
                    );
                    message::run(
                        &agent.command,
                        &agent.model,
                        &request,
                        &repo.root,
                        timeout,
                        &cancel,
                    )
                })
                .await;
            ws.update_in(cx, |ws, window, cx| {
                ws.generated(at, &title, before, answer, window, cx)
            })
            .ok();
        })
        .detach();
    }

    /// The agent's answer: in the fields, unless the summary or the description changed since
    /// the click (what was typed is never replaced, and a commit made meanwhile cleared them);
    /// a failure says why, with Details; a cancel says nothing.
    // ponytail: a block closed or pointed at another folder meanwhile drops the answer, and its
    // agent runs on to its timeout; set `generating` in `set_git_folder` and on close if a slow
    // agent's cost matters.
    fn generated(
        &mut self,
        at: GitAt,
        agent: &str,
        before: (SharedString, SharedString),
        answer: Result<String, Failure>,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(git) = self.git_at(&at) else {
            return;
        };
        git.generating = None;
        let (summary, description) = (git.summary.clone(), git.description.clone());
        cx.notify();
        let parts = answer.and_then(|a| {
            message::split(&a).ok_or(Failure::Empty {
                stderr: String::new(),
            })
        });
        match parts {
            Err(Failure::Cancelled) => {}
            Err(failure) => self.notify_generate_failure(agent, &failure, window, cx),
            Ok((s, d)) => {
                if (summary.read(cx).value(), description.read(cx).value()) != before {
                    show_notification(
                        window,
                        cx,
                        Notification::info(format!(
                            "Kept your message: it changed while {agent} was writing one"
                        )),
                    );
                    return;
                }
                summary.update(cx, |field, cx| field.set_value(s, window, cx));
                description.update(cx, |field, cx| field.set_value(d, window, cx));
            }
        }
    }

    /// Generate failed: the sentence, and Details with the exit code and what the agent wrote
    /// to stderr. No Run in a terminal: the command's files are gone by now.
    fn notify_generate_failure(
        &self,
        agent: &str,
        failure: &Failure,
        window: &mut Window,
        cx: &mut App,
    ) {
        eprintln!("templum: {agent}: {failure}");
        let title = SharedString::from(format!("{agent}: commit message"));
        let (text, mono) = (failure.details(), self.cell.font.family.clone());
        let notification = Notification::error(failure.to_string())
            .title(title.clone())
            .autohide(false)
            .content(move |_, _, _| {
                let (title, text, mono) = (title.clone(), text.clone(), mono.clone());
                div()
                    .mt(px(6.0))
                    .child(
                        Button::new("generate-details")
                            .label("Details")
                            .small()
                            .on_click(move |_, window, cx| {
                                prompt::details(
                                    title.clone(),
                                    text.clone(),
                                    mono.clone(),
                                    window,
                                    cx,
                                )
                            }),
                    )
                    .into_any_element()
            });
        show_notification(window, cx, notification);
    }
}

/// Generate ✨, beside the summary: shown while the agent chosen in Settings ▸ Git is ready and
/// there is something to describe (what is staged, or every change for Commit all changes). It
/// spins while the agent writes; a click then stops it.
fn generate_button(
    ws: &Workspace,
    id: BlockId,
    git: &Git,
    z: f32,
    cx: &mut Context<Workspace>,
) -> Option<AnyElement> {
    let agent = ws.commit_agent.as_ref().filter(|a| a.ready)?;
    if git.repo().is_none() || (git.status.staged().is_empty() && !git.commit_all()) {
        return None;
    }
    let (ui, n) = (ws.ui, id.0 as usize);
    let running = git.generating.is_some();
    let tip: SharedString = if running {
        "Stop the agent".into()
    } else {
        format!("Generate: {} writes the message", agent.title).into()
    };
    Some(
        div()
            .id(("git-generate", n))
            .flex()
            .flex_shrink_0()
            .items_center()
            .justify_center()
            .size(px(22.0 * z))
            .rounded(px(5.0 * z))
            .cursor_pointer()
            .hover(move |s| s.bg(ui.hover))
            .child(if running {
                Spinner::new()
                    .with_size(UiSize::Size(px(12.0 * z)))
                    .into_any_element()
            } else {
                Icon::new(IconName::Sparkles)
                    .size(px(13.0 * z))
                    .text_color(ui.title)
                    .into_any_element()
            })
            .tooltip(move |window, cx| Tooltip::new(tip.clone()).build(window, cx))
            .on_click(cx.listener(move |ws, _: &ClickEvent, window, cx| {
                ws.generate_message(id, window, cx)
            }))
            .test_support()
            .into_any_element(),
    )
}

    /// The model Generate asks for; empty: the agent's recommended one (the key goes).
    pub(crate) fn set_commit_model(&mut self, model: &str, cx: &mut Context<Self>) {
        let model = model.trim();
        if model.is_empty() {
            self.edit(
                Edit::remove(TABLE, "model"),
                |c| c.git.commit_message.model = None,
                cx,
            );
        } else {
            let chosen = model.to_string();
            self.edit(
                Edit::set(TABLE, "model", model),
                |c| c.git.commit_message.model = Some(chosen),
                cx,
            );
        }
    }

    /// `[git.repositories."<root>"].commit_instructions`: they win over Settings ▸ Git's in
    /// this repository; empty: the global ones again.
    // ponytail: removing the last key leaves an empty `[git.repositories."…"]` line in the file;
    // drop the table in `save_edits` when someone minds it.
    pub(crate) fn set_repo_instructions(&mut self, root: &Path, text: &str, cx: &mut Context<Self>) {
        let key = repository_key(root);
        let table = config::repository_table(&key);
        let text = text.trim().to_string();
        if text.is_empty() {
            self.edit(
                Edit::remove(table, "commit_instructions"),
                |c| {
                    c.git.repositories.remove(&key);
                },
                cx,
            );
        } else {
            self.edit(
                Edit::set(table, "commit_instructions", text.as_str()),
                |c| {
                    c.git.repositories.entry(key).or_default().commit_instructions = Some(text)
                },
                cx,
            );
        }
    }

    /// The ⚙'s Instructions for this repository…: a field holding them, Save writes them.
    pub(crate) fn ask_repo_instructions(
        &mut self,
        id: BlockId,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(root) = self
            .space
            .git(id)
            .and_then(|g| g.repo())
            .map(|r| r.root.clone())
        else {
            return;
        };
        let current = self
            .config
            .git
            .repositories
            .get(&repository_key(&root))
            .and_then(|r| r.commit_instructions.clone())
            .unwrap_or_default();
        let entity = cx.entity();
        prompt::ask_text(
            "Instructions for this repository",
            "Save",
            current,
            move |text, _, cx| {
                entity.update(cx, |ws, cx| ws.set_repo_instructions(&root, &text, cx));
                true
            },
            window,
            cx,
        );
    }

    /// is sent), its answer or its whole error shown under the button. It runs even when the
    /// agent isn't ready: its error says why. A click while it runs stops it.
    pub(crate) fn try_message(&mut self, cx: &mut Context<Self>) {
        if let Some(TryIt::Running(cancel)) = &self.message_try {
            cancel.store(true, Ordering::Relaxed);
            return;
        }
        let Some(agent) = self.commit_agent.clone() else {
            return;
        };
        let settings = self.config.git.commit_message.clone();
        let cancel = Arc::new(AtomicBool::new(false));
        self.message_try = Some(TryIt::Running(cancel.clone()));
        cx.notify();
        let template = settings
            .prompt
            .unwrap_or_else(|| message::PROMPT.to_string());
        let timeout = Duration::from_secs(settings.timeout);
        let instructions = settings.instructions;
        cx.spawn(async move |ws, cx| {
            let answer = cx
                .background_executor()
                .spawn(async move {
                    let files = [message::SAMPLE_FILE.to_string()];
                    let request = message::request(
                        &template,
                        &Request {
                            instructions: &instructions,
                            files: &files,
                            diff: message::SAMPLE_DIFF,
                            recent: &[],
                            max_bytes: usize::MAX,
                        },
                    );
                    message::run(
                        &agent.command,
                        &agent.model,
                        &request,
                        &std::env::temp_dir(),
                        timeout,
                        &cancel,
                    )
                })
                .await;
            ws.update(cx, |ws, cx| {
                ws.message_try = match answer {
                    Err(Failure::Cancelled) => None,
                    Ok(answer) => Some(TryIt::Answer(answer.trim().to_string())),
                    Err(failure) => Some(TryIt::Failed(failure.details())),
                };
                cx.notify();
            })
            .ok();
        })
        .detach();
    }

struct AreaState {

/// A text area of `rows` lines showing `value`, the row's whole width (under its title);
/// typing calls `set` with the whole text.
pub(super) fn text_area(
    entity: &Entity<Workspace>,
    key: &'static str,
    value: String,
    rows: usize,
    set: fn(&mut Workspace, &str, &mut Context<Workspace>),
    window: &mut Window,
    cx: &mut App,
) -> AnyElement {
    let value = SharedString::from(value);
    let e = entity.clone();
    let initial = value.clone();
    let state = window.use_keyed_state(
        SharedString::from(format!("area-{key}")),
        cx,
        move |window, cx| {
            let input = cx.new(|cx| {
                TextareaState::new(window, cx)
                    .rows(rows)
                    .default_value(initial)
            });
            let _change = cx.subscribe(&input, move |_, input, event: &InputEvent, cx| {
                if let InputEvent::Change = event {
                    let text = input.read(cx).value();
                    e.update(cx, |ws, cx| set(ws, &text, cx));
                }
            });
            AreaState { input, _change }
        },
    );
    // What the workspace shows wins over the field's text: a hand edit, a reset.
    state.update(cx, |state, cx| {
        if state.input.read(cx).value() != value {
            state
                .input
                .update(cx, |input, cx| input.set_value(value.clone(), window, cx));
        }
    });
    Textarea::new(&state.read(cx).input)
        .w_full()
        .into_any_element()
}

/// The agents with a generate command; choosing one puts the model back to its recommended one.
fn agent_row(ws: &Workspace, entity: &Entity<Workspace>) -> Row {
    let settings = &ws.config.git.commit_message;
    let choices: Vec<(SharedString, SharedString)> = ws
        .agents
        .iter()
        .filter(|a| a.generate.is_some())
        .map(|a| (a.id.clone().into(), a.title.clone().into()))
        .collect();
    let current: SharedString = ws
        .commit_agent
        .as_ref()
        .map(|a| a.id.clone())
        .or_else(|| settings.agent.clone())
        .unwrap_or_else(|| "None".to_string())
        .into();
    let about = match (&ws.commit_agent, &settings.agent) {
        (Some(a), _) if a.model.is_empty() && a.command.contains("{model}") => {
            "No model: type one below".to_string()
        }
        (Some(a), _) if !a.ready => format!("Not installed: {}", a.program()),
        (Some(_), _) => "Generate ✨, beside a Git block's summary, asks it".to_string(),
        (None, Some(id)) => format!("{id} has no generate command: set one in Agents"),

/// What Another model shows: what is being typed while it is the model set, else the model
/// set (none: the recommended one, which the list above shows).
fn typed_model(ws: &Workspace) -> String {
    let set = ws
        .config
        .git
        .commit_message
        .model
        .clone()
        .unwrap_or_default();
    match ws.drafts.get("model") {
        Some(typed) if typed.trim() == set => typed.clone(),
        _ => set,
    }
}

/// Typing in Another model: the text is kept as typed (a space before the next word stays),
/// the model trimmed.
fn set_typed_model(ws: &mut Workspace, text: &str, cx: &mut Context<Workspace>) {
    ws.drafts.insert("model", text.to_string());
    ws.set_commit_model(text, cx);
}

/// `instructions`, kept as typed; empty removes the key.
pub(crate) fn set_commit_instructions(ws: &mut Workspace, text: &str, cx: &mut Context<Workspace>) {
    if text.trim().is_empty() {
        ws.edit(
            Edit::remove(TABLE, "instructions"),
            |c| c.git.commit_message.instructions.clear(),
            cx,
        );
    } else {
        let kept = text.to_string();
        ws.edit(
            Edit::set(TABLE, "instructions", text),
            |c| c.git.commit_message.instructions = kept,
            cx,
        );
    }
}

/// `prompt`: the default, or nothing, removes the key (Reset to default).
pub(crate) fn set_commit_prompt(ws: &mut Workspace, text: &str, cx: &mut Context<Workspace>) {
    if text == message::PROMPT || text.trim().is_empty() {
        ws.edit(
            Edit::remove(TABLE, "prompt"),
            |c| c.git.commit_message.prompt = None,
            cx,
        );
    } else {
        let kept = text.to_string();
        ws.edit(
            Edit::set(TABLE, "prompt", text),
            |c| c.git.commit_message.prompt = Some(kept),
            cx,
        );
    }
}

/// Try it: a button (it spins, and stops the agent, while it runs), and under it the answer, or
/// the whole error in red.

    let running = matches!(ws.message_try, Some(TryIt::Running(_)));
    let e = entity.clone();

        .id("git-try-message")
        .flex()
        .items_center()
        .gap(px(6.0))
        .px(px(10.0))
        .py(px(3.0))
        .rounded_full()
        .border_1()
        .border_color(ui.hairline)
        .text_size(px(12.0))
        .cursor_pointer()
        .hover(move |s| s.bg(ui.hover))
        .active(move |s| s.bg(ui.pressed))
        .when(running, |el| {
            el.child(Spinner::new().with_size(UiSize::Size(px(12.0))))
        })
        .child(if running { "Stop" } else { "Try it" })
        .on_click(move |_: &ClickEvent, _, cx| e.update(cx, |ws, cx| ws.try_message(cx)))
        .test_support();
    let shown = match &ws.message_try {
        Some(TryIt::Answer(text)) => Some((text.clone(), ui.title)),
        Some(TryIt::Failed(text)) => Some((text.clone(), hsla(ws.theme.palette.ansi[1], 1.0))),
        _ => None,
    };
    let row = Row::new("git.commit_message.try", "Try it")
        .description("Runs the agent on a small sample change, not yours, and shows its answer")
        .control(button);
    match shown {
        Some((text, color)) => row.below(
            div()
                .id("git-try-result")
                .p(px(8.0))
                .rounded(px(6.0))
                .border_1()
                .border_color(ui.hairline)
                .font_family(ws.cell.font.family.clone())
                .text_size(px(12.0))
                .text_color(color)
                .child(text)
                .test_support(),
        ),
        None => row,
    }
}
