# Git Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Git block on one repository: changes with staging and diffs, commits, history, branches, stashes, fetch / pull / push, files opened in the editor block, and every command run through the user's own `git` off the UI thread.

**Architecture:** A new UI-free library crate, `templum-git`, holds `Repo` (the root, the `git` program, one method per command returning typed values or a `GitError`) and pure parsers for `git status --porcelain=v2 -z`, the log record format, `for-each-ref`, `stash list` and `diff-tree --name-status`, unit-tested on recorded output and integration-tested on a temporary repository (CI has `git`). In `templum`, `git_block.rs` holds the block's state (`Git`: the folder, what was found there, the last status, the tab, the lists, the diff view, the commit fields) and its body; the workspace gains one `Body::Git` arm, runs every `git` call on the background executor one at a time per block, refreshes on a 2-second timer while the block is on screen, after each action, and when a terminal of the workspace finishes a command in the repository. Failed commands become a notification with **Details** and **Run in a terminal** (a terminal beside the block with the command typed in).

**Tech Stack:** Rust 1.98, `std::process::Command` for `git`, GPUI through `gpui-kit =0.7.1` (gpui-component `Button`, `Input`, `Textarea`, `Checkbox`, `Spinner`, `Notification`, `AlertDialog`, `EditorState` with the `diff` grammar; GPUI's `uniform_list`), `serde_json`. No new dependency.

**Spec:** `docs/specs/cockpit.md`, section 8 (Git), the `new_git` row of section 3's shortcut table, "Shared pieces" (Settings ▸ Tools, `Target::GitRow`), "Error handling" and "Testing". Plans 1, 2 and 4 are merged: `Space::blocks`, `Body`, `toolbar.rs`, `launcher::ask_folder_for`, `prompt.rs`, `menu::Target`, `editor.rs` with `Workspace::open_in_editor` and `terminal_beside`, and `Canvas::place_beside` exist.

## Global Constraints

- Only `crates/templum` depends on `gpui-kit`; `templum-git` depends on nothing but `std` (`tempfile` for its tests). No new dependency line in any crate.
- `gpui-kit` stays pinned `=0.7.1`. No Cargo feature is added: the `tree-sitter-diff` grammar is already on.
- No `unsafe`. Every logic change ships a test that fails without it; UI changes get a headless `#[gpui_kit::test]`. The tests that need `git` run it from `PATH`; CI's three runners have it.
- Commits go on `development`, titled with an imperative sentence (AGENTS.md).
- Before every commit: `cargo fmt --all && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`. Task 1 also runs `cargo deny check`.
- **`git` never waits for input:** every command runs with `GIT_TERMINAL_PROMPT=0`, `GIT_EDITOR=true`, no stdin, in the repository's root. A read or an action runs on `cx.background_executor()`; the UI thread never runs `git`.
- **It never runs a command the user didn't ask for, except reads.** Reads: `rev-parse`, `status`, `log`, `for-each-ref`, `stash list`, `diff`, `show`, `diff-tree`, `config --get`, `--version`, `check-ref-format`.
- Exact values: a new Git block is **800 × 560** world units, at least **480 × 320**; the lists column is **300** world units wide; rows are **24** world units tall; text is **12** world units × zoom (the diff and hashes in the terminal font at **12**); the status is read every **2 seconds** while the block is in the viewport; History loads **200** commits at a time; a terminal opened for a failed command goes beside the block (`Canvas::place_beside`).
- Shortcut: `new_git` Ctrl+Shift+G / Cmd+Shift+G.
- Config: `[git] program = "git"` (default `"git"`), in a new Settings ▸ **Tools** section, with the version found or "not found".
- Where this plan differs from the spec, on purpose (each one is noted again in its task):
  - the History search filters the loaded commits in Templum (subject and author, without case): `git log --grep` and `--author` together mean *both* must match, not either;
  - ↺ (discard) is on unstaged rows only: discarding a staged row would need two commands with different failure modes (unstage it first, then discard);
  - `Diff` is the diff's text plus `first_hunk_line`: nothing needs the hunks split further;
  - the block's title bar holds the repository's name; the branch pill, the counts and Fetch / Pull / Push / ↻ are the body's first row (the title bar is the drag handle, 28 units tall);
  - the commit's author is read with each status (one more `git config --get` per refresh is cheap);
  - the Set… dialog for the author asks the name, then the email, in two dialogs (`prompt::ask_text` twice).
- GPUI lessons in `docs/adr/0002-ui-framework.md` apply; read the pinned sources (`~/.cargo/registry/src/*/gpui-pre-0.3.8`, `gpui-base-0.7.1`, `gpui-component-0.7.1`), never guess. Everything named below was read there on 2026-10-11.

## Review Focus

1. **A repository with no commits yet.** `git log`, `git restore --staged` and `git diff` against HEAD all fail there; the block must still show untracked files, stage them (`git add`), unstage them (`git reset -q --`, which works without HEAD) and commit. Pinned by `a_fresh_repository_lists_an_untracked_file_and_stages_it` (Task 3) and `unstage_works_before_the_first_commit` (Task 2).
2. **A refresh asked while one runs.** The 2-second timer, a finished terminal command and a click on ↻ can all land while a read is out; exactly one more read must follow, never a pile. Pinned by `a_refresh_asked_while_one_runs_waits_and_runs_once` (Task 3).
3. **A path with a space, a non-ASCII name, or a rename.** `-z` output puts the rename's old path in the *next* NUL field; the lists, the diff and the stage commands must use the exact paths. Pinned by `porcelain_v2_with_every_kind_of_entry` (Task 1) and `staging_a_renamed_file_and_one_with_a_space` (Task 2).
4. **A failed command must never hang or hide its reason.** `GIT_TERMINAL_PROMPT=0` turns a password prompt into an error; the notification shows stderr's first line, **Details** shows it all, and **Run in a terminal** types the exact command. Pinned by `a_failed_command_offers_details_and_a_terminal` (Task 6).
5. **Closing the block, the workspace or the window while a command runs.** The background task holds a weak entity; a block gone when the result comes back is ignored, nothing panics. Pinned by `a_result_for_a_closed_block_is_dropped` (Task 3).

```rust
//! Pure parsers for `git`'s machine formats. Every format here is documented by Git and stable:
//! `status --porcelain=v2 -z`, `log --format` with `-z`, `for-each-ref --format`,
//! `stash list --format`, `diff-tree --name-status -z`.

/// What happened to a file, as the status badges name it.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Change {
    Modified,
    Added,
    Deleted,
    Renamed,
    Untracked,
    Conflict,
    TypeChanged,
}

impl Change {
    /// The badge's letter (docs/specs/cockpit.md, section 8).
    pub fn letter(self) -> char {
        match self {
            Change::Modified => 'M',
            Change::Added => 'A',
            Change::Deleted => 'D',
            Change::Renamed => 'R',
            Change::Untracked => 'U',
            Change::Conflict => 'C',
            Change::TypeChanged => 'T',
        }
    }

    pub fn word(self) -> &'static str {
        match self {
            Change::Modified => "modified",
            Change::Added => "added",
            Change::Deleted => "deleted",
            Change::Renamed => "renamed",
            Change::Untracked => "untracked",
            Change::Conflict => "conflict",
            Change::TypeChanged => "type changed",
        }
    }

    /// A porcelain status letter; '.' and anything unknown is None. A copy counts as added.
    fn of(letter: u8) -> Option<Change> {
        Some(match letter {
            b'M' => Change::Modified,
            b'A' | b'C' => Change::Added,
            b'D' => Change::Deleted,
            b'R' => Change::Renamed,
            b'T' => Change::TypeChanged,
            b'U' => Change::Conflict,
            _ => return None,
        })
    }
}

/// One path in the status: what is staged for it and what isn't.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Entry {
    /// Relative to the root, with '/' on every OS, as git prints it.
    pub path: String,
    /// A rename's old path.
    pub from: Option<String>,
    /// Index against HEAD.
    pub staged: Option<Change>,
    /// Working tree against the index; an untracked file is `Untracked` here, a conflict is
    /// `Conflict` here.
    pub unstaged: Option<Change>,
}

impl Entry {
    pub fn conflict(&self) -> bool {
        self.unstaged == Some(Change::Conflict)
    }

    pub fn name(&self) -> &str {
        self.path.rsplit('/').next().unwrap_or(&self.path)
    }

    /// The folder part, "" at the root.
    pub fn folder(&self) -> &str {
        self.path.rsplit_once('/').map_or("", |(dir, _)| dir)
    }
}

/// `git status --porcelain=v2 --branch -z -uall`, parsed.
#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct Status {
    /// None: detached.
    pub branch: Option<String>,
    /// HEAD's commit; None before the first commit.
    pub oid: Option<String>,
    pub upstream: Option<String>,
    pub ahead: u32,
    pub behind: u32,
    pub entries: Vec<Entry>,
}

impl Status {
    pub fn conflicts(&self) -> Vec<&Entry> {
        self.entries.iter().filter(|e| e.conflict()).collect()
    }

    pub fn staged(&self) -> Vec<&Entry> {
        self.entries
            .iter()
            .filter(|e| e.staged.is_some() && !e.conflict())
            .collect()
    }

    /// Unstaged changes and untracked files, together.
    pub fn unstaged(&self) -> Vec<&Entry> {
        self.entries
            .iter()
            .filter(|e| e.unstaged.is_some() && !e.conflict())
            .collect()
    }
}

/// NUL-separated records, as `-z` prints them, without the empty last one.
fn records(out: &[u8]) -> impl Iterator<Item = &str> {
    out.split(|b| *b == 0)
        .filter(|r| !r.is_empty())
        .map(|r| std::str::from_utf8(r).unwrap_or(""))
}

pub fn parse_status(out: &[u8]) -> Status {
    let mut status = Status::default();
    let mut records = records(out);
    while let Some(record) = records.next() {
        if let Some(header) = record.strip_prefix("# ") {
            let (key, value) = header.split_once(' ').unwrap_or((header, ""));
            match key {
                "branch.oid" if value != "(initial)" => status.oid = Some(value.to_string()),
                "branch.head" if value != "(detached)" => status.branch = Some(value.to_string()),
                "branch.upstream" => status.upstream = Some(value.to_string()),
                "branch.ab" => {
                    let mut parts = value.split(' ');
                    status.ahead = parts.next().and_then(|a| a[1..].parse().ok()).unwrap_or(0);
                    status.behind = parts.next().and_then(|b| b[1..].parse().ok()).unwrap_or(0);
                }
                _ => {}
            }
            continue;
        }
        let mut fields = record.splitn(2, ' ');
        let (kind, rest) = (fields.next().unwrap_or(""), fields.next().unwrap_or(""));
        let entry = match kind {
            // ? <path>
            "?" => Entry {
                path: rest.to_string(),
                from: None,
                staged: None,
                unstaged: Some(Change::Untracked),
            },
            // 1 <XY> <sub> <mH> <mI> <mW> <hH> <hI> <path>
            // 2 <XY> <sub> <mH> <mI> <mW> <hH> <hI> <X><score> <path>  then the old path's record
            // u <XY> <sub> <m1> <m2> <m3> <mW> <h1> <h2> <h3> <path>
            "1" | "2" | "u" => {
                let xy = rest.as_bytes();
                let (x, y) = (xy.first().copied().unwrap_or(b'.'), xy.get(1).copied().unwrap_or(b'.'));
                let skip = match kind {
                    "1" => 7,
                    "2" => 8,
                    _ => 9,
                };
                let path = rest.splitn(skip + 1, ' ').nth(skip).unwrap_or("").to_string();
                let from = (kind == "2").then(|| records.next().unwrap_or("").to_string());
                if kind == "u" {
                    Entry {
                        path,
                        from: None,
                        staged: None,
                        unstaged: Some(Change::Conflict),
                    }
                } else {
                    Entry {
                        path,
                        from,
                        staged: Change::of(x),
                        unstaged: Change::of(y),
                    }
                }
            }
            // "!" (ignored) is never asked for; anything else is unknown.
            _ => continue,
        };
        status.entries.push(entry);
    }
    status
}

/// `git log -z --format=LOG_FORMAT --date=LOG_DATE`: fields split by 0x1f, records by NUL.
pub const LOG_FORMAT: &str = "%H%x1f%h%x1f%an%x1f%ae%x1f%at%x1f%ad%x1f%P%x1f%D%x1f%s%x1f%b";
pub const LOG_DATE: &str = "format:%Y-%m-%d %H:%M";

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Commit {
    pub hash: String,
    pub short: String,
    pub author: String,
    pub email: String,
    /// Unix seconds.
    pub time: i64,
    /// "2026-10-11 16:14", in the local time zone.
    pub date: String,
    pub parents: Vec<String>,
    /// As `%D` names them: "HEAD -> main", "tag: v1", "origin/main".
    pub refs: Vec<String>,
    pub subject: String,
    pub body: String,
}

pub fn parse_log(out: &[u8]) -> Vec<Commit> {
    records(out)
        .filter_map(|record| {
            let f: Vec<&str> = record.splitn(10, '\x1f').collect();
            if f.len() < 10 {
                return None;
            }
            let list = |s: &str| -> Vec<String> {
                s.split(", ")
                    .filter(|r| !r.is_empty())
                    .map(str::to_string)
                    .collect()
            };
            Some(Commit {
                hash: f[0].to_string(),
                short: f[1].to_string(),
                author: f[2].to_string(),
                email: f[3].to_string(),
                time: f[4].parse().unwrap_or(0),
                date: f[5].to_string(),
                parents: f[6].split(' ').filter(|p| !p.is_empty()).map(str::to_string).collect(),
                refs: list(f[7]),
                subject: f[8].to_string(),
                body: f[9].trim_end().to_string(),
            })
        })
        .collect()
}

/// `git for-each-ref --format=BRANCH_FORMAT refs/heads refs/remotes`: one line per ref, fields
/// split by NUL.
pub const BRANCH_FORMAT: &str = "%(refname)%00%(refname:short)%00%(objectname:short)%00%(upstream:short)%00%(upstream:track,nobracket)%00%(subject)%00%(HEAD)";

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Branch {
    /// "main", or "origin/main" for a remote one.
    pub name: String,
    pub remote: bool,
    pub current: bool,
    /// The short hash of its last commit.
    pub commit: String,
    pub upstream: Option<String>,
    /// Its upstream no longer exists.
    pub gone: bool,
    pub ahead: u32,
    pub behind: u32,
    /// Its last commit's subject.
    pub subject: String,
}

pub fn parse_branches(out: &[u8]) -> Vec<Branch> {
    let text = String::from_utf8_lossy(out);
    text.lines()
        .filter_map(|line| {
            let f: Vec<&str> = line.split('\0').collect();
            if f.len() < 7 || f[0].ends_with("/HEAD") {
                return None;
            }
            let track = f[4];
            let count = |word: &str| -> u32 {
                track
                    .split(", ")
                    .find_map(|part| part.strip_prefix(word))
                    .and_then(|n| n.trim().parse().ok())
                    .unwrap_or(0)
            };
            Some(Branch {
                name: f[1].to_string(),
                remote: f[0].starts_with("refs/remotes/"),
                current: f[6] == "*",
                commit: f[2].to_string(),
                upstream: (!f[3].is_empty()).then(|| f[3].to_string()),
                gone: track == "gone",
                ahead: count("ahead "),
                behind: count("behind "),
                subject: f[5].to_string(),
            })
        })
        .collect()
}

/// `git stash list -z --format=STASH_FORMAT`.
pub const STASH_FORMAT: &str = "%gd%x1f%at%x1f%gs";

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Stash {
    /// N in `stash@{N}`.
    pub index: usize,
    pub time: i64,
    /// "On main: my work", "WIP on main: 3dba34c Add 2b".
    pub message: String,
}

pub fn parse_stashes(out: &[u8]) -> Vec<Stash> {
    records(out)
        .filter_map(|record| {
            let f: Vec<&str> = record.splitn(3, '\x1f').collect();
            if f.len() < 3 {
                return None;
            }
            let index = f[0]
                .strip_prefix("stash@{")?
                .strip_suffix('}')?
                .parse()
                .ok()?;
            Some(Stash {
                index,
                time: f[1].parse().unwrap_or(0),
                message: f[2].to_string(),
            })
        })
        .collect()
}

/// One file of a commit, from `git diff-tree --root --no-commit-id -r -z -M --name-status`.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct CommitFile {
    pub change: Change,
    pub path: String,
    pub from: Option<String>,
}

pub fn parse_name_status(out: &[u8]) -> Vec<CommitFile> {
    let mut files = Vec::new();
    let mut records = records(out);
    while let Some(code) = records.next() {
        let Some(change) = code.bytes().next().and_then(Change::of) else {
            continue;
        };
        let Some(first) = records.next() else {
            break;
        };
        // R<score> and C<score> take two paths: the old one first.
        if matches!(change, Change::Renamed) || code.starts_with('C') {
            let Some(path) = records.next() else {
                break;
            };
            files.push(CommitFile {
                change,
                path: path.to_string(),
                from: Some(first.to_string()),
            });
        } else {
            files.push(CommitFile {
                change,
                path: first.to_string(),
                from: None,
            });
        }
    }
    files
}

/// The new file's first line of the first hunk (1-based), from `@@ -a,b +c,d @@`.

        .parse()
        .ok()
}
```

```rust
//! One repository and the `git` program that runs on it. Every method runs one command to
//! completion on the calling thread (the UI runs them on its background executor), never waits
//! for input, and gives back typed values or a [`GitError`] with the command and its stderr.

use std::fmt;
use std::io;
use std::path::{Path, PathBuf};
use std::process::{Command, Stdio};

use crate::parse::{self, Change, Entry, Operation, Status};

/// A command that failed: which one, how, and what git said.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct GitError {
    /// "git push origin main", as a shell would take it.
    pub command: String,
    /// The exit code; None when it couldn't run or was killed by a signal.
    pub code: Option<i32>,
    pub stderr: String,
    /// The program isn't installed (or isn't on PATH).
    pub missing: bool,
}

impl GitError {
    pub fn first_line(&self) -> &str {
        self.stderr
            .lines()
            // Git's hints come before the fatal line; the fatal line says why.
            .find(|l| l.starts_with("fatal:") || l.starts_with("error:"))
            .or_else(|| self.stderr.lines().next())
            .unwrap_or("")
    }

    /// It failed because git would have asked for a password or a key.
    pub fn needs_input(&self) -> bool {
        parse::needs_input(&self.stderr)
    }
}

impl fmt::Display for GitError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}: {}", self.command, self.first_line())
    }
}

impl std::error::Error for GitError {}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Repo {
    program: String,
    /// The working tree's top folder.
    pub root: PathBuf,
    /// Where HEAD, MERGE_HEAD and the like live (a worktree's own, for a linked worktree).
    pub git_dir: PathBuf,
}

/// "git a 'b c'": the command as a notification or a terminal shows it.
fn shown(program: &str, args: &[&str]) -> String {
    std::iter::once(program)
        .chain(args.iter().copied())
        .map(|a| {
            if a.is_empty() || a.contains(' ') {
                format!("'{a}'")
            } else {
                a.to_string()
            }
        })
        .collect::<Vec<_>>()
        .join(" ")
}

/// Runs `program args` in `dir`: no terminal, no prompt, no editor, English messages.
fn run_in(program: &str, dir: &Path, args: &[&str]) -> Result<Vec<u8>, GitError> {
    let command = shown(program, args);
    let mut c = Command::new(program);
    c.args(args)
        .current_dir(dir)
        .env("GIT_TERMINAL_PROMPT", "0")
        .env("GIT_EDITOR", "true")
        .env("LC_ALL", "C")
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped());
    // No console window flashing behind the app.
    #[cfg(windows)]
    {
        use std::os::windows::process::CommandExt as _;
        c.creation_flags(0x0800_0000); // CREATE_NO_WINDOW
    }
    let out = c.output().map_err(|e| GitError {
        missing: e.kind() == io::ErrorKind::NotFound,
        command: command.clone(),
        code: None,
        stderr: format!("Couldn't run {program}: {e}"),
    })?;
    if out.status.success() {
        Ok(out.stdout)
    } else {
        Err(GitError {
            command,
            code: out.status.code(),
            stderr: String::from_utf8_lossy(&out.stderr).into_owned(),
            missing: false,
        })
    }
}

impl Repo {
    /// "git version 2.55.0", or why `program` can't run.
    pub fn version(program: &str) -> Result<String, GitError> {
        let out = run_in(program, Path::new("."), &["--version"])?;
        Ok(String::from_utf8_lossy(&out).trim().to_string())
    }

    /// The repository holding `folder`: Ok(None) when there is none.
    pub fn discover(program: &str, folder: &Path) -> Result<Option<Repo>, GitError> {
        let out = match run_in(
            program,
            folder,
            &["rev-parse", "--show-toplevel", "--absolute-git-dir"],
        ) {
            Ok(out) => out,
            Err(e) if e.stderr.contains("not a git repository") => return Ok(None),
            Err(e) => return Err(e),
        };
        let text = String::from_utf8_lossy(&out);
        let mut lines = text.lines();
        let (Some(root), Some(git_dir)) = (lines.next(), lines.next()) else {
            return Ok(None);
        };
        Ok(Some(Repo {
            program: program.to_string(),
            root: PathBuf::from(root),
            git_dir: PathBuf::from(git_dir),
        }))
    }

    /// `git init` in `folder`.
    pub fn init(program: &str, folder: &Path) -> Result<Repo, GitError> {
        run_in(program, folder, &["init", "-q"])?;
        Self::discover(program, folder)?.ok_or_else(|| GitError {
            command: shown(program, &["init", "-q"]),
            code: None,
            stderr: "git init made no repository".to_string(),
            missing: false,
        })
    }

    /// Runs `git args` in the root; Ok is stdout.
    pub fn run(&self, args: &[&str]) -> Result<Vec<u8>, GitError> {
        run_in(&self.program, &self.root, args)
    }

    fn text(&self, args: &[&str]) -> Result<String, GitError> {
        Ok(String::from_utf8_lossy(&self.run(args)?).into_owned())
    }

    pub fn status(&self) -> Result<Status, GitError> {
        let out = self.run(&["status", "--porcelain=v2", "--branch", "-z", "-uall"])?;
        Ok(parse::parse_status(&out))
    }

    /// A merge, rebase, cherry-pick or revert in progress, read from the git dir's markers.
    pub fn operation(&self) -> Option<Operation> {
        let has = |name: &str| self.git_dir.join(name).exists();
        if has("MERGE_HEAD") {
            Some(Operation::Merge)
        } else if has("rebase-merge") || has("rebase-apply") {
            Some(Operation::Rebase)
        } else if has("CHERRY_PICK_HEAD") {
            Some(Operation::CherryPick)
        } else if has("REVERT_HEAD") {
            Some(Operation::Revert)
        } else {
            None
        }
    }

    /// `user.name` and `user.email`, from any config level; None when either is unset.
    pub fn author(&self) -> Result<Option<(String, String)>, GitError> {
        let get = |key: &str| -> Result<Option<String>, GitError> {
            match self.text(&["config", "--get", key]) {
                Ok(v) if !v.trim().is_empty() => Ok(Some(v.trim().to_string())),
                Ok(_) => Ok(None),
                // Exit 1: the key isn't set.
                Err(e) if e.code == Some(1) => Ok(None),
                Err(e) => Err(e),
            }
        };
        Ok(match (get("user.name")?, get("user.email")?) {
            (Some(name), Some(email)) => Some((name, email)),
            _ => None,
        })
    }

    /// Writes both to the global config.
    pub fn set_author(program: &str, name: &str, email: &str) -> Result<(), GitError> {
        run_in(program, Path::new("."), &["config", "--global", "user.name", name])?;
        run_in(program, Path::new("."), &["config", "--global", "user.email", email])?;
        Ok(())
    }

    /// `git add -A -- paths`: new, changed and deleted files alike.
    pub fn stage(&self, paths: &[&str]) -> Result<(), GitError> {
        let mut args = vec!["add", "-A", "--"];
        args.extend_from_slice(paths);
        self.run(&args).map(drop)
    }

    /// `git reset -q -- paths`: works before the first commit, where `restore --staged` doesn't.
    pub fn unstage(&self, paths: &[&str]) -> Result<(), GitError> {
        let mut args = vec!["reset", "-q", "--"];
        args.extend_from_slice(paths);
        self.run(&args).map(drop)
    }

    /// Throws away unstaged changes: tracked files go back to the index, untracked ones are
    /// deleted.
    pub fn discard(&self, entries: &[&Entry]) -> Result<(), GitError> {
        let tracked: Vec<&str> = entries
            .iter()
            .filter(|e| e.unstaged != Some(Change::Untracked))
            .map(|e| e.path.as_str())
            .collect();
        if !tracked.is_empty() {
            let mut args = vec!["restore", "--worktree", "--"];
            args.extend_from_slice(&tracked);
            self.run(&args)?;
        }
        for e in entries.iter().filter(|e| e.unstaged == Some(Change::Untracked)) {
            // -uall lists files, never folders.
            std::fs::remove_file(self.root.join(&e.path)).map_err(|err| GitError {
                command: format!("rm {}", e.path),
                code: None,
                stderr: err.to_string(),
                missing: false,
            })?;
        }
        Ok(())
    }

    /// Appends `path` as a line of the root's .gitignore (made if missing).
    pub fn ignore(&self, path: &str) -> io::Result<()> {
        let file = self.root.join(".gitignore");
        let mut text = std::fs::read_to_string(&file).unwrap_or_default();
        if !text.is_empty() && !text.ends_with('\n') {
            text.push('\n');
        }
        text.push_str(path);
        text.push('\n');
        std::fs::write(file, text)
    }

    /// The entry's diff as `git diff` prints it: the index against HEAD for `staged`, else the
    /// working tree against the index. An untracked file is shown whole as added, a binary
    /// one says "Binary file".
    pub fn diff(&self, entry: &Entry, staged: bool) -> Result<String, GitError> {
        if entry.unstaged == Some(Change::Untracked) {
            let bytes = std::fs::read(self.root.join(&entry.path)).unwrap_or_default();
            if bytes.iter().take(8 * 1024).any(|b| *b == 0) {
                return Ok("Binary file".to_string());
            }
            let text = String::from_utf8_lossy(&bytes);
            let lines: Vec<&str> = text.lines().collect();
            let mut out = format!("+++ b/{}\n@@ -0,0 +1,{} @@\n", entry.path, lines.len());
            for line in lines {
                out.push('+');
                out.push_str(line);
                out.push('\n');
            }
            return Ok(out);
        }
        let mut args = vec!["diff", "--no-color", "-M"];
        if staged {
            args.push("--cached");
        }
        args.push("--");
        if let Some(from) = &entry.from {
            args.push(from);
        }
        args.push(&entry.path);
        self.text(&args)
    }

    /// `git commit -m message` (`--amend` with `amend`): the new commit's short hash.
    pub fn commit(&self, message: &str, amend: bool) -> Result<String, GitError> {
        let mut args = vec!["commit", "-q", "-m", message];
        if amend {
            args.push("--amend");
        }
        self.run(&args)?;
        Ok(self.text(&["rev-parse", "--short", "HEAD"])?.trim().to_string())
    }

    /// HEAD's full message, for Amend.
    pub fn last_message(&self) -> Result<String, GitError> {
        Ok(self.text(&["log", "-1", "--format=%B"])?.trim_end().to_string())
    }
}
```

```rust
/// A Git block's state: the folder, what it holds, and the last read.
pub(crate) struct Git {
    /// What the user chose; the repository's root may be above it.
    pub folder: PathBuf,
    pub found: Found,
    pub tab: Tab,
    pub status: Status,
    pub operation: Option<Operation>,
    /// `user.name` and `user.email`; None: not set, so Commit is disabled.
    pub author: Option<(String, String)>,
    /// A command runs in the background: reads wait, actions are disabled.
    pub busy: bool,
    /// A refresh was asked while busy: one runs when the command ends.
    pub pending: bool,
    /// Reads completed so far (the tests count them).
    pub reads: u64,
    /// Why the last read failed, shown under the top bar.
    pub error: Option<String>,
}

impl Git {
    pub fn new(folder: PathBuf, tab: Tab) -> Git {
        Git {
            folder,
            found: Found::Looking,
            tab,
            status: Status::default(),
            operation: None,
            author: None,
            busy: false,
            pending: false,
            reads: 0,
            error: None,
        }
    }

    pub fn repo(&self) -> Option<&Repo> {
        match &self.found {
            Found::Repo(repo) => Some(repo),
            _ => None,
        }
    }

    /// The repository's folder name, else the chosen folder's.
    pub fn name(&self) -> String {
        let dir = self.repo().map_or(&self.folder, |r| &r.root);
        dir.file_name().map_or_else(
            || dir.display().to_string(),
            |n| n.to_string_lossy().into_owned(),
        )
    }

    pub fn title(&self) -> SharedString {
        self.name().into()
    }

    pub fn item(&self, rect: Rect) -> session::GitItem {
        session::GitItem {
            rect: rect.into(),
            folder: self.folder.to_string_lossy().into_owned(),
            tab: self.tab.name().to_string(),
        }
    }
}
```

```rust
            move || Read::of(&repo),

                let Some(git) = ws.git_at(&at) else {
                    return;
                };
                git.reads += 1;
                match read {
                    Ok(read) => {
                        git.status = read.status;
                        git.operation = read.operation;
                        git.author = read.author;
                        git.error = None;
                    }
                    Err(e) => git.error = Some(e.to_string()),
                }
            },
            window,
            cx,
        );
    }

    /// Every git_block::POLL: reads the Git blocks in the viewport again.
    fn poll_git(&mut self, window: &mut Window, cx: &mut Context<Self>) {
        let vp = self.viewport(window);
        let due: Vec<BlockId> = self
            .space
            .canvas
            .visible_from(&self.space.view, vp)
            .map(|b| b.id)
            .filter(|id| self.space.git(*id).is_some_and(|g| g.repo().is_some()))
            .collect();
        for id in due {
            self.refresh_git(id, window, cx);
        }
    }

    /// The Git block `at` names, in whichever workspace it is.
    fn git_at(&mut self, at: &GitAt) -> Option<&mut Git> {
        self.space_by_id_mut(&at.space)?.git_mut(at.block)
    }

    /// Runs `job` on the background executor, the block marked busy meanwhile, then `done` on
    /// the UI thread with its result. A refresh asked while it ran follows, once. A block
    /// closed in the meantime gets nothing.
    fn git_job<T: Send + 'static>(
        &mut self,
        at: GitAt,
        job: impl FnOnce() -> T + Send + 'static,
        done: impl FnOnce(&mut Workspace, GitAt, T, &mut Window, &mut Context<Workspace>) + 'static,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(git) = self.git_at(&at) else {
            return;
        };
        git.busy = true;
        cx.notify();
        cx.spawn_in(window, async move |ws, cx| {
            let result = cx.background_executor().spawn(async move { job() }).await;
            ws.update_in(cx, |ws, window, cx| {
                if let Some(git) = ws.git_at(&at) {
                    git.busy = false;
                }
                done(ws, at.clone(), result, window, cx);
                let again = ws
                    .git_at(&at)
                    .is_some_and(|g| std::mem::take(&mut g.pending));
                if again {
                    ws.refresh_at(at, window, cx);
                }
                cx.notify();
            })
            .ok();
        })
        .detach();
    }
```

```rust
/// Which side of a conflict to keep.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Side {
    Ours,
    Theirs,
}

impl Repo {
    /// Takes one side of a conflicted file (it stays unresolved until staged).
    pub fn resolve(&self, path: &str, side: Side) -> Result<(), GitError> {
        let flag = match side {
            Side::Ours => "--ours",
            Side::Theirs => "--theirs",
        };
        self.run(&["checkout", flag, "--", path]).map(drop)
    }

    /// `git <operation> --abort`.
    pub fn abort(&self, op: Operation) -> Result<(), GitError> {
        self.run(&[op.name(), "--abort"]).map(drop)
    }

    /// `git <operation> --continue`; GIT_EDITOR=true keeps the prepared message.
    pub fn continue_(&self, op: Operation) -> Result<(), GitError> {
        self.run(&[op.name(), "--continue"]).map(drop)
    }
}
```

```rust
    /// Shows a row's diff on the right (read in the background).
    pub(crate) fn select_git_row(
        &mut self,
        id: BlockId,
        list: git_block::List,
        path: String,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        git.selected = Some((list, path));
        cx.notify();
        self.reload_git_diff(id, window, cx);
    }

    /// Reads the selected row's diff again; clears it when the row is gone.
    pub(crate) fn reload_git_diff(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        let Some(repo) = git.repo().cloned() else {
            return;
        };
        let Some(entry) = git.selected_entry().cloned() else {
            git.selected = None;
            git.diff_line = None;
            git.diff.update(cx, |d, cx| d.set_value("", window, cx));
            return;
        };
        let staged = git.selected.as_ref().is_some_and(|s| s.0 == git_block::List::Staged);
        let at = GitAt { space: self.space.id.clone(), block: id };
        self.git_job(
            at,
            move || repo.diff(&entry, staged),
            |ws, at, diff, window, cx| {
                let Some(git) = ws.git_at(&at) else {
                    return;
                };
                let text = match diff {
                    Ok(text) => text,
                    Err(e) => e.to_string(),
                };
                git.diff_line = templum_git::first_hunk_line(&text);
                let view = git.diff.clone();
                view.update(cx, |d, cx| d.set_value(text, window, cx));
            },
            window,
            cx,
        );
    }

    /// Runs `job` on the block's repository in the background; its failure is a notification,
    /// and the block is read again either way.
    pub(crate) fn git_action(
        &mut self,
        id: BlockId,
        job: impl FnOnce(&Repo) -> Result<(), GitError> + Send + 'static,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(repo) = self.space.git(id).and_then(|g| g.repo().cloned()) else {
            return;
        };
        let at = GitAt { space: self.space.id.clone(), block: id };
        self.git_job(
            at,
            move || job(&repo),
            |ws, at, result, window, cx| {
                if let Err(e) = result {
                    notify_git_error(window, cx, &e);
                }
                ws.refresh_at(at, window, cx);
            },
            window,
            cx,
        );
    }

    pub(crate) fn stage(&mut self, id: BlockId, paths: Vec<String>, window: &mut Window, cx: &mut Context<Self>) {
        self.git_action(id, move |repo| repo.stage(&refs(&paths)), window, cx);
    }

    pub(crate) fn unstage(&mut self, id: BlockId, paths: Vec<String>, window: &mut Window, cx: &mut Context<Self>) {
        self.git_action(id, move |repo| repo.unstage(&refs(&paths)), window, cx);
    }

    /// Asks, then throws the unstaged changes of `paths` away.
    pub(crate) fn discard(&mut self, id: BlockId, paths: Vec<String>, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git(id) else {
            return;
        };
        let entries: Vec<Entry> = git
            .status
            .unstaged()
            .into_iter()
            .filter(|e| paths.contains(&e.path))
            .cloned()
            .collect();
        if entries.is_empty() {
            return;
        }
        let what = match entries.as_slice() {
            [one] => format!("Discard the changes to {}?", one.path),
            many => format!("Discard the changes to {} files?", many.len()),
        };
        let ws = cx.entity();
        prompt::confirm(
            what,
            "Untracked files are deleted. This can't be undone.",
            "Discard",
            move |window, cx| {
                let entries = entries.clone();
                ws.update(cx, |ws, cx| {
                    ws.git_action(
                        id,
                        move |repo| repo.discard(&entries.iter().collect::<Vec<_>>()),
                        window,
                        cx,
                    )
                })
            },
            window,
            cx,
        );
    }

    /// Appends the path to the repository's .gitignore.
    pub(crate) fn ignore_path(&mut self, id: BlockId, path: String, window: &mut Window, cx: &mut Context<Self>) {
        self.git_action(
            id,
            move |repo| {
                repo.ignore(&path).map_err(|e| GitError {
                    command: format!("ignore {path}"),
                    code: None,
                    stderr: e.to_string(),
                    missing: false,
                })
            },
            window,
            cx,
        );
    }

    pub(crate) fn resolve(&mut self, id: BlockId, path: String, side: templum_git::Side, window: &mut Window, cx: &mut Context<Self>) {
        self.git_action(id, move |repo| repo.resolve(&path, side), window, cx);
    }

    pub(crate) fn abort_operation(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let Some(op) = self.space.git(id).and_then(|g| g.operation) else {
            return;
        };
        self.git_action(id, move |repo| repo.abort(op), window, cx);
    }

    pub(crate) fn continue_operation(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let Some(op) = self.space.git(id).and_then(|g| g.operation) else {
            return;
        };
        self.git_action(id, move |repo| repo.continue_(op), window, cx);
    }

    /// Opens a repository path in an editor beside the Git block, at the shown diff's first hunk
    /// when it is the selected row.
    pub(crate) fn open_from_git(&mut self, id: BlockId, path: &str, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git(id) else {
            return;
        };
        let Some(root) = git.repo().map(|r| r.root.clone()) else {
            return;
        };
        let line = git
            .selected
            .as_ref()
            .filter(|s| s.1 == path)
            .and_then(|_| git.diff_line);
        self.open_in_editor(&root, &root.join(path), line, Some(id), window, cx);
    }
```

```rust
    /// Commits what is staged with the form's message; "Committed abc1234" and the fields
    /// clear.
    pub(crate) fn git_commit(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git(id) else {
            return;
        };
        if !git.can_commit(cx) {
            return;
        }
        let (message, amend) = (git.message(cx), git.amend);
        let Some(repo) = git.repo().cloned() else {
            return;
        };
        let at = GitAt { space: self.space.id.clone(), block: id };
        self.git_job(
            at,
            move || repo.commit(&message, amend),
            |ws, at, result, window, cx| {
                match result {
                    Ok(short) => {
                        if let Some(git) = ws.git_at(&at) {
                            git.amend = false;
                            let (summary, description) = (git.summary.clone(), git.description.clone());
                            summary.update(cx, |s, cx| s.set_value("", window, cx));
                            description.update(cx, |d, cx| d.set_value("", window, cx));
                        }
                        show_notification(window, cx, Notification::success(format!("Committed {short}")));
                    }
                    Err(e) => notify_git_error(window, cx, &e),
                }
                ws.refresh_at(at, window, cx);
            },
            window,
            cx,
        );
    }

    /// Ctrl+Enter in a block's summary or description.
    pub(crate) fn commit_from(&mut self, field: gpui_kit::EntityId, window: &mut Window, cx: &mut Context<Self>) {
        let Some(id) = self.space.blocks.iter().find_map(|(id, b)| b.git().filter(|g| g.owns_field(field)).map(|_| *id)) else {
            return;
        };
        self.git_commit(id, window, cx);
    }

    /// Amend on: the fields show the last commit's message; off: they clear.
    pub(crate) fn set_amend(&mut self, id: BlockId, on: bool, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        git.amend = on;
        cx.notify();
        let (summary, description) = (git.summary.clone(), git.description.clone());
        if !on {
            summary.update(cx, |s, cx| s.set_value("", window, cx));
            description.update(cx, |d, cx| d.set_value("", window, cx));
            return;
        }
        let Some(repo) = git.repo().cloned() else {
            return;
        };
        let at = GitAt { space: self.space.id.clone(), block: id };
        self.git_job(
            at,
            move || repo.last_message(),
            move |_, _, message, window, cx| {
                let Ok(message) = message else {
                    return;
                };
                let (first, rest) = message.split_once('\n').unwrap_or((&message, ""));
                summary.update(cx, |s, cx| s.set_value(first.to_string(), window, cx));
                description.update(cx, |d, cx| d.set_value(rest.trim().to_string(), window, cx));
            },
            window,
            cx,
        );
    }

    pub(crate) fn set_git_author(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let ws = cx.entity();

                                    cx,
                                )
                            });
                            true
                        },
                        window,
                        cx,
                    );
                });
                true
            },

            cx,
```

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Pull {
    FastForward,
    Merge,
    Rebase,
}

impl Repo {
    pub fn fetch(&self) -> Result<(), GitError> {
        self.run(&["fetch", "--prune"]).map(drop)
    }

    pub fn pull(&self, how: Pull) -> Result<(), GitError> {
        let flag = match how {
            Pull::FastForward => "--ff-only",
            Pull::Merge => "--no-rebase",
            Pull::Rebase => "--rebase",
        };
        self.run(&["pull", flag]).map(drop)
    }

    pub fn push(&self, publish: Option<&str>) -> Result<(), GitError> {
        match publish {
            Some(branch) => self.run(&["push", "-u", "origin", branch]).map(drop),
            None => self.run(&["push"]).map(drop),
```

```rust
    /// Runs one of fetch, pull and push, its button spinning meanwhile.
    fn git_sync(
        &mut self,
        id: BlockId,
        which: git_block::Sync,
        job: impl FnOnce(&Repo) -> Result<(), GitError> + Send + 'static,
        on_err: impl FnOnce(&mut Workspace, BlockId, &GitError, &mut Window, &mut Context<Workspace>)
        + 'static,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        if git.busy {
            return;
        }
        let Some(repo) = git.repo().cloned() else {
            return;
        };
        git.sync = Some(which);
        let at = GitAt {
            space: self.space.id.clone(),
            block: id,
        };
        self.git_job(
            at,
            move || job(&repo),
            move |ws, at, result, window, cx| {
                if let Some(git) = ws.git_at(&at) {
                    git.sync = None;
                }
                if let Err(e) = result {
                    on_err(ws, at.block, &e, window, cx);
                }
                ws.refresh_at(at, window, cx);
            },
            window,
            cx,
        );
    }

    pub(crate) fn fetch(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        self.git_sync(
            id,
            git_block::Sync::Fetch,
            |repo| repo.fetch(),
            |_, block, e, window, cx| {
                let ws = cx.entity();
                notify_git_error(&ws, block, e, Vec::new(), window, cx)
            },
            window,
            cx,
        );
    }

    /// `--ff-only`; when that isn't possible, the notification offers Merge and Rebase.
    pub(crate) fn pull(
        &mut self,
        id: BlockId,
        how: templum_git::Pull,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        use templum_git::Pull;
        self.git_sync(
            id,
            git_block::Sync::Pull,
            move |repo| repo.pull(how),
            move |_, block, e, window, cx| {
                let ws = cx.entity();
                let mut extra: Vec<Extra> = Vec::new();
                if how == Pull::FastForward && templum_git::not_fast_forward(&e.stderr) {
                    extra.push((
                        "git-pull-merge",
                        "Merge",
                        Rc::new(move |ws, window, cx| ws.pull(block, Pull::Merge, window, cx)),
                    ));
                    extra.push((
                        "git-pull-rebase",
                        "Rebase",
                        Rc::new(move |ws, window, cx| ws.pull(block, Pull::Rebase, window, cx)),
                    ));
                }
                notify_git_error(&ws, block, e, extra, window, cx);
            },
            window,
            cx,
        );
    }

    /// `git push`; a branch with no upstream asks, then `git push -u origin <branch>`.
    pub(crate) fn push(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git(id) else {
            return;
        };
        let publish = match (&git.status.upstream, &git.status.branch) {
            (None, Some(branch)) => Some(branch.clone()),
            _ => None,
        };
        let Some(branch) = publish else {
            self.push_now(id, None, window, cx);
            return;
        };
        let ws = cx.entity();
        prompt::confirm(
            format!("Publish {branch}?"),
            format!("git push -u origin {branch}"),
            "Push",
            move |window, cx| {
                let branch = branch.clone();
                ws.update(cx, |ws, cx| ws.push_now(id, Some(branch), window, cx))
            },
            window,
            cx,
        );
    }

    fn push_now(
        &mut self,
        id: BlockId,
        publish: Option<String>,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        self.git_sync(
            id,
            git_block::Sync::Push,
            move |repo| repo.push(publish.as_deref()),
            |_, block, e, window, cx| {
                let ws = cx.entity();
                notify_git_error(&ws, block, e, Vec::new(), window, cx)
            },
            window,
            cx,
        );
    }
```

```rust
    /// first commit: none.
    pub fn log(&self, skip: usize, count: usize) -> Result<Vec<Commit>, GitError> {
        let format = format!("--format={}", parse::LOG_FORMAT);
        let date = format!("--date={}", parse::LOG_DATE);
        let skip = format!("--skip={skip}");
        let count = format!("-n{count}");
        match self.run(&["log", "-z", &format, &date, &skip, &count]) {
            Ok(out) => Ok(parse::parse_log(&out)),
            Err(e) if e.stderr.contains("does not have any commits") => Ok(Vec::new()),
            Err(e) => Err(e),
        }
    }

    pub fn commit_files(&self, hash: &str) -> Result<Vec<CommitFile>, GitError> {
        let out = self.run(&[
            "diff-tree", "--root", "--no-commit-id", "-r", "-z", "-M", "--name-status", hash,
        ])?;
        Ok(parse::parse_name_status(&out))
    }

    pub fn commit_diff(&self, hash: &str, file: &CommitFile) -> Result<String, GitError> {
        let mut args = vec![
            "diff-tree", "--root", "--no-commit-id", "-p", "-M", "--no-color", hash, "--",
        ];
        if let Some(from) = &file.from {
            args.push(from);
        }
        args.push(&file.path);
        self.text(&args)
    }
```

```rust
    /// The Git block `id` of the workspace on screen (the History list's closure builds it too).
    pub(crate) fn here(&self, id: BlockId) -> GitAt {
        GitAt {
            space: self.space.id.clone(),
            block: id,
        }
    }

    /// After a command: the status now, and the shown tab's list once the status is in.
    fn after_action(&mut self, at: GitAt, window: &mut Window, cx: &mut Context<Self>) {
        if let Some(git) = self.git_at(&at) {
            git.pending_lists = true;
        }
        self.refresh_at(at, window, cx);
    }

    /// Reads the list behind the shown tab (History, Branches or Stashes) in the background.
    fn refresh_lists_at(&mut self, at: GitAt, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.git_at(&at) else {
            return;
        };
        if git.busy {
            git.pending_lists = true;
            return;
        }
        match git.tab {
            git_block::Tab::Changes => {}
            git_block::Tab::History => self.load_history(at, 0, window, cx),
            // Tasks 8 and 9.
            git_block::Tab::Branches | git_block::Tab::Stashes => {}
        }
    }

    /// Loads a page of History: the first page replaces the list, a later one extends it.
    pub(crate) fn load_history(&mut self, at: GitAt, skip: usize, window: &mut Window, cx: &mut Context<Self>) {
        let Some(repo) = self.git_at(&at).and_then(|g| g.repo().cloned()) else {
            return;
        };
        self.git_job(
            at,
            move || repo.log(skip, git_block::PAGE),
            move |ws, at, log, _, _| {
                let Some(git) = ws.git_at(&at) else {
                    return;
                };
                match log {
                    Ok(page) => {
                        git.more = page.len() == git_block::PAGE;
                        let mut all = if skip == 0 { Vec::new() } else { (*git.commits).clone() };
                        all.extend(page);
                        git.commits = Rc::new(all);
                        git.error = None;
                    }
                    Err(e) => git.error = Some(e.to_string()),
                }
            },
            window,
            cx,
        );
    }

    /// Shows a commit's message and files on the right of History.
    pub(crate) fn show_commit(&mut self, id: BlockId, hash: String, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git(id) else {
            return;
        };
        let Some(commit) = git.commits.iter().find(|c| c.hash == hash).cloned() else {
            return;
        };
        let Some(repo) = git.repo().cloned() else {
            return;
        };
        let files_of = hash.clone();
        self.git_job(
            self.here(id),
            move || repo.commit_files(&files_of),
            move |ws, at, files, window, cx| {
                let Some(git) = ws.git_at(&at) else {
                    return;
                };

                    Ok(files) => {
                        git.shown = Some(git_block::Shown { commit, files, file: None });

                        view.update(cx, |d, cx| d.set_value("", window, cx));
                    }
                    Err(e) => git.error = Some(e.to_string()),
                }
            },
            window,
            cx,
        );
    }
```

```rust
    let names: Vec<_> = b.iter().map(|b| (b.name.as_str(), b.remote, b.current)).collect();
    assert_eq!(names, [("feat", false, true), ("main", false, false), ("origin/main", true, false)]);

    assert_eq!(b[0].subject, "b");

    assert_eq!(repo.status().unwrap().branch.as_deref(), Some("main"));

    repo.checkout("feature").unwrap();
    write(dir.path(), "b.txt", "changed\n");

    write(dir.path(), "a.txt", "changed\n");

    repo.stage(&["a.txt"]).unwrap();
    repo.commit("other a", false).unwrap();
    repo.checkout("main").unwrap();
    write(dir.path(), "a.txt", "dirty\n");
    let err = repo.checkout("other").unwrap_err();

    repo.stash_push("Templum: before switching", true).unwrap();
```

```rust
    /// Local and remote branches, sorted as git lists them (local first).
    pub fn branches(&self) -> Result<Vec<Branch>, GitError> {
        let format = format!("--format={}", parse::BRANCH_FORMAT);
        let out = self.run(&["for-each-ref", &format, "refs/heads", "refs/remotes"])?;
        Ok(parse::parse_branches(&out))
    }

    pub fn checkout(&self, name: &str) -> Result<(), GitError> {
        self.run(&["checkout", "-q", name]).map(drop)
    }

    /// "origin/x": a local x tracking it, checked out.
    pub fn checkout_remote(&self, name: &str) -> Result<(), GitError> {
        self.run(&["checkout", "-q", "--track", name]).map(drop)
    }

    pub fn rename_branch(&self, from: &str, to: &str) -> Result<(), GitError> {
        self.check_ref_format(to)?;
        self.run(&["branch", "-m", from, to]).map(drop)
    }

    /// Merges `name` into the current branch.
    pub fn merge(&self, name: &str) -> Result<(), GitError> {
        self.run(&["merge", "--no-edit", name]).map(drop)
    }

    pub fn delete_branch(&self, name: &str, force: bool) -> Result<(), GitError> {
        self.run(&["branch", if force { "-D" } else { "-d" }, name]).map(drop)
    }

    /// `git stash push -m message`, with untracked files when asked.
    pub fn stash_push(&self, message: &str, untracked: bool) -> Result<(), GitError> {
        let mut args = vec!["stash", "push", "-q", "-m", message];
        if untracked {
            args.push("-u");
        }
        self.run(&args).map(drop)
    }
```

```rust
    pub(crate) fn load_branches(&mut self, at: GitAt, window: &mut Window, cx: &mut Context<Self>) {
        let Some(repo) = self.git_at(&at).and_then(|g| g.repo().cloned()) else {
            return;
        };
        self.git_job(
            at,
            move || repo.branches(),
            |ws, at, branches, _, _| {
                let Some(git) = ws.git_at(&at) else {
                    return;
                };
                match branches {
                    Ok(b) => git.branches = b,
                    Err(e) => git.error = Some(e.to_string()),
                }
            },
            window,
            cx,
        );
    }

    /// Checks a branch out; one git refuses for local changes offers Stash and switch.
    pub(crate) fn checkout_branch(&mut self, id: BlockId, name: String, remote: bool, window: &mut Window, cx: &mut Context<Self>) {
        let Some(repo) = self.space.git(id).and_then(|g| g.repo().cloned()) else {
            return;
        };
        let job_name = name.clone();
        self.git_job(
            self.here(id),
            move || if remote { repo.checkout_remote(&job_name) } else { repo.checkout(&job_name) },
            move |ws, at, result, window, cx| {
                if let Err(e) = result {
                    let entity = cx.entity();
                    let block = at.block;
                    let mut extra: Vec<Extra> = Vec::new();
                    if e.stderr.contains("would be overwritten") || e.stderr.contains("local changes") {
                        let name = name.clone();
                        extra.push((
                            "git-stash-switch",
                            "Stash and switch",
                            Rc::new(move |ws, window, cx| ws.stash_and_switch(block, name.clone(), remote, window, cx)),
                        ));
                    }
                    notify_git_error(&entity, at.block, &e, extra, window, cx);
                }
                ws.after_action(at, window, cx);
            },
            window,
            cx,
        );
    }

    /// Stashes everything (untracked files too), then checks the branch out.
    pub(crate) fn stash_and_switch(&mut self, id: BlockId, name: String, remote: bool, window: &mut Window, cx: &mut Context<Self>) {
        self.git_action(
            id,
            move |repo| {
                repo.stash_push(&format!("Templum: before switching to {name}"), true)?;
                if remote { repo.checkout_remote(&name) } else { repo.checkout(&name) }
            },
            window,
            cx,
        );
    }

    pub(crate) fn rename_branch(&mut self, id: BlockId, name: String, window: &mut Window, cx: &mut Context<Self>) {
        let ws = cx.entity();
        let from = name.clone();
        prompt::ask_text(
            "Rename branch",
            "Rename",
            name,
            move |to, window, cx| {
                let to = to.trim().to_string();
                if to.is_empty() || to == from {
                    return false;
                }
                let from = from.clone();
                ws.update(cx, |ws, cx| ws.git_action(id, move |repo| repo.rename_branch(&from, &to), window, cx));
                true
            },
            window,
            cx,
        );
    }

    /// Merges `name` into the current branch, after asking.
    pub(crate) fn merge_branch(&mut self, id: BlockId, name: String, window: &mut Window, cx: &mut Context<Self>) {
        let current = self.space.git(id).and_then(|g| g.status.branch.clone()).unwrap_or_else(|| "HEAD".to_string());
        let ws = cx.entity();
        prompt::confirm(
            format!("Merge {name} into {current}?"),
            "Conflicts, if any, show in the Changes tab.",
            "Merge",
            move |window, cx| {
                let name = name.clone();
                ws.update(cx, |ws, cx| ws.git_action(id, move |repo| repo.merge(&name), window, cx))
            },
            window,
            cx,
        );
    }

    /// Deletes a local branch after asking; an unmerged one asks again, to force.
    pub(crate) fn delete_branch(&mut self, id: BlockId, name: String, force: bool, window: &mut Window, cx: &mut Context<Self>) {
        if force {
            self.delete_now(id, name, true, window, cx);
            return;
        }
        let ws = cx.entity();
        prompt::confirm(
            format!("Delete {name}?"),
            "Its commits stay in the history while something points at them.",
            "Delete",
            move |window, cx| {
                let name = name.clone();
                ws.update(cx, |ws, cx| ws.delete_now(id, name, false, window, cx))
            },
            window,
            cx,
        );
    }

    fn delete_now(&mut self, id: BlockId, name: String, force: bool, window: &mut Window, cx: &mut Context<Self>) {
        let Some(repo) = self.space.git(id).and_then(|g| g.repo().cloned()) else {
            return;
        };
        let job_name = name.clone();
        self.git_job(
            self.here(id),
            move || repo.delete_branch(&job_name, force),
            move |ws, at, result, window, cx| {
                if let Err(e) = result {
                    let entity = cx.entity();
                    let block = at.block;
                    let mut extra: Vec<Extra> = Vec::new();
                    if !force && templum_git::not_merged(&e.stderr) {
                        let name = name.clone();
                        extra.push((
                            "git-delete-force",
                            "Delete anyway",
                            Rc::new(move |ws, window, cx| {
                                ws.delete_branch(block, name.clone(), true, window, cx)
                            }),
                        ));
                    }
                    notify_git_error(&entity, at.block, &e, extra, window, cx);
                }
                ws.after_action(at, window, cx);
            },
            window,
            cx,
        );
    }

    /// `git push -u origin <name>` for a local branch with no upstream.
    pub(crate) fn publish_branch(&mut self, id: BlockId, name: String, window: &mut Window, cx: &mut Context<Self>) {
        self.push_now(id, Some(name), window, cx);
    }
```

```rust
    pub(crate) fn load_stashes(&mut self, at: GitAt, window: &mut Window, cx: &mut Context<Self>) {
        let Some(repo) = self.git_at(&at).and_then(|g| g.repo().cloned()) else {
            return;
        };
        self.git_job(
            at,
            move || repo.stashes(),
            |ws, at, stashes, _, _| {
                let Some(git) = ws.git_at(&at) else {
                    return;
                };
                match stashes {
                    Ok(s) => {
                        if git.stash_shown.is_some_and(|i| !s.iter().any(|st| st.index == i)) {
                            git.stash_shown = None;
                        }
                        git.stashes = s;
                    }
                    Err(e) => git.error = Some(e.to_string()),
                }
            },
            window,
            cx,
        );
    }

    /// Stash changes…: a message and whether untracked files go too.
    pub(crate) fn stash_changes(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let ws = cx.entity();
        prompt::ask_text_and_flag(
            "Stash changes",
            "Stash",
            "Message",
            "Include untracked files",
            move |message, untracked, window, cx| {
                let message = message.trim().to_string();
                if message.is_empty() {
                    return false;
                }
                ws.update(cx, |ws, cx| ws.git_action(id, move |repo| repo.stash_push(&message, untracked), window, cx));
                true
            },
            window,
            cx,
        );
    }

    /// Apply (or Pop: apply and drop) a stash.
    pub(crate) fn stash_apply(&mut self, id: BlockId, index: usize, pop: bool, window: &mut Window, cx: &mut Context<Self>) {
        self.git_action(
            id,
            move |repo| if pop { repo.stash_pop(index) } else { repo.stash_apply(index) },
            window,
            cx,
        );
    }

    pub(crate) fn stash_drop(&mut self, id: BlockId, index: usize, window: &mut Window, cx: &mut Context<Self>) {
        let ws = cx.entity();
        prompt::confirm(
            "Drop this stash?",
            "Its changes are lost. This can't be undone.",
            "Drop",
            move |window, cx| ws.update(cx, |ws, cx| ws.git_action(id, move |repo| repo.stash_drop(index), window, cx)),
            window,
            cx,
        );
    }

    /// Shows a stash's diff on the right.
    pub(crate) fn show_stash(&mut self, id: BlockId, index: usize, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        git.stash_shown = Some(index);
        let Some(repo) = git.repo().cloned() else {
            return;
        };
        self.git_job(
            self.here(id),
            move || repo.stash_show(index),
            |ws, at, diff, window, cx| {
                let Some(git) = ws.git_at(&at) else {
                    return;
                };
                let text = diff.unwrap_or_else(|e| e.to_string());
                let view = git.diff.clone();
                view.update(cx, |d, cx| d.set_value(text, window, cx));
            },
            window,
            cx,
        );
    }
```
