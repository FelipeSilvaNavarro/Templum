# Drawing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pen and highlighter strokes, lines, arrows, rectangles and ellipses drawn on the canvas with the toolbar's drawing tools, erased, selected, moved, deleted and undone, saved with the canvas and drawn above the blocks.

**Architecture:** The model is pure, in `templum-canvas`'s `ink.rs` (`Drawing`, hit-testing, bounds, moving, the Shift constraint). The app keeps `Space::ink: Vec<Drawing>` next to the blocks, paints it in one `canvas()` layer above the blocks with GPUI's `PathBuilder` and `paint_path`, and reads the pointer through a layer like the hand's while a drawing tool is on. The file gets an `"ink"` list in `session.rs`. The toolbar gets its third group and a second pill with the stroke options.

**Tech Stack:** Rust 1.98, GPUI through `gpui-kit =0.7.1` (`PathBuilder`, `paint_path`, `outline`), `lyon_tessellation` 1.0 (already in the tree through GPUI) for round caps and joins, `serde_json`.

**Spec:** `docs/specs/cockpit.md`, section 4 (Drawing) and the Drawing group of section 3 (the toolbar). Plan 1 (`docs/plans/2026-10-11-canvas-foundations.md`) is merged: `Space::blocks`, `Tool`, `toolbar.rs` and `Target::Agents` exist.

## Global Constraints

- Only `crates/templum` depends on `gpui-kit`; `templum-canvas` stays free of GPUI and serde.
- `gpui-kit` stays pinned `=0.7.1`.
- **One dependency line is added**, `lyon_tessellation = "1"` in `crates/templum/Cargo.toml`: it is already compiled in the tree (GPUI's `lyon`), MIT OR Apache-2.0, and only its `LineCap` and `LineJoin` are named, because GPUI re-exports `StrokeOptions` but not those two enums. The spec's "no new dependency" means no new crate enters the tree; this follows the "Already in the tree" convention of the other dependency lines. Record it as a ruling if the executor disagrees.
- No `unsafe`. Every logic change ships a test that fails without it; UI changes get a headless `#[gpui_kit::test]`.
- Commits go on `development`, titled with an imperative sentence (AGENTS.md).
- Before every commit: `cargo fmt --all && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`.
- Tasks 3 and 6 change painting: `cargo run --release -p templum -- --bench` with `p95_ms` ≤ 16.7, the JSON line in the commit message. Task 6 puts 200 strokes of 50 points on the bench's canvas, and the bar must still hold.
- Exact values: points closer than **1.5** world units to the previous one are skipped; hit tolerance **6 / zoom** world units plus half the width; widths thin **2**, medium **4**, thick **8**, highlighter **16** at **35 %** opacity; a drawn width is never under **1 px** on screen; arrow head **max(10, 4 × width)** long at **30°**; selection outline **1 px** accent with **4 / zoom** padding; undo keeps **50** steps; a stroke under 2 points or a shape under 2 world units is dropped; widths in a file are clamped to **1 … 64**.
- Colors by name: `foreground`, `red`, `yellow`, `green`, `cyan`, `blue`, `magenta`, resolved from the theme's palette (foreground, ANSI 1, 3, 2, 6, 4, 5).
- GPUI lessons in `docs/adr/0002-ui-framework.md` apply; read the pinned sources, never guess.

    Red,
    Yellow,
    Green,
    Cyan,
    Blue,
    Magenta,
}

impl Color {

        Color::Foreground,
        Color::Red,
        Color::Yellow,
        Color::Green,
        Color::Cyan,
        Color::Blue,
        Color::Magenta,
    ];

    pub fn name(self) -> &'static str {
        match self {
            Color::Foreground => "foreground",
            Color::Red => "red",
            Color::Yellow => "yellow",
            Color::Green => "green",

            Color::Magenta => "magenta",
        }
    }

        Self::ALL.into_iter().find(|c| c.name() == name)
    }

    Ellipse,

/// A stroke (pen or highlighter) or a shape, in world units.
#[derive(Clone, Debug, PartialEq)]
pub enum Drawing {
    Stroke {
        points: Vec<Point>,
        width: f32,
        color: Color,
        highlight: bool,
    },
    Shape {
        kind: ShapeKind,
        from: Point,
        to: Point,
        width: f32,
        color: Color,
    },
}

/// A pen point closer than this to the previous one isn't kept.
pub const MIN_POINT_DISTANCE: f32 = 1.5;
/// How far (screen pixels) from the ink a click still hits it. The caller divides by the zoom.
pub const HIT_PX: f32 = 6.0;
pub const MIN_WIDTH: f32 = 1.0;
pub const MAX_WIDTH: f32 = 64.0;
/// A shape smaller than this on both sides is dropped when the drag ends.
pub const MIN_SHAPE: f32 = 2.0;

impl Drawing {
    /// Appends a point to a stroke, unless it is within [`MIN_POINT_DISTANCE`] of the last one.
    /// Shapes take no points.
    pub fn push_point(&mut self, p: Point) -> bool {
        let Drawing::Stroke { points, .. } = self else {
            return false;
        };
        if points
            .last()
            .is_some_and(|last| distance(*last, p) < MIN_POINT_DISTANCE)
        {
            return false;
        }
        points.push(p);
        true
    }

    /// Too small to keep: a stroke under 2 points, a shape under [`MIN_SHAPE`] both ways.
    pub fn is_empty(&self) -> bool {
        match self {
            Drawing::Stroke { points, .. } => points.len() < 2,
            Drawing::Shape { from, to, .. } => {
                (from.x - to.x).abs() < MIN_SHAPE && (from.y - to.y).abs() < MIN_SHAPE
            }
        }
    }

    pub fn width(&self) -> f32 {
        match self {
            Drawing::Stroke { width, .. } | Drawing::Shape { width, .. } => *width,
        }
    }

    pub fn color(&self) -> Color {
        match self {
            Drawing::Stroke { color, .. } | Drawing::Shape { color, .. } => *color,
        }
    }

    /// The box around the ink, half the width out from its points.
    pub fn bounds(&self) -> Rect {
        let (min, max) = match self {
            Drawing::Stroke { points, .. } => points.iter().fold(
                (Point::new(f32::MAX, f32::MAX), Point::new(f32::MIN, f32::MIN)),
                |(lo, hi), p| {
                    (
                        Point::new(lo.x.min(p.x), lo.y.min(p.y)),
                        Point::new(hi.x.max(p.x), hi.y.max(p.y)),
                    )
                },
            ),
            Drawing::Shape { from, to, .. } => (
                Point::new(from.x.min(to.x), from.y.min(to.y)),
                Point::new(from.x.max(to.x), from.y.max(to.y)),
            ),
        };
        let pad = self.width() / 2.0;
        Rect::new(
            min.x - pad,
            min.y - pad,
            max.x - min.x + 2.0 * pad,
            max.y - min.y + 2.0 * pad,
        )
    }

    /// True within `tolerance` plus half the width of the ink itself (a rectangle's edges, an
    /// ellipse's rim), never of the empty inside of a shape.
    pub fn hit(&self, p: Point, tolerance: f32) -> bool {
        let t = tolerance + self.width() / 2.0;
        match self {
            Drawing::Stroke { points, .. } => match points.as_slice() {
                [] => false,
                [only] => distance(*only, p) <= t,
                _ => points
                    .windows(2)
                    .any(|w| segment_distance(p, w[0], w[1]) <= t),
            },
            Drawing::Shape {
                kind: ShapeKind::Line | ShapeKind::Arrow,
                from,
                to,
                ..
            } => segment_distance(p, *from, *to) <= t,
            Drawing::Shape {
                kind: ShapeKind::Rect,
                from,
                to,
                ..
            } => {
                let (a, c) = (*from, *to);
                let b = Point::new(c.x, a.y);
                let d = Point::new(a.x, c.y);
                [(a, b), (b, c), (c, d), (d, a)]
                    .iter()
                    .any(|(s, e)| segment_distance(p, *s, *e) <= t)
            }
            Drawing::Shape {
                kind: ShapeKind::Ellipse,
                from,
                to,
                ..
            } => {
                let (rx, ry) = ((from.x - to.x).abs() / 2.0, (from.y - to.y).abs() / 2.0);
                let center = Point::new((from.x + to.x) / 2.0, (from.y + to.y) / 2.0);
                if rx <= t || ry <= t {
                    // Flat enough to be a line.
                    return segment_distance(p, *from, *to) <= t;
                }
                let (dx, dy) = ((p.x - center.x) / rx, (p.y - center.y) / ry);
                let r = (dx * dx + dy * dy).sqrt();
                (r - 1.0).abs() * rx.min(ry) <= t
            }
        }
    }

    pub fn move_by(&mut self, dx: f32, dy: f32) {
        match self {
            Drawing::Stroke { points, .. } => {
                for p in points {
                    p.x += dx;
                    p.y += dy;
                }
            }
            Drawing::Shape { from, to, .. } => {
                from.x += dx;
                from.y += dy;
                to.x += dx;
                to.y += dy;
            }
        }
    }
}

/// Where a shape's far corner goes with Shift held: lines and arrows snap to multiples of 45°,
/// rectangles and ellipses become squares and circles.
pub fn constrain(from: Point, to: Point, kind: ShapeKind) -> Point {
    let (dx, dy) = (to.x - from.x, to.y - from.y);
    match kind {
        ShapeKind::Line | ShapeKind::Arrow => {
            let len = (dx * dx + dy * dy).sqrt();
            if len == 0.0 {
                return to;
            }
            let step = std::f32::consts::FRAC_PI_4;
            let angle = (dy.atan2(dx) / step).round() * step;
            Point::new(from.x + len * angle.cos(), from.y + len * angle.sin())
        }
        ShapeKind::Rect | ShapeKind::Ellipse => {
            let side = dx.abs().max(dy.abs());
            Point::new(from.x + side * dx.signum(), from.y + side * dy.signum())
        }
    }
}

fn distance(a: Point, b: Point) -> f32 {
    ((a.x - b.x).powi(2) + (a.y - b.y).powi(2)).sqrt()
}

/// Distance from `p` to the segment `a`–`b`.
fn segment_distance(p: Point, a: Point, b: Point) -> f32 {
    let (abx, aby) = (b.x - a.x, b.y - a.y);
    let len2 = abx * abx + aby * aby;
    let t = if len2 == 0.0 {
        0.0
    } else {
        (((p.x - a.x) * abx + (p.y - a.y) * aby) / len2).clamp(0.0, 1.0)
    };
    distance(p, Point::new(a.x + t * abx, a.y + t * aby))
}

pub(crate) struct InkItem {
    pub kind: String,
    pub color: String,
    pub width: f32,
    #[serde(default, skip_serializing_if = "std::ops::Not::not")]
    pub highlight: bool,

    pub to: Option<[f32; 2]>,
}

impl InkItem {
    pub fn of(drawing: &Drawing) -> InkItem {
        let xy = |p: &Point| [p.x, p.y];
        match drawing {
            Drawing::Stroke {
                points,
                width,
                color,
                highlight,
            } => InkItem {
                kind: "stroke".into(),
                color: color.name().into(),
                width: *width,
                highlight: *highlight,
                points: points.iter().map(xy).collect(),
                from: None,
                to: None,
            },
            Drawing::Shape {
                kind,
                from,
                to,
                width,
                color,
            } => InkItem {
                kind: kind.name().into(),
                color: color.name().into(),
                width: *width,
                highlight: false,
                points: Vec::new(),
                from: Some(xy(from)),
                to: Some(xy(to)),
            },
        }
    }

    /// None for an unknown kind, a stroke under 2 points, a shape missing an end, or a number
    /// that isn't finite. An unknown color is the foreground; the width is clamped.
    pub fn drawing(&self) -> Option<Drawing> {
        let color = Color::from_name(&self.color).unwrap_or(Color::Foreground);
        if !self.width.is_finite() {
            return None;
        }
        let width = self.width.clamp(MIN_WIDTH, MAX_WIDTH);
        let point = |p: [f32; 2]| (p[0].is_finite() && p[1].is_finite()).then(|| Point::new(p[0], p[1]));
        if self.kind == "stroke" {
            let points = self.points.iter().map(|p| point(*p)).collect::<Option<Vec<_>>>()?;
            if points.len() < 2 {
                return None;
            }
            return Some(Drawing::Stroke {
                points,
                width,
                color,
                highlight: self.highlight,
            });
        }
        Some(Drawing::Shape {
            kind: ShapeKind::from_name(&self.kind)?,
            from: point(self.from?)?,
            to: point(self.to?)?,
            width,
            color,
        })
    }

/// Around a selected drawing's box, world units.
const SELECTION_PAD: f32 = 4.0;

/// A drawing's color in the theme; highlighters are translucent.
pub(crate) fn color_of(color: Color, theme: &Theme, highlight: bool) -> Hsla {
    let p = &theme.palette;
    let rgb = match color {
        Color::Foreground => p.foreground,
        Color::Red => p.ansi[1],
        Color::Yellow => p.ansi[3],
        Color::Green => p.ansi[2],
        Color::Cyan => p.ansi[6],
        Color::Blue => p.ansi[4],
        Color::Magenta => p.ansi[5],
    };

/// Whether any of the drawing is in the viewport (screen size), through `camera`.
pub(crate) fn visible(drawing: &Drawing, camera: &Camera, viewport: Size) -> bool {
    let z = camera.zoom();
    let world = Rect::new(camera.origin.x, camera.origin.y, viewport.w / z, viewport.h / z);
    drawing.bounds().intersects(&world)
}

/// Paints the drawings: highlighters first, then the rest, then the one being drawn, then the
/// selected one's outline. `bounds` is the layer's, in window coordinates.
#[allow(clippy::too_many_arguments)]
pub(crate) fn paint(
    drawings: &[Drawing],
    live: Option<&Drawing>,
    selected: Option<usize>,
    camera: &Camera,
    theme: &Theme,
    ui: Ui,
    bounds: Bounds<Pixels>,
    window: &mut Window,
) {
    let viewport = Size::new(f32::from(bounds.size.width), f32::from(bounds.size.height));
    let on_screen = |d: &&Drawing| visible(d, camera, viewport);
    let highlights = drawings.iter().filter(on_screen).filter(|d| is_highlight(d));
    let inks = drawings.iter().filter(on_screen).filter(|d| !is_highlight(d));
    for d in highlights.chain(inks).chain(live) {
        paint_one(d, camera, theme, bounds, window);
    }
    if let Some(d) = selected.and_then(|i| drawings.get(i)) {
        let z = camera.zoom();
        let b = d.bounds();
        let pad = SELECTION_PAD;
        let tl = to_screen(camera, bounds, Point::new(b.x - pad, b.y - pad));
        let br = to_screen(camera, bounds, Point::new(b.right() + pad, b.bottom() + pad));
        let rect = Bounds::new(tl, size(br.x - tl.x, br.y - tl.y));
        let _ = z;
        window.paint_quad(outline(rect, ui.accent, BorderStyle::Solid));
    }
}

fn is_highlight(d: &Drawing) -> bool {
    matches!(d, Drawing::Stroke { highlight: true, .. })
}

fn to_screen(camera: &Camera, bounds: Bounds<Pixels>, p: Point) -> gpui_kit::Point<Pixels> {
    let s = camera.to_screen(p);
    point(bounds.origin.x + px(s.x), bounds.origin.y + px(s.y))
}

fn paint_one(d: &Drawing, camera: &Camera, theme: &Theme, bounds: Bounds<Pixels>, window: &mut Window) {
    let z = camera.zoom();
    let width = px((d.width() * z).max(1.0));
    let at = |p: Point| to_screen(camera, bounds, p);
    let mut path = PathBuilder::default().with_style(PathStyle::Stroke(
        StrokeOptions::default()
            .with_line_width(f32::from(width))
            .with_line_cap(LineCap::Round)
            .with_line_join(LineJoin::Round),
    ));
    match d {
        Drawing::Stroke { points, .. } => {
            let Some(first) = points.first() else {
                return;
            };
            path.move_to(at(*first));
            // Smooth: quadratic curves through the midpoints, each point a control point.
            for w in points.windows(2).skip(1) {
                let (ctrl, next) = (w[0], w[1]);
                let mid = Point::new((ctrl.x + next.x) / 2.0, (ctrl.y + next.y) / 2.0);
                path.curve_to(at(mid), at(ctrl));
            }
            if let Some(last) = points.last().filter(|_| points.len() >= 2) {
                path.line_to(at(*last));
            }
        }
        Drawing::Shape {
            kind: ShapeKind::Line,
            from,
            to,
            ..
        } => {
            path.move_to(at(*from));
            path.line_to(at(*to));
        }
        Drawing::Shape {
            kind: ShapeKind::Arrow,
            from,
            to,
            width,
            ..
        } => {
            path.move_to(at(*from));
            path.line_to(at(*to));
            let (dx, dy) = (to.x - from.x, to.y - from.y);
            let len = (dx * dx + dy * dy).sqrt();
            if len > 0.0 {
                let head = (4.0 * width).max(10.0);
                let (ux, uy) = (dx / len, dy / len);
                let (s, c) = (30.0f32.to_radians().sin(), 30.0f32.to_radians().cos());
                for sign in [1.0, -1.0] {
                    // The unit vector rotated by ±30°, pointing back from the tip.
                    let rx = -(ux * c - uy * s * sign);
                    let ry = -(ux * s * sign + uy * c);
                    path.move_to(at(*to));
                    path.line_to(at(Point::new(to.x + rx * head, to.y + ry * head)));
                }
            }
        }
        Drawing::Shape {
            kind: ShapeKind::Rect,
            from,
            to,
            ..
        } => {
            let corners = [
                at(*from),
                at(Point::new(to.x, from.y)),
                at(*to),
                at(Point::new(from.x, to.y)),
            ];
            path.add_polygon(&corners, true);
        }
        Drawing::Shape {
            kind: ShapeKind::Ellipse,
            from,
            to,
            ..
        } => {
            let (cx, cy) = ((from.x + to.x) / 2.0, (from.y + to.y) / 2.0);
            let (rx, ry) = ((to.x - from.x).abs() / 2.0, (to.y - from.y).abs() / 2.0);
            const SIDES: usize = 48;
            let pts: Vec<_> = (0..SIDES)
                .map(|i| {
                    let a = i as f32 / SIDES as f32 * std::f32::consts::TAU;
                    at(Point::new(cx + rx * a.cos(), cy + ry * a.sin()))
                })
                .collect();
            path.add_polygon(&pts, true);
        }
    }
    if let Ok(path) = path.build() {
        window.paint_path(path, color_of(d.color(), theme, is_highlight(d)));
    }
}

       fn ink_at(&self, world: Point) -> Option<usize> {
           let tolerance = HIT_PX / self.space.canvas.camera.zoom();
           self.space.ink.iter().rposition(|d| d.hit(world, tolerance))
       }

       /// Before a change to the drawings: the current ones go on the undo stack.
       fn remember_ink(&mut self) {
           self.space.ink_undo.push(self.space.ink.clone());
           if self.space.ink_undo.len() > INK_UNDO {
               self.space.ink_undo.remove(0);
           }
           self.space.ink_redo.clear();
       }

       pub(crate) fn delete_ink(&mut self, index: usize, cx: &mut Context<Self>) {
           if index >= self.space.ink.len() {
               return;
           }
           self.remember_ink();
           self.space.ink.remove(index);
           self.space.selected_ink = None;
           cx.notify();
       }

       fn undo_ink(&mut self, cx: &mut Context<Self>) -> bool {
           let Some(previous) = self.space.ink_undo.pop() else {
               return false;
           };
           let current = std::mem::replace(&mut self.space.ink, previous);
           self.space.ink_redo.push(current);
           self.space.selected_ink = None;
           cx.notify();
           true
       }

       fn redo_ink(&mut self, cx: &mut Context<Self>) -> bool {
           let Some(next) = self.space.ink_redo.pop() else {
               return false;
           };
           let current = std::mem::replace(&mut self.space.ink, next);
           self.space.ink_undo.push(current);
           self.space.selected_ink = None;
           cx.notify();
           true
       }
