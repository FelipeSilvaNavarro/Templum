## Review Focus

1. **Leave them on main, then the switch fails** (the target branch was deleted in a terminal meanwhile, a file in
   the way): the changes come straight back to the working tree, staged ones staged, and nothing hides in a stash.
   Pinned in Task 2 (`a_switch_that_fails_after_leaving_brings_the_changes_back`).
2. **A conflict region chosen after the file was edited elsewhere** (the user fixed part of it in an editor, an
   agent rewrote it): the choice is refused with "The file changed; try again" and the file is left as it is; it
   never rewrites another region. Pinned in Task 13 (`a_region_changed_since_it_was_read_is_refused`).
3. **A branch whose upstream was deleted on the server** (merged and deleted on GitHub, then fetched with prune):
   the top bar never says "up to date"; it says "not published" and offers Publish branch. Pinned in Task 1
   (`a_gone_upstream_has_no_counts`) and Task 7 (`a_gone_upstream_offers_publish_not_sync`).
4. **A conflicted file with CRLF line endings, or with diff3 markers** (`merge.conflictStyle=diff3`, common in
   teams): the regions are found, the base part is never shown, and the chosen text keeps the file's line endings
   byte for byte. Pinned in Task 4 (`crlf_and_diff3_regions_resolve_byte_for_byte`).
5. **Compare open while the 2-second read runs** (an agent writing in the background): the comparison's panel is
   never replaced by the working changes, and the Changes panel keeps its own scroll and folds. Pinned in Task 12
   (`the_comparison_survives_the_two_second_read`).

Facts checked on git 2.55 while writing this plan (the tests pin them):

- `git stash push -m "templum: left on main"` on `main` lists as `On main: templum: left on main` (`%gs`).
- A branch whose upstream was deleted and pruned: `status --porcelain=v2 --branch` prints `# branch.upstream` and
  **no** `# branch.ab` line.
- git 2.48+ creates `refs/remotes/origin/HEAD` on fetch when it is missing (`remote.<name>.followRemoteHEAD`): a test
  "without origin/HEAD" deletes it (`git remote set-head origin -d`) and doesn't fetch after.
- Markers: `<<<<<<< HEAD` / `=======` / `>>>>>>> feature` in a merge; `>>>>>>> a6caaa4 (feat)` in a rebase;
  `||||||| 63b4097` before the base part with `merge.conflictStyle=diff3`. In a merge and in a rebase alike, the
  `<<<<<<<` part is what `git checkout --ours` takes.
- `git stash pop` that conflicts exits 1, leaves the file unmerged and keeps the stash.
- `git rev-list --count feat --not --exclude=feat --branches --remotes` counts the commits only `feat` has.
- `git diff-tree -p --root -r -M --diff-merges=first-parent <hash>` gives a root commit's, a normal commit's and a
  merge's (against its first parent) diff alike.

In `crates/templum-git/src/repo.rs`, replace `push` in the `impl Repo` that holds `fetch` and `pull`:

```rust
    pub fn push(&self) -> Result<(), GitError> {
        self.run(&["push"]).map(drop)
    }

    /// `git push -u <remote> <branch>`: the branch goes to the server and follows it from then.
    pub fn publish(&self, remote: &str, branch: &str) -> Result<(), GitError> {
        self.run(&["push", "-u", remote, branch]).map(drop)
    }

    /// Pushes `branch`, not the one checked out, to its upstream: the remote and the ref it
    /// follows are read from its config, so a branch tracking another name goes there.
    pub fn push_branch(&self, branch: &str) -> Result<(), GitError> {
        let get = |key: String| -> Result<String, GitError> {
            Ok(self.text(&["config", "--get", &key])?.trim().to_string())
        };
        let remote = get(format!("branch.{branch}.remote"))?;
        let merge = get(format!("branch.{branch}.merge"))?;
        self.run(&["push", &remote, &format!("refs/heads/{branch}:{merge}")])
            .map(drop)
    }

    /// The remotes' names, as `git remote` lists them.
    pub fn remotes(&self) -> Result<Vec<String>, GitError> {
        Ok(self
            .text(&["remote"])?
            .lines()
            .map(str::trim)
            .filter(|l| !l.is_empty())
            .map(str::to_string)
            .collect())
    }

    /// The branch a pull request would go into: the one `origin/HEAD` names, else `main`, else
```

```rust
/// What a switch found of the changes once left on the branch it went to.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Back {
    /// None were left there.
    Nothing,
    /// They are back in the working tree and their stash is gone.
    Popped,
    /// They couldn't come back cleanly (a conflict, a file in the way): git's line. The stash
    /// stays in Stashes.
    Kept(String),
}

/// The message of the stash a switch leaves changes in.
pub fn left_on(name: &str) -> String {
    format!("templum: left on {name}")
}

impl Repo {
    /// Switches to `to`: a local branch, or a remote one ("origin/x"), which goes to the local x
    /// when there is one and else makes it, tracking origin/x. With `leave` (the branch being
    /// left, or its short hash on a detached HEAD), the uncommitted changes, untracked files
    /// too, go first into a stash named `left_on(leave)`; a switch that then fails puts them
    /// straight back, so nothing stays hidden. Once switched, the newest stash left on `to` is
    /// popped (the others stay in Stashes).
    pub fn switch(&self, to: &str, remote: bool, leave: Option<&str>) -> Result<Back, GitError> {
        let local = if remote {
            to.split_once('/').map_or(to, |(_, b)| b)
        } else {
            to
        };
        let top = || {
            self.text(&["rev-parse", "-q", "--verify", "refs/stash"])
                .unwrap_or_default()
        };
        let mut stashed = false;
        if let Some(name) = leave {
            let before = top();
            self.stash_push(&left_on(name), true)?;
            // Nothing to stash makes no stash: never pop someone else's.
            stashed = top() != before;
        }
        let has_local = self
            .run(&["rev-parse", "--verify", "-q", &format!("refs/heads/{local}")])
            .is_ok();
        let switched = if remote && !has_local {
            self.checkout_remote(to)
        } else {
            self.checkout(local)
        };
        if let Err(e) = switched {
            if stashed {
                let _ = self.pop_whole("stash@{0}");
            }
            return Err(e);
        }
        let mine = format!("On {local}: {}", left_on(local));
        let Some(stash) = self.stashes()?.into_iter().find(|s| s.message == mine) else {
            return Ok(Back::Nothing);
        };
        let name = self.stash_ref(&stash)?;
        Ok(match self.pop_whole(&name) {
            Ok(()) => Back::Popped,
            Err(e) => Back::Kept(e.first_line().to_string()),
        })
    }

    /// Pops a stash with its staged changes staged again (`--index`); when git can't do that
    /// part, as plain changes.
    fn pop_whole(&self, name: &str) -> Result<(), GitError> {
        match self.run(&["stash", "pop", "-q", "--index", name]) {
            Err(e) if e.stderr.contains("Try without --index") => {
                self.run(&["stash", "pop", "-q", name]).map(drop)
            }
            r => r.map(drop),
        }
    }
}
```

```rust
/// What Sync did.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Synced {
    /// Got `got` commits from the server, sent `sent`.
    Done { got: u32, sent: u32 },
    /// Both sides have new commits: nothing was changed; `sync_join` joins them.
    Diverged { ahead: u32, behind: u32 },
}

impl Repo {
    /// Sync: fetch, then a fast-forward to the upstream when it has new commits, then a push
    /// when this branch has new ones. The counts are the status's after the fetch (what each
    /// side has that the other hasn't). Both new: nothing is joined.
    pub fn sync(&self) -> Result<Synced, GitError> {
        self.fetch()?;
        let s = self.status()?;
        let (sent, got) = (s.ahead, s.behind);
        if sent > 0 && got > 0 {
            return Ok(Synced::Diverged {
                ahead: sent,
                behind: got,
            });
        }
        if got > 0 {
            self.run(&["merge", "--ff-only", "-q", "@{u}"])?;
        }
        if sent > 0 {
            self.push()?;
        }
        Ok(Synced::Done { got, sent })
    }

    /// A diverged Sync, joined: the user's commits put on top (`rebase`) or a merge, either one
    /// with `--autostash` (a rebase refuses to start over uncommitted changes), then the push.
    pub fn sync_join(&self, rebase: bool) -> Result<Synced, GitError> {
        let got = self.status()?.behind;
        let how = if rebase { "--rebase" } else { "--no-rebase" };
        self.run(&["pull", how, "--autostash"])?;
        let sent = self.status()?.ahead;
        if sent > 0 {
            self.push()?;
        }
        Ok(Synced::Done { got, sent })
    }
}
```

```rust
//! Conflict regions in a file's text: what `<<<<<<<`, `|||||||`, `=======` and `>>>>>>>` mark,
//! each part named after its marker's label (never "ours" or "theirs": in a rebase those are
//! backwards), and the text with one region resolved. Pure: tested on text.
//! See docs/specs/git.md, section 5, Conflicts.

use std::ops::Range;

use crate::diff::{FileDiff, Hunk, Kind, Line};
use crate::parse::Change;

/// One conflict region, as byte ranges into the file's text. A part's range holds its lines
/// with their endings, as the file has them.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Region {
    /// From the `<<<<<<<` line's start to the end of the `>>>>>>>` line.
    pub whole: Range<usize>,
    /// The part after `<<<<<<<`: HEAD's in a merge and in a rebase alike (`checkout --ours`).
    pub first: Range<usize>,
    /// The common ancestor's part (`|||||||`, with diff3 or zdiff3): never shown.
    pub base: Option<Range<usize>>,
    /// The part after `=======` (`checkout --theirs`).
    pub second: Range<usize>,
    /// What follows `<<<<<<< ` ("HEAD") and `>>>>>>> ` ("feature", "a6caaa4 (feat)").
    pub first_label: String,
    pub second_label: String,
    /// The `<<<<<<<` line, from 1.
    pub line: u32,
}

impl Region {
    /// A part's lines as the panel shows them: without their '\n' (a CRLF line keeps its '\r',
    /// as the diff parser's lines do).
    pub fn lines(text: &str, part: &Range<usize>) -> Vec<String> {
        text[part.clone()]
            .split_inclusive('\n')
            .map(|l| l.strip_suffix('\n').unwrap_or(l).to_string())
            .collect()
    }
}

/// Which part of a region stays.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Take {
    First,
    Second,
    /// The first part, then the second.
    Both,
}

/// A marker line's label: `c` seven times at the line's start, then nothing, or a space and
/// the label.
fn marker(line: &str, c: char) -> Option<String> {
    let rest = line.strip_prefix(&c.to_string().repeat(7))?;
    if rest.is_empty() {
        Some(String::new())
    } else {
        rest.strip_prefix(' ').map(str::to_string)
    }
}

/// The regions of `text`, in order. A region that never closes ends the list; a `<<<<<<<` inside
/// an open region starts over from it.
pub fn regions(text: &str) -> Vec<Region> {
    // Each line: its start, its end (after its ending), its text without the ending.
    let mut lines = Vec::new();
    let mut start = 0;
    for piece in text.split_inclusive('\n') {
        let end = start + piece.len();
        let bare = piece.strip_suffix('\n').unwrap_or(piece);
        lines.push((start, end, bare.strip_suffix('\r').unwrap_or(bare)));
        start = end;
    }
    let mut out = Vec::new();
    let mut i = 0;
    'regions: while i < lines.len() {
        let Some(first_label) = marker(lines[i].2, '<') else {
            i += 1;
            continue;
        };
        let open = i;
        let (mut base, mut mid, mut close) = (None, None, None);
        let mut j = open + 1;
        while j < lines.len() {
            let l = lines[j].2;
            if marker(l, '<').is_some() {
                i = j;
                continue 'regions;
            }
            if mid.is_none() && base.is_none() && marker(l, '|').is_some() {
                base = Some(j);
            } else if mid.is_none() && l == "=======" {
                mid = Some(j);
            } else if mid.is_some() && marker(l, '>').is_some() {
                close = Some(j);
                break;
            }
            j += 1;
        }
        let (Some(mid), Some(close)) = (mid, close) else {
            break;
        };
        let at = |k: usize| lines[k].0;
        let after = |k: usize| lines[k].1;
        out.push(Region {
            whole: at(open)..after(close),
            first: after(open)..at(base.unwrap_or(mid)),
            base: base.map(|b| after(b)..at(mid)),
            second: after(mid)..at(close),
            first_label,
            second_label: marker(lines[close].2, '>').unwrap_or_default(),
            line: open as u32 + 1,
        });
        i = close + 1;
    }
    out
}

/// `text` with region `index` replaced by what `take` keeps; None when there is no such region.
pub fn resolve(text: &str, index: usize, take: Take) -> Option<String> {
    let r = regions(text).into_iter().nth(index)?;
    let kept = match take {
        Take::First => &text[r.first.clone()],
        Take::Second => &text[r.second.clone()],
        Take::Both => {
            return Some(format!(
                "{}{}{}{}",
                &text[..r.whole.start],
                &text[r.first.clone()],
                &text[r.second.clone()],
                &text[r.whole.end..]
            ));
        }
    };
    Some(format!("{}{kept}{}", &text[..r.whole.start], &text[r.whole.end..]))
}

/// A conflicted file as the panel shows it: region k's parts are hunks 2k and 2k+1, their lines
/// context lines numbered as in the file, each hunk's context its part's label. With no region
/// left there is no hunk (the file can be marked resolved). None for a text that isn't UTF-8:
/// its row alone shows, with the whole-file choices.
pub fn conflict_diff(path: &str, bytes: &[u8]) -> Option<FileDiff> {
    let text = std::str::from_utf8(bytes).ok()?;
    let mut file = FileDiff::empty();
    file.old_path = Some(path.to_string());
    file.new_path = Some(path.to_string());
    file.status = Change::Conflict;
    for r in regions(text) {
        let count = |part: &Range<usize>| text[part.clone()].split_inclusive('\n').count() as u32;
        let first_at = r.line + 1;
        // The ||||||| line and the base part, then the ======= line.
        let base = r.base.as_ref().map_or(0, |b| count(b) + 1);
        let second_at = first_at + count(&r.first) + base + 1;
        for (part, label, at) in [
            (&r.first, &r.first_label, first_at),
            (&r.second, &r.second_label, second_at),
        ] {
            let lines: Vec<Line> = Region::lines(text, part)
                .into_iter()
                .enumerate()
                .map(|(k, text)| Line {
                    kind: Kind::Context,
                    old_no: None,
                    new_no: Some(at + k as u32),
                    text,
                    no_newline: false,
                })
                .collect();
            file.hunks.push(Hunk {
                old_start: 0,
                old_len: 0,
                new_start: at,
                new_len: lines.len() as u32,
                context: label.clone(),
                lines,
            });
        }
    }
    Some(file)
}
```

```rust
    /// external diff (a user's diff.mnemonicPrefix, diff.noprefix or diff.external would change

        let mut args = vec![

            "core.quotePath=false",
            command,
            "--no-color",
            "--no-ext-diff",
            "--src-prefix=a/",
            "--dst-prefix=b/",
            "-M",
        ];

        }
        args

    pub fn compare_log(&self, base: &str, branch: &str) -> Result<Vec<Commit>, GitError> {
        let format = format!("--format={}", parse::LOG_FORMAT);
        let date = format!("--date={}", parse::LOG_DATE);
        let range = format!("{base}..{branch}");
        let out = self.run(&["log", "-z", &format, &date, &range, "--"])?;
        Ok(parse::parse_log(&out))
    }

    /// What `branch` changed since it left `base` (`git diff base...branch`), as a pull request
    /// shows it.
    pub fn range_diff(
        &self,
        base: &str,
        branch: &str,
        ignore_whitespace: bool,
    ) -> Result<Vec<FileDiff>, GitError> {
        let range = format!("{base}...{branch}");
        let mut args = Self::diff_args("diff", ignore_whitespace);
        args.push(&range);
        args.push("--");
        Ok(parse_diff(&self.text(&args)?, DIFF_LIMIT))
    }

    ) -> Result<Vec<FileDiff>, GitError> {
        let mut args = Self::diff_args("diff-tree", ignore_whitespace);
        args.extend(["-p", "-r", "--root", "--no-commit-id", "--diff-merges=first-parent", hash]);
```

```rust
//! The Git block's words for people: each Git word's one-sentence tooltip, and the sentences
//! that say where a branch stands. See docs/specs/git.md, Words.

use templum_git::Status;

/// The tooltip of a Git word, as the spec's Words table gives it ("" for a word it hasn't).
pub(crate) fn tip(word: &str) -> &'static str {
    match word {
        "Stage" => "Choose this change to go into the next commit.",
        "Unstage" => "Take this change out of the next commit; the file keeps it.",
        "Discard" => "Throw this change away and go back to the last commit's version. You can restore it from Recently discarded.",
        "Commit" => "Save a version of the project with the staged changes, and a message saying what they do.",
        "Amend" => "Replace the last commit with this one (its changes and message), instead of adding a new one.",
        "Push" => "Send your commits to the server (the remote), so others can get them.",
        "Pull" => "Get the server's new commits into this branch.",
        "Fetch" => "Look at what changed on the server, without changing your files.",
        "Sync" => "Pull, then push: your branch and the server's end up the same.",
        "Stash" => "Put your uncommitted changes aside, to bring them back later.",
        "Rebase" => "Put your commits on top of the others', as if you had started after them.",
        "Merge" => "Join another branch's commits into this one.",
        _ => "",
    }
}

/// "1 commit", "3 commits".
pub(crate) fn commits(n: u32) -> String {
    if n == 1 { "1 commit".to_string() } else { format!("{n} commits") }
}

/// "1 changed file", "3 changed files".
pub(crate) fn changed_files(n: usize) -> String {
    if n == 1 { "1 changed file".to_string() } else { format!("{n} changed files") }
}

/// Where the branch stands with the server, and the tooltip saying it in words. Empty on a
/// detached HEAD and before the first commit.
pub(crate) fn server_state(s: &Status) -> (String, String) {
    if s.branch.is_none() || s.oid.is_none() {
        return (String::new(), String::new());
    }
    if s.upstream.is_none() || s.gone {
        let tip = if s.gone {
            "Its branch on the server was deleted. Publish branch sends it again."
        } else {
            "This branch isn't on the server yet. Publish branch sends it."
        };
        return ("not published".to_string(), tip.to_string());
    }
    if s.ahead == 0 && s.behind == 0 {
        return (
            "up to date".to_string(),
            "Your branch and the server's had the same commits at the last fetch.".to_string(),
        );
    }
    let mine = match s.ahead {
        0 => "none of yours to push".to_string(),
        1 => "1 commit of yours not pushed yet".to_string(),
        n => format!("{n} commits of yours not pushed yet"),
    };
    let theirs = match s.behind {
        0 => "nothing new on the server".to_string(),
        n => format!("{n} on the server you don't have"),
    };
    (format!("↑{} ↓{}", s.ahead, s.behind), format!("{mine}, {theirs}"))
}

/// What a Sync did: "Up to date", "Got 3 commits", "Sent 2 commits", "Got 3 commits, sent 2".
pub(crate) fn synced(got: u32, sent: u32) -> String {
    match (got, sent) {
        (0, 0) => "Up to date".to_string(),
        (g, 0) => format!("Got {}", commits(g)),
        (0, s) => format!("Sent {}", commits(s)),
        (g, s) => format!("Got {}, sent {s}", commits(g)),
    }
}
```

```rust
use std::rc::Rc;

use gpui_kit::component::notification::Notification;
use gpui_kit::{Context, Window};
use templum_canvas::BlockId;
use templum_git::Synced;

use crate::git_block::{self, words};
use crate::menu::Target;
use crate::prompt::{self, Choice};

use super::{Extra, Workspace, notify_git_error, notify_with, show_notification};

impl Workspace {
    /// Sync: fetch, fast-forward, push, then "Got 3 commits, sent 2". Both sides new: asks how
    /// to join them.
    pub(crate) fn sync_git(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        self.run_sync(id, None, window, cx);
    }

    /// A diverged Sync, joined by a rebase (`rebase`) or a merge, then pushed.
    pub(crate) fn sync_join(&mut self, id: BlockId, rebase: bool, window: &mut Window, cx: &mut Context<Self>) {
        self.run_sync(id, Some(rebase), window, cx);
    }

    fn run_sync(&mut self, id: BlockId, join: Option<bool>, window: &mut Window, cx: &mut Context<Self>) {
        let (Some(git), entity) = (self.space.git_mut(id), cx.entity()) else {
            return;
        };
        let Some(repo) = git.repo().cloned() else {
            return;
        };
        let cancel = std::sync::Arc::new(std::sync::atomic::AtomicBool::new(false));
        git.sync = Some(git_block::Sync::Both);
        git.cancel = Some(cancel.clone());
        let repo = repo.with_cancel(cancel);
        self.act_job(
            self.here(id),
            move || match join {
                None => repo.sync(),
                Some(rebase) => repo.sync_join(rebase),
            },
            move |ws, at, result, window, cx| {
                if let Some(git) = ws.git_at(&at) {
                    git.sync = None;
                    git.cancel = None;
                }
                match result {
                    Ok(Synced::Done { got, sent }) => {
                        show_notification(window, cx, Notification::success(words::synced(got, sent)))
                    }
                    Ok(Synced::Diverged { .. }) => {
                        let (rebase, merge) = (entity.clone(), entity.clone());
                        let block = at.block;
                        prompt::choose(
                            "Your branch and the server's both have new commits.",
                            "",
                            vec![
                                Choice {
                                    id: "git-rebase",
                                    label: "Put my commits on top (rebase)".into(),
                                    primary: true,
                                    act: Rc::new(move |window, cx| {
                                        rebase.update(cx, |ws, cx| ws.sync_join(block, true, window, cx))
                                    }),
                                },
                                Choice {
                                    id: "git-merge",
                                    label: "Merge".into(),
                                    primary: false,
                                    act: Rc::new(move |window, cx| {
                                        merge.update(cx, |ws, cx| ws.sync_join(block, false, window, cx))
                                    }),
                                },
                                Choice {
                                    id: "cancel",
                                    label: "Cancel".into(),
                                    primary: false,
                                    act: Rc::new(|_, _| {}),
                                },
                            ],
                            window,
                            cx,
                        );
                    }
                    Err(e) if e.cancelled() => {}
                    Err(e) => notify_git_error(&entity, at.clone(), &e, Vec::new(), window, cx),
                }
                ws.after_action(at, window, cx);
            },
            window,
            cx,
        );
    }

    /// Publish branch: to the repository's only remote at once; with several, a menu of them at
    /// the mouse; with none, "No remote" with Run in a terminal (`git remote add origin `
    /// typed, for the user to finish).
    pub(crate) fn publish(&mut self, id: BlockId, branch: String, window: &mut Window, cx: &mut Context<Self>) {
        let Some(repo) = self.space.git(id).and_then(|g| g.repo().cloned()) else {
            return;
        };
        let at_mouse = window.mouse_position();
        self.git_job(
            self.here(id),
            move || repo.remotes(),
            move |ws, at, remotes, window, cx| {
                let block = at.block;
                match remotes {
                    Ok(r) if r.len() == 1 => ws.publish_to(block, r[0].clone(), branch, window, cx),
                    Ok(r) if r.is_empty() => {
                        let entity = cx.entity();
                        let run: Extra = (
                            "git-add-remote",
                            "Run in a terminal".into(),
                            Rc::new(move |ws, window, cx| {
                                let root = ws.space.git(block).and_then(|g| g.repo().map(|r| r.root.clone()));
                                if let Some(root) = root {
                                    ws.terminal_beside(block, &root, Some("git remote add origin "), window, cx);
                                }
                            }),
                        );
                        notify_with(
                            &entity,
                            at,
                            Notification::warning("No remote: add one to publish this branch."),
                            vec![run],
                            window,
                            cx,
                        );
                    }
                    Ok(remotes) => ws.open_menu(Target::GitRemotes { block, branch, remotes }, at_mouse, window, cx),
                    Err(e) => {
                        let entity = cx.entity();
                        notify_git_error(&entity, at, &e, Vec::new(), window, cx)
                    }
                }
            },
            window,
            cx,
        );
    }

    /// `git push -u <remote> <branch>`, its button spinning.
    pub(crate) fn publish_to(&mut self, id: BlockId, remote: String, branch: String, window: &mut Window, cx: &mut Context<Self>) {
        self.git_sync(
            id,
            git_block::Sync::Push,
            move |repo| repo.publish(&remote, &branch),
            |_, at, e, window, cx| {
                let ws = cx.entity();
                notify_git_error(&ws, at, e, Vec::new(), window, cx)
            },
            window,
            cx,
        );
    }
}
```

```rust
/// Two text fields (placeholder, initial text). Enter or `ok` calls `apply` with both; the
/// dialog closes when it returns true.
pub(crate) fn ask_two<V: 'static>(
    title: impl Into<SharedString>,
    ok: &'static str,
    first: (&'static str, String),
    second: (&'static str, String),
    apply: impl Fn(String, String, &mut Window, &mut App) -> bool + 'static,
    window: &mut Window,
    cx: &mut Context<V>,
) {
    let title = title.into();
    let field = |(placeholder, initial): (&'static str, String), window: &mut Window, cx: &mut Context<V>| {
        cx.new(|cx| InputState::new(window, cx).placeholder(placeholder).default_value(initial))
    };
    let (a, b) = (field(first, window, cx), field(second, window, cx));
    let apply = Rc::new(apply);
    let (fa, fb) = (a.clone(), b.clone());
    window.open_alert_dialog(cx, move |alert, _, _| {
        let (apply, fa, fb) = (apply.clone(), fa.clone(), fb.clone());
        alert
            .confirm()
            .title(title.clone())
            .w(px(520.0))

                    .child(Input::new(&fb)),

                let (x, y) = (fa.read(cx).value().to_string(), fb.read(cx).value().to_string());
                apply(x, y, window, cx)
            })
    });
```

```rust
//! Switching a Git block's branch without losing work: the question about uncommitted changes
//! (a stash per branch, popped on return), the unpushed notice. See docs/specs/git.md,
//! section 4, Switching branches.

use std::rc::Rc;

use gpui_kit::component::notification::Notification;
use gpui_kit::{Context, Window};
use templum_canvas::BlockId;
use templum_git::Back;

use crate::git_block::{self, words};
use crate::prompt::{self, Choice};

use super::{Extra, Workspace, notify_git_error, notify_with, show_notification};

impl Workspace {
    /// The branch pill: the branches read afresh, then the switcher.
    pub(crate) fn open_branch_switcher(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let Some(repo) = self.space.git(id).and_then(|g| g.repo().cloned()) else {
            return;
        };
        self.git_job(
            self.here(id),
            move || repo.branches(),
            |ws, at, branches, window, cx| {
                let Ok(branches) = branches else {
                    return;
                };
                if let Some(git) = ws.git_at(&at) {
                    git.branches = branches.clone();
                }
                git_block::switcher::open(cx.entity(), at.block, branches, window, cx);
            },
            window,
            cx,
        );
    }

    /// Switches to `name` (`remote`: "origin/x"). With uncommitted changes it asks what happens
    /// to them first; during a merge or a rebase it says to finish it.
    pub(crate) fn switch_branch(
        &mut self,
        id: BlockId,
        name: String,
        remote: bool,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(git) = self.space.git(id) else {
            return;
        };
        if let Some(op) = git.operation {
            let message = format!("Finish or abort the {} first.", op.name());
            show_notification(window, cx, Notification::warning(message));
            return;
        }
        let s = &git.status;
        if !remote && s.branch.as_deref() == Some(name.as_str()) {
            return;
        }
        // What the stash is named after: the branch, or the commit on a detached HEAD.
        let here = s
            .branch
            .clone()
            .or_else(|| s.oid.as_ref().map(|o| o[..o.len().min(7)].to_string()))
            .unwrap_or_default();
        if s.entries.is_empty() {
            self.switch_now(id, name, remote, None, window, cx);
            return;
        }
        let unpushed = unpushed(s)
            .map(|(branch, n)| format!("{branch} has {} not pushed yet.", words::commits(n)))
            .unwrap_or_default();
        let entity = cx.entity();
        let act = |leave: Option<String>| -> Rc<dyn Fn(&mut Window, &mut gpui_kit::App)> {
            let (entity, name) = (entity.clone(), name.clone());
            Rc::new(move |window, cx| {
                let (name, leave) = (name.clone(), leave.clone());
                entity.update(cx, |ws, cx| ws.switch_now(id, name, remote, leave, window, cx))
            })
        };
        let commit = entity.clone();
        prompt::choose(
            format!("You have {}. What should happen to them?", words::changed_files(s.entries.len())),
            unpushed,
            vec![
                Choice { id: "git-leave", label: format!("Leave them on {here}").into(), primary: true, act: act(Some(here.clone())) },
                Choice { id: "git-bring", label: "Bring them along".into(), primary: false, act: act(None) },
                Choice {
                    id: "git-commit-first",
                    label: "Commit first".into(),
                    primary: false,
                    act: Rc::new(move |window, cx| commit.update(cx, |ws, cx| ws.focus_summary(id, window, cx))),
                },
                Choice { id: "cancel", label: "Cancel".into(), primary: false, act: Rc::new(|_, _| {}) },
            ],
            window,
            cx,
        );
    }

    /// The switch itself (`leave`: the stash's name for the changes left behind), then what
    /// came back, and the branch left behind's commits not pushed.
    pub(crate) fn switch_now(
        &mut self,
        id: BlockId,
        name: String,
        remote: bool,
        leave: Option<String>,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(git) = self.space.git(id) else {
            return;
        };
        let Some(repo) = git.repo().cloned() else {
            return;
        };
        let left = unpushed(&git.status);
        let here = git.status.branch.clone().unwrap_or_default();
        let (to, job_leave) = (name.clone(), leave.clone());
        self.act_job(
            self.here(id),
            move || repo.switch(&to, remote, job_leave.as_deref()),
            move |ws, at, result, window, cx| {
                let entity = cx.entity();
                let block = at.block;
                let local = if remote { name.split_once('/').map_or(name.as_str(), |(_, b)| b) } else { name.as_str() };
                match result {
                    Ok(back) => {
                        match back {
                            Back::Nothing => {}
                            Back::Popped => show_notification(
                                window,
                                cx,
                                Notification::success(format!("Your changes on {local} are back")),
                            ),
                            Back::Kept(why) => show_notification(
                                window,
                                cx,
                                Notification::warning(format!(
                                    "Your changes left on {local} are still in Stashes: {why}"
                                )),
                            ),
                        }
                        if let Some((branch, n)) = left.clone() {
                            let push: Extra = (
                                "git-push-left",
                                format!("Push {branch}").into(),
                                Rc::new({
                                    let branch = branch.clone();
                                    move |ws, window, cx| ws.push_branch(block, branch.clone(), window, cx)
                                }),
                            );
                            notify_with(
                                &entity,
                                at.clone(),
                                Notification::info(format!("{branch} has {} not pushed yet", words::commits(n))),
                                vec![push],
                                window,
                                cx,
                            );
                        }
                    }
                    Err(e) => {
                        let mut extra: Vec<Extra> = Vec::new();
                        let refused = e.stderr.contains("would be overwritten") || e.stderr.contains("local changes");
                        if leave.is_none() && refused && !here.is_empty() {
                            let (name, here) = (name.clone(), here.clone());
                            extra.push((
                                "git-leave-them",
                                format!("Leave them on {here}").into(),
                                Rc::new(move |ws, window, cx| {
                                    ws.switch_now(block, name.clone(), remote, Some(here.clone()), window, cx)
                                }),
                            ));
                        }
                        notify_git_error(&entity, at.clone(), &e, extra, window, cx);
                    }
                }
                ws.after_action(at, window, cx);
            },
            window,
            cx,
        );
    }

    /// The Changes tab, its column shown, the summary with the keyboard (the `c` key, Commit
    /// first).
    pub(crate) fn focus_summary(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        git.tab = git_block::Tab::Changes;
        git.lists_folded = false;
        let summary = git.summary.clone();
        cx.notify();
        summary.update(cx, |s, cx| s.focus(window, cx));
    }

    /// Push `main` (from the unpushed notice): a branch not checked out, to its upstream.
    pub(crate) fn push_branch(&mut self, id: BlockId, branch: String, window: &mut Window, cx: &mut Context<Self>) {
        self.git_sync(
            id,
            git_block::Sync::Push,
            move |repo| repo.push_branch(&branch),
            |_, at, e, window, cx| {
                let ws = cx.entity();
                notify_git_error(&ws, at, e, Vec::new(), window, cx)
            },
            window,
            cx,
        );
    }
}

/// The checked-out branch and its commits not pushed, when it has an upstream and some.
fn unpushed(s: &templum_git::Status) -> Option<(String, u32)> {
    let branch = s.branch.clone()?;
    (s.upstream.is_some() && !s.gone && s.ahead > 0).then_some((branch, s.ahead))
}
```

```rust
//! The branch switcher: the top bar's branch pill opens it. A search over the local branches,
//! then the remote ones; Enter switches (through the question about changes); + New branch…
//! at the foot. See docs/specs/git.md, section 1, Top bar.

use gpui_kit::component::WindowExt as _;
use gpui_kit::component::button::{Button, ButtonVariants as _};
use gpui_kit::component::command::{Command, CommandGroup, CommandItem, CommandState};
use gpui_kit::prelude::*;
use gpui_kit::{App, Entity, Window, px};
use templum_canvas::BlockId;
use templum_git::Branch;

use crate::workspace::Workspace;

pub(crate) fn open(ws: Entity<Workspace>, block: BlockId, branches: Vec<Branch>, window: &mut Window, cx: &mut App) {
    let (local, remote): (Vec<Branch>, Vec<Branch>) = branches.into_iter().partition(|b| !b.remote);
    let state = cx.new(|cx| CommandState::new(window, cx));
    let palette = state.clone();
    window.open_dialog(cx, move |dialog, _, _| {
        let (ws_pick, ws_new) = (ws.clone(), ws.clone());
        let (local_names, remote_names): (Vec<String>, Vec<String>) = (
            local.iter().map(|b| b.name.clone()).collect(),
            remote.iter().map(|b| b.name.clone()).collect(),
        );
        // Both groups always: their sections stay 0 and 1, filtered or not.
        dialog.title("Switch branch").w(px(420.0)).child(
            Command::new(&palette)
                .group(CommandGroup::new().label("Local").items(
                    local.iter().map(|b| CommandItem::new().label(b.name.clone()).checked(b.current)),
                ))
                .group(CommandGroup::new().label("Remote").items(
                    remote.iter().map(|b| CommandItem::new().label(b.name.clone())),
                ))
                .placeholder("Search branches")
                .footer(move |_, _, _| {
                    let ws = ws_new.clone();
                    Button::new("git-switcher-new")
                        .label("+ New branch…")
                        .ghost()
                        .on_click(move |_, window, cx| {
                            window.close_dialog(cx);
                            let ws = ws.clone();
                            // The next dialog opens once this one has closed.
                            window.defer(cx, move |window, cx| {
                                ws.update(cx, |ws, cx| ws.branch_from(block, None, window, cx))
                            });
                        })
                })
                .on_confirm(move |at, window, cx| {
                    let (name, remote) = match at.section {
                        0 => (local_names.get(at.row).cloned(), false),
                        _ => (remote_names.get(at.row).cloned(), true),
                    };
                    let Some(name) = name else {
                        return;
                    };
                    window.close_dialog(cx);
                    ws_pick.update(cx, |ws, cx| ws.switch_branch(block, name, remote, window, cx));
                }),
        )
    });
    state.update(cx, |state, cx| state.focus(window, cx));
}
```

```rust
//! A Git block's comparison: a branch against the default one (or a base chosen), its commits
//! on the left, its diff in the panel. See docs/specs/git.md, section 5, Comparison.

use std::rc::Rc;

use gpui_kit::component::notification::Notification;
use gpui_kit::{Context, Window};
use templum_canvas::BlockId;
use templum_git::{Commit, FileDiff, GitError};

use crate::git_block::diff_view::{DiffPanel, Source};
use crate::git_block::{self, Compare, Tab, words};

use super::{GitAt, Workspace, show_notification};

impl Workspace {
    /// Compare `branch` with the default branch: the Branches tab shows it.
    pub(crate) fn compare_branch(&mut self, id: BlockId, branch: String, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        let Some(base) = git.default_branch.clone() else {
            show_notification(window, cx, Notification::warning("No main branch to compare with."));
            return;
        };
        git.compare = Some(Compare {
            branch,
            base,
            commits: Rc::new(Vec::new()),
            narrowed: None,
            panel: DiffPanel::range(String::new()),
        });
        git.tab = Tab::Branches;
        cx.notify();
        let at = self.here(id);
        self.refresh_lists_at(at, window, cx);
    }

    /// Reads the comparison: its commits, and the whole diff or the narrowed commit's. A result
    /// for a comparison changed meanwhile (another branch, base or commit) is dropped.
    pub(crate) fn load_compare(&mut self, at: GitAt, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.git_at(&at) else {
            return;
        };
        let (Some(repo), Some(c)) = (git.repo().cloned(), git.compare.as_ref()) else {
            return;
        };
        let asked = (c.branch.clone(), c.base.clone(), c.narrowed.clone());
        let ignore_ws = c.panel.ignore_ws;
        let (branch, base, narrowed) = asked.clone();
        self.git_job(
            at,
            move || -> Result<(Vec<Commit>, Vec<FileDiff>), GitError> {
                let commits = repo.compare_log(&base, &branch)?;
                let files = match &narrowed {
                    Some(hash) => repo.commit_changes(hash, ignore_ws)?,
                    None => repo.range_diff(&base, &branch, ignore_ws)?,
                };
                Ok((commits, files))
            },
            move |ws, at, read, _, cx| {
                let Some(git) = ws.git_at(&at) else {
                    return;
                };
                let Some(c) = git.compare.as_mut().filter(|c| (c.branch.clone(), c.base.clone(), c.narrowed.clone()) == asked) else {
                    return;
                };
                match read {
                    Ok((commits, files)) => {
                        let title = match &c.narrowed {
                            Some(hash) => format!("{} vs {} · commit {}", c.branch, c.base, &hash[..hash.len().min(7)]),
                            None => format!("{} vs {} · {}", c.branch, c.base, words::commits(commits.len() as u32)),
                        };
                        c.panel.source = Source::Range { title };
                        c.commits = Rc::new(commits);
                        c.panel.set_files(files);
                        git.error = None;
                    }
                    Err(e) => git.error = Some(e.to_string()),
                }
                cx.notify();
            },
            window,
            cx,
        );
    }

    /// A commit of the comparison (Some) narrows the panel to it; the heading (None) shows them
    /// all again.
    pub(crate) fn narrow_compare(&mut self, id: BlockId, hash: Option<String>, window: &mut Window, cx: &mut Context<Self>) {
        let Some(c) = self.space.git_mut(id).and_then(|g| g.compare.as_mut()) else {
            return;
        };
        c.narrowed = hash;
        let at = self.here(id);
        self.load_compare(at, window, cx);
    }

    /// The column's ←: back to the branches.
    pub(crate) fn close_compare(&mut self, id: BlockId, cx: &mut Context<Self>) {
        if let Some(git) = self.space.git_mut(id) {
            git.compare = None;
            cx.notify();
        }
    }

    /// The base button: any other branch, local or remote, from a searchable list.
    pub(crate) fn choose_compare_base(&mut self, id: BlockId, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git(id) else {
            return;
        };
        let Some(branch) = git.compare.as_ref().map(|c| c.branch.clone()) else {
            return;
        };
        let names: Vec<String> = git.branches.iter().map(|b| b.name.clone()).filter(|b| *b != branch).collect();
        git_block::switcher::pick(cx.entity(), "Compare with", names, move |ws, base, window, cx| {
            if let Some(c) = ws.space.git_mut(id).and_then(|g| g.compare.as_mut()) {
                c.base = base;
                c.narrowed = None;
            }
            let at = ws.here(id);
            ws.load_compare(at, window, cx);
        }, window, cx);
    }
}
```

```rust
//! A Git block's conflicts: a region's part chosen, a whole file's version chosen, Mark
//! resolved. Each choice keeps a copy of the file in the trash first. See docs/specs/git.md,
//! section 5, Conflicts.

use std::time::SystemTime;

use gpui_kit::component::notification::Notification;
use gpui_kit::{Context, Window};
use templum_canvas::BlockId;
use templum_git::conflict::{Region, Take, regions, resolve};
use templum_git::trash;

use crate::prompt;

use super::git_discard::REFUSED;
use super::{Workspace, notify_git_error, show_notification};

/// Why a choice didn't happen.
enum Refused {
    /// The region isn't what was shown any more.
    Changed,
    Io(std::io::Error),
}

impl Workspace {
    /// A region's part (or both) replaces the region in the file, after a copy in the trash;
    /// refused when the region isn't the one shown (`shown`: its two parts' lines as drawn).
    pub(crate) fn resolve_region(
        &mut self,
        id: BlockId,
        path: String,
        region: usize,
        take: Take,
        shown: (Vec<String>, Vec<String>),
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(root) = self.space.git(id).and_then(|g| g.repo().map(|r| r.root.clone())) else {
            return;
        };
        let keep = self.trash.clone();
        self.act_job(
            self.here(id),
            move || -> Result<(), Refused> {
                let full = root.join(&path);
                let bytes = std::fs::read(&full).map_err(Refused::Io)?;
                let text = String::from_utf8(bytes).map_err(|_| Refused::Changed)?;
                let r = regions(&text).into_iter().nth(region).ok_or(Refused::Changed)?;
                if (Region::lines(&text, &r.first), Region::lines(&text, &r.second)) != shown {
                    return Err(Refused::Changed);
                }
                let resolved = resolve(&text, region, take).ok_or(Refused::Changed)?;
                let paths = [path.clone()];
                let (files, size) = trash::measure(&root, &paths);
                let kept = match keep.as_ref().filter(|_| trash::fits(files, size)) {
                    Some(t) => Some((t, t.put(&root, &paths, &format!("Chose a part of {path}"), SystemTime::now()).map_err(Refused::Io)?)),
                    None => None,
                };
                std::fs::write(&full, resolved).map_err(Refused::Io)?;
                if let Some((t, k)) = kept {
                    let _ = t.seal(&k);
                    let _ = t.prune(SystemTime::now());
                }
                Ok(())
            },
            |ws, at, done, window, cx| {
                match done {
                    Ok(()) => {}
                    Err(Refused::Changed) => {
                        eprintln!("templum: {REFUSED}");
                        show_notification(window, cx, Notification::error(REFUSED));
                    }
                    Err(Refused::Io(e)) => {
                        let message = format!("Couldn't write the file: {e}");
                        eprintln!("templum: {message}");
                        show_notification(window, cx, Notification::error(message));
                    }
                }
                ws.after_action(at, window, cx);
            },
            window,
            cx,
        );
    }

    /// A whole file's version (`git checkout --ours` / `--theirs`), after a copy in the trash.
    pub(crate) fn resolve_file(
        &mut self,
        id: BlockId,
        path: String,
        side: templum_git::Side,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(repo) = self.space.git(id).and_then(|g| g.repo().cloned()) else {
            return;
        };
        let keep = self.trash.clone();
        self.act_job(
            self.here(id),
            move || {
                let paths = [path.clone()];
                let (files, size) = trash::measure(&repo.root, &paths);
                let kept = keep
                    .as_ref()
                    .filter(|_| trash::fits(files, size))
                    .and_then(|t| t.put(&repo.root, &paths, &format!("Chose a version of {path}"), SystemTime::now()).ok().map(|k| (t, k)));
                let done = repo.resolve(&path, side);
                if let Some((t, k)) = kept {
                    let _ = t.seal(&k);
                }
                done
            },
            |ws, at, done, window, cx| {
                if let Err(e) = done {
                    let entity = cx.entity();
                    notify_git_error(&entity, at.clone(), &e, Vec::new(), window, cx);
                }
                ws.after_action(at, window, cx);
            },
            window,
            cx,
        );
    }

    /// Mark resolved: stages the file; with conflict markers still in it, asks first.
    pub(crate) fn mark_resolved(&mut self, id: BlockId, path: String, window: &mut Window, cx: &mut Context<Self>) {
        let Some(git) = self.space.git(id) else {
            return;
        };
        if !git.markers_left(&path) {
            self.stage(id, vec![path], window, cx);
            return;
        }
        let entity = cx.entity();
        prompt::confirm(
            format!("Mark {path} resolved?"),
            "It still has conflict markers: Git will record them as they are.",
            "Mark resolved",
            move |window, cx| {
                let path = path.clone();
                entity.update(cx, |ws, cx| ws.stage(id, vec![path], window, cx))
            },
            window,
            cx,
        );
    }
}
```
