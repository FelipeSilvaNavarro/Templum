# Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An editor block on one folder: a lazy file tree, tabs of open files in gpui-kit's code editor with syntax highlighting, save, files reloaded when they change on disk, the tree's file operations, and `Workspace::open_in_editor` for the Git block that comes next.

**Architecture:** One new module, `editor.rs`, holds the block's state (`Editor`: the folder, the tree's read folders, the tabs) and its body; the tree is gpui-base's `Tree`/`TreeState` fed from Templum's own folder model (a folder is read when it is expanded), the tabs are Templum's own row (they must scale with the zoom), the text is gpui-kit's `EditorState`/`Editor`. The workspace gains one `Body::Editor` arm, the folder dialog is the agents' one made generic, the file is one new `session::Item` kind. File reads and writes run on the UI thread (files are at most 32 MB and come from the page cache).

**Tech Stack:** Rust 1.98, GPUI through `gpui-kit =0.7.1` (gpui-base `Tree`, gpui-component `EditorState`, `Editor`, `TextView`, `Button`, `AlertDialog`), the tree-sitter grammar features of gpui-kit, `serde_json`. No new crate.

**Spec:** `docs/specs/cockpit.md`, section 7 (The editor), the `new_editor` row of section 3's shortcut table, and "Shared pieces" (`add_beside`). Plans 1 and 2 (`docs/plans/2026-10-11-canvas-foundations.md`, `docs/plans/2026-10-11-drawing.md`) are merged: `Space::blocks`, `Body`, `toolbar.rs`, `launcher.rs`, `prompt.rs` and `menu::Target::Block` exist.

## Global Constraints

- Only `crates/templum` depends on `gpui-kit`; `templum-canvas` stays free of GPUI and serde.
- `gpui-kit` stays pinned `=0.7.1`; this plan only adds Cargo **features** to it. No new dependency line.
- **Grammars: the curated list, not `tree-sitter-languages`.** The full feature doesn't resolve: gpui-component's SQL grammar (`tree-sitter-sequel`) pins `cc ~1.2` while the lock holds `cc 1.7`. The spec's fallback list applies (markdown, json, toml, yaml, diff, bash, rust, javascript, typescript, tsx, python, go, html, css, c, cpp, java, lua, make; sql dropped). Checked on 2026-10-11 in a copy of the tree: `cargo deny check` says `advisories ok, bans ok, licenses ok, sources ok` with that list, adding 16 `tree-sitter-*` crates.
- No `unsafe`. Every logic change ships a test that fails without it; UI changes get a headless `#[gpui_kit::test]`.
- Commits go on `development`, titled with an imperative sentence (AGENTS.md).
- Before every commit: `cargo fmt --all && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`. Task 1 also runs `cargo deny check`.
- Exact values: a new editor is **900 × 600** world units, at least **480 × 320**; the tree is **220** world units wide; text is the terminal font at **13** world units × zoom; a file with a **NUL byte in its first 8 KB** is binary; over **4 MB** opens read-only; over **32 MB** isn't opened; open files and the focused editor's tree are checked every **2 seconds**; a terminal opened from the tree goes **24** units to the right of the editor, cascading down by **32**.
- Shortcuts: `new_editor` Ctrl+Shift+E / Cmd+Shift+E; `save` Ctrl+S / Cmd+S; `close_tab` Ctrl+W on every OS; `go_to_line` Ctrl+G / Cmd+G. `save`, `close_tab` and `go_to_line` run only while an editor block has the focus; otherwise the key goes to the terminal.
- **`find` is not a Templum command.** gpui-kit's editor binds Ctrl+F (search) and Ctrl+H (replace) in its own focus context, and GPUI dispatches key bindings before `on_key_down` listeners (`gpui-pre-0.3.8/src/window.rs`, `dispatch_key_event`): a Templum `find` would never run while the editor has the focus, and must not run otherwise. The spec's "Search" row is met by the editor itself.
- Settings ▸ Tools (`git.program`, `docker.program`) is **not** in this plan: nothing reads those keys before plan 5. Plan 5 adds the section with the first reader.
- GPUI lessons in `docs/adr/0002-ui-framework.md` apply; read the pinned sources (`~/.cargo/registry/src/*/gpui-pre-0.3.8`, `gpui-base-0.7.1`, `gpui-component-0.7.1`), never guess.

```rust
/// `dir`'s entries: folders first, then files, each sorted without case. Hidden files are

pub(crate) fn read_dir(dir: &Path) -> Vec<Entry> {
    let mut entries: Vec<Entry> = std::fs::read_dir(dir)
        .map(|read| {
            read.filter_map(|e| {
                let e = e.ok()?;
                let path = e.path();
                Some(Entry {
                    name: e.file_name().to_string_lossy().into_owned(),
                    is_dir: path.is_dir(),
                    path,
                })
            })
            .collect()
        })
        .unwrap_or_default();
    entries.sort_by(|a, b| {
        b.is_dir
            .cmp(&a.is_dir)
            .then_with(|| a.name.to_lowercase().cmp(&b.name.to_lowercase()))
    });
    entries
}
```

```rust
/// An editor block: one folder, the file tree over it, the open files.
pub(crate) struct Editor {
    pub folder: PathBuf,
    pub tree: Entity<TreeState>,
    /// The folders read so far, by path: the root and each one expanded. A folder that was
    /// never expanded costs nothing (`node_modules`).
    pub dirs: HashMap<PathBuf, Vec<Entry>>,
    pub expanded: HashSet<PathBuf>,
    pub show_tree: bool,
    /// When the tree was last read, for the refresh while the block is focused.
    pub tree_read: Instant,
    _expansions: Subscription,
}

impl Editor {
    pub fn new(folder: PathBuf, show_tree: bool, cx: &mut Context<Workspace>) -> Editor {
        let tree = cx.new(|cx| TreeState::new(cx));
        let _expansions = cx.subscribe(&tree, |ws, tree, event: &TreeEvent, cx| {
            ws.on_tree_event(&tree, event, cx)
        });
        let mut editor = Editor {
            folder,
            tree,
            dirs: HashMap::new(),
            expanded: HashSet::new(),
            show_tree,
            tree_read: Instant::now(),
            _expansions,
        };
        editor.refresh(cx);
        editor
    }

    /// Reads the root and every expanded folder again; shows them when something changed.
    pub fn refresh(&mut self, cx: &mut App) -> bool {
        let dirs: HashMap<PathBuf, Vec<Entry>> = std::iter::once(&self.folder)
            .chain(&self.expanded)
            .map(|d| (d.clone(), read_dir(d)))
            .collect();
        self.tree_read = Instant::now();
        if dirs == self.dirs {
            return false;
        }
        self.dirs = dirs;
        self.show(cx);
        true
    }

    /// Rebuilds the tree's items from `dirs`, keeping the selected row.
    pub fn show(&self, cx: &mut App) {
        let items = self.items(&self.folder);
        self.tree.update(cx, |tree, cx| {
            let selected = tree.selected_item().map(|i| i.id.clone());
            tree.set_items(items, cx);
            let ix = selected.and_then(|id| tree.index_of(&id));
            tree.set_selected_index(ix, cx);
        });
    }

    /// `dir`'s items, with each folder's items under it. An item's id is its path.
    fn items(&self, dir: &Path) -> Vec<TreeItem> {
        let Some(entries) = self.dirs.get(dir) else {
            return Vec::new();
        };
        entries
            .iter()
            .map(|e| {
                let id = e.path.to_string_lossy().into_owned();
                let item = TreeItem::new(id.clone(), e.name.clone());
                if !e.is_dir {
                    return item;
                }
                // A folder keeps a child so the tree knows it is one: its entries once read,
                // else a placeholder that can't be clicked.
                let children = match self.dirs.get(&e.path) {
                    Some(read) if !read.is_empty() => self.items(&e.path),
                    Some(_) => vec![TreeItem::new(format!("{id}/"), "empty").disabled(true)],
                    None => vec![TreeItem::new(format!("{id}/"), "…").disabled(true)],
                };
                item.children(children)
                    .expanded(self.expanded.contains(&e.path))
            })
            .collect()
    }

    pub fn folder_name(&self) -> String {
        self.folder.file_name().map_or_else(
            || self.folder.display().to_string(),
            |n| n.to_string_lossy().into_owned(),
        )
    }

    pub fn title(&self) -> SharedString {
        self.folder_name().into()
    }

    /// As the canvas file holds it.
    pub fn item(&self, rect: Rect) -> session::EditorItem {
        session::EditorItem {
            rect: rect.into(),
            folder: self.folder.to_string_lossy().into_owned(),
            open: Vec::new(),
            active: None,
            tree: self.show_tree,
        }
    }
}
```

```rust
/// The body below the header, at the block's zoom `z`: the tree on the left (when shown) and

pub(crate) fn body(
    ws: &Workspace,
    id: BlockId,
    editor: &Editor,
    z: f32,
    cx: &mut Context<Workspace>,
) -> AnyElement {
    let ui = ws.ui;

/// One row of the tree: indented by its depth, a chevron for a folder, a file icon for a file.
/// The tree itself selects and expands on mouse down; a placeholder row does nothing.
fn row(
    _entity: &Entity<Workspace>,
    _block: BlockId,
    ix: usize,
    entry: &TreeEntry,
    state: TreeEntryState,
    ui: Ui,
    z: f32,
) -> AnyElement {
    let item = entry.item();
    let disabled = item.is_disabled();
    let is_dir = item.is_folder();
```

   ```rust
       /// An editor on `folder`, its top-left corner at `at`; the folder becomes a recent one.
       pub(crate) fn add_editor_at(
           &mut self,
           folder: &Path,
           at: Point,
           window: &mut Window,
           cx: &mut Context<Self>,
       ) -> Option<BlockId> {
           if !folder.is_dir() {
               let message = format!("{} isn't a folder", folder.display());
               eprintln!("templum: {message}");
               show_notification(window, cx, Notification::warning(message));
               return None;

       /// A folder of an editor's tree was expanded (read it, once) or collapsed.
       fn on_tree_event(
           &mut self,
           tree: &Entity<TreeState>,
           event: &TreeEvent,
           cx: &mut Context<Self>,
       ) {
           let Some(editor) = self.space.blocks.values_mut().find_map(|b| match b {
               Body::Editor(e) if e.tree == *tree => Some(e),
               _ => None,
           }) else {
               return;
           };
           match event {
               TreeEvent::Expanded(id) => {
                   let path = PathBuf::from(id.as_ref());
                   if !editor.dirs.contains_key(&path) {
                       editor.dirs.insert(path.clone(), editor::read_dir(&path));
                   }
                   editor.expanded.insert(path);
               }
               TreeEvent::Collapsed(id) => {
                   editor.expanded.remove(Path::new(id.as_ref()));
               }
           }
           editor.show(cx);
           cx.notify();
       }
   ```

```rust
/// Over this, a file opens read-only; over `TOO_BIG_OVER`, it doesn't open.
pub(crate) const READ_ONLY_OVER: u64 = 4 * 1024 * 1024;
pub(crate) const TOO_BIG_OVER: u64 = 32 * 1024 * 1024;

/// The language gpui-kit highlights `path` with: by its extension, by its name for files like
/// Makefile, "text" when it has no grammar.
pub(crate) fn lang_of(path: &Path) -> &'static str {
    let name = path.file_name().and_then(|n| n.to_str()).unwrap_or("");
    let ext = path
        .extension()
        .and_then(|e| e.to_str())
        .unwrap_or("")
        .to_ascii_lowercase();
    match (name, ext.as_str()) {
        ("Makefile" | "makefile" | "GNUmakefile", _) | (_, "mk") => "make",
        (_, "h" | "hpp" | "hh" | "cc" | "cxx") => "cpp",
        (_, "mjs" | "cjs" | "jsx") => "javascript",
        (_, "htm") => "html",
        (_, "zsh" | "bash") => "bash",
        (_, "patch") => "diff",
        // gpui-kit knows the common extensions ("rs", "ts", "md", "yml"…); the rest is text.
        _ => Language::from_str(&ext).name(),
    }
}

pub(crate) fn is_binary(bytes: &[u8]) -> bool {
    bytes.iter().take(BINARY_PROBE).any(|b| *b == 0)
}

/// "\r\n" when the first line ends that way, else "\n".
pub(crate) fn line_ending(text: &str) -> &'static str {
    match text.find('\n') {
        Some(i) if text[..i].ends_with('\r') => "\r\n",
        _ => "\n",
    }
}

/// The editor's text as the file is written: the editor works in "\n"; the file keeps its line
/// ending, and ends with a newline only if it did.
pub(crate) fn encode(edited: &str, crlf: bool, newline: bool) -> String {
    let mut out = edited.replace("\r\n", "\n");
    if newline && !out.ends_with('\n') {
        out.push('\n');
    } else if !newline && out.ends_with('\n') {
        out.pop();
    }
    if crlf { out.replace('\n', "\r\n") } else { out }
}

/// The file's modification time; None when it is gone.
pub(crate) fn mtime(path: &Path) -> Option<SystemTime> {
    std::fs::metadata(path).ok()?.modified().ok()
}

/// "812 B", "12.3 KB", "4.0 MB".
pub(crate) fn human(bytes: u64) -> String {
    const K: f64 = 1024.0;
    match bytes {
        b if b < 1024 => format!("{b} B"),
        b if b < 1024 * 1024 => format!("{:.1} KB", b as f64 / K),
        b => format!("{:.1} MB", b as f64 / (K * K)),
    }
}
```

```rust
    /// Opens `path` in a tab (or shows its tab) and returns the tab's index; Err says why it
    /// can't be opened. The tab becomes the active one.
    pub fn open_tab(
        &mut self,
        path: &Path,
        window: &mut Window,
        cx: &mut Context<Workspace>,
    ) -> Result<usize, String> {
        if let Some(i) = self.tabs.iter().position(|t| t.path == path) {
            self.active = Some(i);
            return Ok(i);
        }
        let name = path.file_name().map_or_else(
            || path.display().to_string(),
            |n| n.to_string_lossy().into_owned(),
        );
        let size = std::fs::metadata(path)
            .map_err(|e| format!("Couldn't open {name}: {e}"))?
            .len();
        if size > TOO_BIG_OVER {
            return Err(format!("{name} is over 32 MB, so Templum doesn't open it"));
        }
        let bytes = std::fs::read(path).map_err(|e| format!("Couldn't read {name}: {e}"))?;
        let (content, text) = if is_binary(&bytes) {
            (Content::Binary { size }, String::new())
        } else {
            let raw = String::from_utf8_lossy(&bytes);
            let content = Content::Text {
                crlf: line_ending(&raw) == "\r\n",
                newline: raw.ends_with('\n'),
                big: size > READ_ONLY_OVER,
            };
            (content, raw.replace("\r\n", "\n"))
        };
        let big = matches!(content, Content::Text { big: true, .. });
        let (lang, wrap) = (lang_of(path), self.wrap);
        let editor = cx.new(|cx| {
            let mut state = EditorState::new(window, cx)
                .language(lang)
                .line_number(true)
                .soft_wrap(wrap)
                .default_value(text);
            state.set_readonly(big, cx);
            state
        });
        let _edits = cx.subscribe(&editor, |ws, editor, event: &InputEvent, cx| {
            if matches!(event, InputEvent::Change) {
                ws.on_edit(&editor, cx);
            }
        });
        self.tabs.push(Tab {
            path: path.to_path_buf(),
            editor,
            content,
            dirty: false,
            mtime: mtime(path),
            conflict: false,
            preview: false,
            _edits,
        });
        self.active = Some(self.tabs.len() - 1);
        Ok(self.tabs.len() - 1)
    }

    pub fn active_tab(&self) -> Option<&Tab> {
        self.tabs.get(self.active?)
    }

    pub fn active_tab_mut(&mut self) -> Option<&mut Tab> {
        self.tabs.get_mut(self.active?)
    }

    /// Gives the keyboard to the active file's editor; false when there is none to type in.
    pub fn focus(&self, window: &mut Window, cx: &mut App) -> bool {
        match self.active_tab() {
            Some(tab) if !tab.preview && matches!(tab.content, Content::Text { .. }) => {
                tab.editor.update(cx, |e, cx| e.focus(window, cx));
                true
            }
            _ => false,
        }
    }

            .iter()
```

   ```rust
           &mut self,
           block: BlockId,
           i: usize,
           window: &mut Window,
           cx: &mut Context<Self>,
       ) {
           self.release_focus(block, window, cx);
           let Some(editor) = self.space.editor_mut(block) else {
               return;

               return;
   ```

   ```rust
           cx: &mut Context<Self>,
       ) {
           let dirty = self
               .space
               .editor(block)
               .and_then(|e| e.tabs.get(i))
               .filter(|t| t.dirty)
               .map(editor::Tab::name);
           let Some(name) = dirty else {
               self.remove_tab(block, i, window, cx);
               return;
           };
           let ws = cx.entity();
           let saver = ws.clone();
           prompt::save_or_discard(
               format!("Save {name}?"),
               "Its changes are lost otherwise.",
               move |window, cx| {
                   saver.update(cx, |ws, cx| {
                       let saved = ws.save_tab(block, i, window, cx);
                       if saved {
                           ws.remove_tab(block, i, window, cx);
                       }
                       saved
                   })
               },
               move |window, cx| ws.update(cx, |ws, cx| ws.remove_tab(block, i, window, cx)),
               window,
               cx,
           );
       }

       /// Writes one tab's file; a failure says so and the tab stays changed.
       pub(crate) fn save_tab(
           &mut self,
           block: BlockId,
           i: usize,
           window: &mut Window,
           cx: &mut Context<Self>,
       ) -> bool {
           let Some(tab) = self.space.editor_mut(block).and_then(|e| e.tabs.get_mut(i)) else {
               return true;
           };
           let result = tab.save(cx);
           let name = tab.name();
           cx.notify();
           match result {
               Ok(()) => true,
               Err(err) => {
                   let message = format!("Couldn't save {name}: {err}");
                   eprintln!("templum: {message}");
                   show_notification(window, cx, Notification::error(message));
                   false
               }
           }
       }

       /// The `save` command: the focused editor's active tab.
       fn save_active(&mut self, window: &mut Window, cx: &mut Context<Self>) {
           if let Some(block) = self.focused_editor()
               && let Some(i) = self.space.editor(block).and_then(|e| e.active)
           {
               self.save_tab(block, i, window, cx);
           }
       }

       /// Writes every changed tab of an editor block; false when one failed.
       pub(crate) fn save_all(
           &mut self,
           block: BlockId,
           window: &mut Window,
           cx: &mut Context<Self>,
       ) -> bool {
           let dirty: Vec<usize> = self
               .space
               .editor(block)
               .map(|e| {
                   e.tabs
                       .iter()
                       .enumerate()
                       .filter(|(_, t)| t.dirty)
                       .map(|(i, _)| i)
                       .collect()
               })
               .unwrap_or_default();
           dirty
               .into_iter()
               .fold(true, |ok, i| self.save_tab(block, i, window, cx) && ok)
       }

       /// Every changed tab of every workspace, on the way out; false when one failed.
       fn save_everything(&mut self, window: &mut Window, cx: &mut Context<Self>) -> bool {
           let mut failed = None;
           for space in std::iter::once(&mut self.space).chain(&mut self.others) {
               for tab in space
                   .blocks
                   .values_mut()
                   .filter_map(|b| b.editor_mut())
                   .flat_map(|e| e.tabs.iter_mut())
                   .filter(|t| t.dirty)
               {
                   if let Err(err) = tab.save(cx) {
                       failed.get_or_insert(format!("Couldn't save {}: {err}", tab.name()));
                   }
               }
           }
           cx.notify();
           match failed {
               Some(message) => {
                   eprintln!("templum: {message}");
                   show_notification(window, cx, Notification::error(message));
                   false
               }
               None => true,
           }
       }

               .flat_map(|e| e.tabs.iter())
               .filter(|t| t.dirty)
   ```

```rust
    /// Reads the file again into the editor, keeping the cursor's line. False when it can't be
    /// read.
    pub fn reload(&mut self, window: &mut Window, cx: &mut App) -> bool {
        let Ok(bytes) = std::fs::read(&self.path) else {
            return false;
        };
        let raw = String::from_utf8_lossy(&bytes);
        if let Content::Text { crlf, newline, .. } = &mut self.content {
            *crlf = line_ending(&raw) == "\r\n";
            *newline = raw.ends_with('\n');
        }
        let text = raw.replace("\r\n", "\n");
        self.editor.update(cx, |e, cx| {
            let line = e.cursor_position().line;
            e.set_value(text, window, cx);
            // Not set_cursor_position: that would take the keyboard from whatever has it.
            let offset = e.text().position_to_offset(&Position { line, character: 0 });
            e.set_selected_range(offset..offset, cx);
        });
        self.dirty = false;
        self.conflict = false;
        self.mtime = mtime(&self.path);
        true
    }
```

   ```rust
       /// gone one is marked changed so Save brings it back; and the focused editor's tree is
       /// read again once TREE_REFRESH has passed. Only the workspace on screen: hidden ones catch
       /// up when shown.
       fn check_files(&mut self, window: &mut Window, cx: &mut Context<Self>) {
           let focused = self.space.focused;
           let mut changed = false;
           for (id, body) in &mut self.space.blocks {
               let Body::Editor(editor) = body else {
                   continue;
               };
               for tab in &mut editor.tabs {
                   let now = editor::mtime(&tab.path);
                   if now == tab.mtime {
                       continue;
                   }
                   match (now, tab.dirty) {
                       (None, _) => {
                           tab.dirty = true;
                           tab.mtime = None;
                       }
                       (Some(_), false) => {
                           tab.reload(window, cx);
                       }
                       (Some(_), true) => {
                           tab.conflict = true;
                           tab.mtime = now;
                       }
                   }
                   changed = true;
               }
               if focused == Some(*id) && editor.tree_read.elapsed() >= editor::TREE_REFRESH {
                   changed |= editor.refresh(cx);
               }
           }
           if changed {
               cx.notify();
           }
       }

       pub(crate) fn reload_tab(
           &mut self,
           block: BlockId,
           i: usize,

       ) {
           if let Some(tab) = self.space.editor_mut(block).and_then(|e| e.tabs.get_mut(i)) {
   ```

```rust
    pub fn place_beside(&self, anchor: Rect, size: Size) -> Rect {
        let mut p = Point::new(anchor.x + anchor.w + BESIDE, anchor.y);
        while self
            .blocks
            .iter()
```

```rust
    pub(crate) fn refresh_tree(&mut self, block: BlockId, cx: &mut Context<Self>) {
        if let Some(editor) = self.space.editor_mut(block) {
            editor.refresh(cx);
            cx.notify();
        }
    }

    /// Creates a file (and opens it) or a folder in `dir`; false (the dialog stays) for an empty
    /// name or one with a separator. A name already taken says so.
    pub(crate) fn new_entry(
        &mut self,
        block: BlockId,
        dir: &Path,
        folder: bool,
        name: &str,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) -> bool {
        let name = name.trim();
        if name.is_empty() || name.contains(['/', '\\']) {
            return false;
        }
        let path = dir.join(name);
        let made = if folder {
            std::fs::create_dir(&path)
        } else {
            std::fs::OpenOptions::new()
                .write(true)
                .create_new(true)
                .open(&path)
                .map(|_| ())
        };
        if let Err(err) = made {
            let message = format!("Couldn't create {name}: {err}");
            eprintln!("templum: {message}");
            show_notification(window, cx, Notification::warning(message));
            return false;
        }
        if let Some(editor) = self.space.editor_mut(block) {
            editor.expanded.insert(dir.to_path_buf());
        }
        self.refresh_tree(block, cx);
        if !folder {
            self.open_file(block, &path, None, window, cx);
        }
        true
    }

    /// Renames a file or folder in place; open tabs under it follow it.
    pub(crate) fn rename_entry(
        &mut self,
        block: BlockId,
        path: &Path,
        name: &str,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) -> bool {
        let name = name.trim();
        if name.is_empty() || name.contains(['/', '\\']) {
            return false;
        }
        let to = path.with_file_name(name);
        if let Err(err) = std::fs::rename(path, &to) {
            let message = format!("Couldn't rename {}: {err}", path.display());
            eprintln!("templum: {message}");
            show_notification(window, cx, Notification::warning(message));
            return false;
        }
        if let Some(editor) = self.space.editor_mut(block) {
            for tab in &mut editor.tabs {
                if let Some(moved) = editor::moved(&tab.path, path, &to) {
                    tab.path = moved;
                }
            }
            editor.expanded = editor
                .expanded
                .drain()
                .map(|d| editor::moved(&d, path, &to).unwrap_or(d))
                .collect();
        }
        self.refresh_tree(block, cx);
        true
    }

    /// Deletes a file, or a folder with everything in it; tabs on what was deleted close.
    pub(crate) fn delete_entry(
        &mut self,
        block: BlockId,
        path: &Path,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let removed = if path.is_dir() {
            std::fs::remove_dir_all(path)
        } else {
            std::fs::remove_file(path)
        };
        if let Err(err) = removed {
            let message = format!("Couldn't delete {}: {err}", path.display());
            eprintln!("templum: {message}");
            show_notification(window, cx, Notification::warning(message));
            return;
        }
        let gone: Vec<usize> = self
            .space
            .editor(block)
            .map(|e| {
                e.tabs
                    .iter()
                    .enumerate()
                    .filter(|(_, t)| t.path.starts_with(path))
                    .map(|(i, _)| i)
                    .collect()
            })
            .unwrap_or_default();
        // Highest first, so the lower indices stay right.
        for i in gone.into_iter().rev() {
            self.remove_tab(block, i, window, cx);
        }
        self.refresh_tree(block, cx);
    }

    /// A terminal in `folder`, placed to the right of the editor block.
    pub(crate) fn terminal_beside(
        &mut self,
        block: BlockId,
        folder: &Path,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let Some(anchor) = self.space.canvas.get(block).map(|b| b.rect) else {
            return;
        };
        self.space.pristine = false;
        let size = chrome::block_size(DEFAULT_COLS, DEFAULT_ROWS, self.cell.size);
        let rect = self.space.canvas.place_beside(anchor, size);
        self.spawn_block(rect, Some(folder.to_path_buf()), window, cx);
        window.focus(&self.focus_handle, cx);
    }
```

```rust
    /// Opens `path` (at `line`, 1-based) in an editor of this workspace: one whose folder holds
    /// the file, else any, else a new one on `folder` at the viewport's center. The camera flies
    /// there if the block is off screen.
    pub(crate) fn open_in_editor(
        &mut self,
        folder: &Path,
        path: &Path,
        line: Option<u32>,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let holding = |b: &Body| b.editor().is_some_and(|e| path.starts_with(&e.folder));
        let found = self
            .space
            .blocks
            .iter()
            .find(|(_, b)| holding(b))
            .or_else(|| self.space.blocks.iter().find(|(_, b)| b.editor().is_some()))
            .map(|(id, _)| *id);
        let id = found.or_else(|| {
            let center = self.space.canvas.camera.to_world(self.center(window));
            let size = editor::SIZE;
            let at = self
                .space
                .canvas
                .place_new(
                    size,
                    Point::new(center.x - size.w / 2.0, center.y - size.h / 2.0),
                )
                .origin();
            self.add_editor_at(folder, at, window, cx)
        });
        let Some(id) = id else {
            return;
        };
        self.open_file(id, path, line, window, cx);
        let space = self.space.id.clone();
        self.reveal(&space, id, window, cx);
    }

    /// The `go_to_line` command: a line number, then the cursor goes there.
    fn go_to_line(&mut self, window: &mut Window, cx: &mut Context<Self>) {
        let Some(block) = self.focused_editor() else {
            return;
        };
        let Some(path) = self
            .space
            .editor(block)
            .and_then(|e| e.active_tab())
            .filter(|t| matches!(t.content, editor::Content::Text { .. }))
            .map(|t| t.path.clone())
        else {
            return;
        };
        let ws = cx.entity();
        prompt::ask_text(
            "Go to line",
            "Go",
            "",
            move |text, window, cx| {
                let Ok(line) = text.trim().parse::<u32>() else {
                    return false;
                };
                ws.update(cx, |ws, cx| {
                    ws.open_file(block, &path, Some(line), window, cx)
                });
                true
            },
            window,
            cx,
        );
    }
```

`reveal` switches to the space (a no-op here), focuses the block and flies when it is off screen; `open_file` already focused the tab's editor, and `reveal`'s `focus_block` keeps it there (`focus_inner`). `run` gets `Command::GoToLine => self.go_to_line(window, cx),`.
