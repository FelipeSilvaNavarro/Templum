# Git block v2, batch 1: the diff panel — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Changes tab's one-file read-only editor with the spec's diff panel: every working change in
one scroll (Changes, then Staged), Unified, with file and hunk rows, old and new line numbers, the file's language
colors, changed words, folded unchanged stretches, special files, text selection and copy.

**Architecture:** `templum-git` gains a pure parser of `git diff` output (`diff.rs`), word diffs (`words.rs`)
and `Repo::working_diff`, which reads both sides and the untracked files in one background job. `templum` gains
`git_block/diff_view/`: a rows model built from the files (pure, unit-tested), a highlight cache (one
`SyntaxHighlighter` per language, styles kept per hunk), a selection model, and rows drawn in a `uniform_list`
whose line rows paint with `canvas` + `shape_line`. The block's 2-second poll reads the whole working diff; a
result equal to the shown one changes nothing.

**Tech Stack:** Rust 2024, GPUI through gpui-kit `=0.7.1` (`uniform_list`, `canvas`, `shape_line`,
`SyntaxHighlighter`, `Rope`), the user's `git` run by `templum-git`.

**Spec:** `docs/specs/git.md` — section 1 (Zoom), section 2 (The diff panel), section 3 (Left column, Diff panel,
Open in editor), Architecture (`diff.rs`, `words.rs`, `repo.rs`, `git_block/diff_view/`, Data flow), Error
handling, Testing, Performance; Delivery, batch 1. Batches 2 to 6 get their own plans after this one ships.

## Review Focus

1. **A path with spaces or non-ASCII letters** (`café.txt`, `with space.txt`): git quotes it unless
   `core.quotePath=false`, and adds a tab after it on `---`/`+++` lines. The file row must show the name as
   typed. Pinned in Task 1 (parser) and Task 3 (`-c core.quotePath=false`).
2. **A CRLF file:** every line ends in `\r`. The parser keeps it (batch 2's patches need it back), the panel
   never draws it, and changed words still pair. Pinned in Task 1 and Task 7 (`display`).
3. **A merge conflict in progress:** `git diff` prints `diff --cc` with `@@@` hunks. The parser skips them and the
   panel draws the rest. Pinned in Task 1 and Task 3.
4. **A file the agent changes between the status read and the diff read:** a file row with no status entry
   must still draw (its badge from the diff), and a status entry with no diff must not panic. Pinned in Task 5.
5. **A block whose folder changes, or whose tree becomes clean:** the old rows, selection and highlight cache
   must go, and the panel says "Nothing changed since the last commit". Pinned in Task 5.

```rust
use crate::parse::Change;

/// Past this many changed lines a file is folded by default (with Show diff).
pub const LARGE: u32 = 2000;

/// One file of a diff, as `git diff` prints it.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct FileDiff {
    /// The path before (a rename's old one); None for a new file.
    pub old_path: Option<String>,
    /// The path after; None for a deleted file.
    pub new_path: Option<String>,
    pub status: Change,
    pub binary: bool,
    /// `old mode 100644` → `new mode 100755`.
    pub mode: Option<(String, String)>,
    pub hunks: Vec<Hunk>,
    /// Its diff was longer than the limit: the hunks were dropped.
    pub too_large: bool,
    /// The working file's size and line count, counted by `Repo::working_diff`; None when the
    /// file is gone or wasn't counted.
    pub bytes: Option<u64>,
    pub lines: Option<u32>,
}

impl FileDiff {
    pub fn empty() -> FileDiff {
        FileDiff {
            old_path: None,
            new_path: None,
            status: Change::Modified,
            binary: false,
            mode: None,
            hunks: Vec::new(),
            too_large: false,
            bytes: None,
            lines: None,
        }
    }

    /// The path now (the old one for a deleted file).
    pub fn path(&self) -> &str {
        self.new_path
            .as_deref()
            .or(self.old_path.as_deref())
            .unwrap_or("")
    }

    fn count(&self, kind: Kind) -> u32 {
        self.hunks
            .iter()
            .flat_map(|h| &h.lines)
            .filter(|l| l.kind == kind)
            .count() as u32
    }

    pub fn added(&self) -> u32 {
        self.count(Kind::Added)
    }

    pub fn removed(&self) -> u32 {
        self.count(Kind::Removed)
    }

    pub fn changed(&self) -> u32 {
        self.added() + self.removed()
    }

    /// A lock file, a minified file or a source map.
    pub fn generated(&self) -> bool {
        let name = self.path().rsplit('/').next().unwrap_or("");
        matches!(
            name,
            "Cargo.lock" | "package-lock.json" | "yarn.lock" | "pnpm-lock.yaml"
        ) || name.ends_with(".min.js")
            || name.ends_with(".min.css")
            || name.ends_with(".map")
    }

    /// Folded by default, with Show diff: generated, or over `LARGE` changed lines.
    pub fn large(&self) -> bool {
        self.generated() || self.changed() > LARGE
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Hunk {
    pub old_start: u32,
    pub old_len: u32,
    pub new_start: u32,
    pub new_len: u32,
    /// What git names after `@@ … @@`: the function or heading, often empty.
    pub context: String,
    pub lines: Vec<Line>,
}

impl Hunk {
    /// Where it is: git's context, else "Lines 12–20" (the new side).
    pub fn title(&self) -> String {
        if !self.context.is_empty() {
            return self.context.clone();
        }
        let end = self.new_start + self.new_len.saturating_sub(1);
        if end > self.new_start {
            format!("Lines {}–{end}", self.new_start)
        } else {
            format!("Line {}", self.new_start)
        }
    }

    /// Removed lines paired with the added lines right after them, the i-th with the i-th:
    /// indices into `lines`. The pairs are what the changed words are computed on.
    pub fn pairs(&self) -> Vec<(usize, usize)> {
        let mut pairs = Vec::new();
        let mut i = 0;
        while i < self.lines.len() {
            if self.lines[i].kind != Kind::Removed {
                i += 1;
                continue;
            }
            let removed = i;
            while i < self.lines.len() && self.lines[i].kind == Kind::Removed {
                i += 1;
            }
            let added = i;
            while i < self.lines.len() && self.lines[i].kind == Kind::Added {
                i += 1;
            }
            for k in 0..(added - removed).min(i - added) {
                pairs.push((removed + k, added + k));
            }
        }
        pairs
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Kind {
    Context,
    Added,
    Removed,
}

impl Kind {
    /// The gutter's sign, and the line's first byte in a patch.
    pub fn sign(self) -> char {
        match self {
            Kind::Context => ' ',
            Kind::Added => '+',
            Kind::Removed => '-',
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Line {
    pub kind: Kind,
    pub old_no: Option<u32>,
    pub new_no: Option<u32>,
    /// Without its leading sign and its '\n'; a CRLF file's lines keep their '\r'.
    pub text: String,
    /// "\ No newline at end of file" followed it.
    pub no_newline: bool,
}

/// `git diff --no-color` output into files. A file whose text is longer than `limit` bytes keeps
/// its headers and drops its hunks (`too_large`). Combined diffs (`diff --cc`, a conflicted
/// file) are skipped.
pub fn parse_diff(text: &str, limit: usize) -> Vec<FileDiff> {
    let mut files: Vec<FileDiff> = Vec::new();
    // Where the open file's section started, for the limit; None while skipping.
    let mut start: Option<usize> = None;
    let mut offset = 0;
    // The next line numbers of the open hunk.
    let (mut old_next, mut new_next) = (0u32, 0u32);
    for raw in text.split_inclusive('\n') {
        let at = offset;
        offset += raw.len();
        let line = raw.strip_suffix('\n').unwrap_or(raw);
        if let Some(rest) = line.strip_prefix("diff --git ") {
            let (old, new) = git_header_paths(rest);
            let mut file = FileDiff::empty();
            file.old_path = Some(old);
            file.new_path = Some(new);
            files.push(file);
            start = Some(at);
            continue;
        }
        if line.starts_with("diff --cc ") || line.starts_with("diff --combined ") {
            start = None;
            continue;
        }
        let Some(from) = start else {
            continue;
        };
        let file = files.last_mut().expect("opened by diff --git");
        if offset - from > limit {
            file.hunks.clear();
            file.too_large = true;
            start = None;
            continue;
        }
        if let Some(rest) = line.strip_prefix("@@ ") {
            if let Some(hunk) = parse_hunk_header(rest) {
                (old_next, new_next) = (hunk.old_start, hunk.new_start);
                file.hunks.push(hunk);
            }
            continue;
        }
        if let Some(hunk) = file.hunks.last_mut() {
            let (kind, text) = match line.as_bytes().first() {
                Some(b' ') => (Kind::Context, &line[1..]),
                Some(b'+') => (Kind::Added, &line[1..]),
                Some(b'-') => (Kind::Removed, &line[1..]),
                Some(b'\\') => {
                    if let Some(last) = hunk.lines.last_mut() {
                        last.no_newline = true;
                    }
                    continue;
                }
                _ => continue,
            };
            let (old_no, new_no) = match kind {
                Kind::Context => (Some(old_next), Some(new_next)),
                Kind::Added => (None, Some(new_next)),
                Kind::Removed => (Some(old_next), None),
            };
            old_next += u32::from(old_no.is_some());
            new_next += u32::from(new_no.is_some());
            hunk.lines.push(Line {
                kind,
                old_no,
                new_no,
                text: text.to_string(),
                no_newline: false,
            });
            continue;
        }
        // The headers before the first hunk.
        if let Some(mode) = line.strip_prefix("old mode ") {
            file.mode = Some((mode.to_string(), String::new()));
        } else if let Some(mode) = line.strip_prefix("new mode ") {
            if let Some(m) = &mut file.mode {
                m.1 = mode.to_string();
            }
        } else if line.starts_with("new file mode ") {
            file.status = Change::Added;
            file.old_path = None;
        } else if line.starts_with("deleted file mode ") {
            file.status = Change::Deleted;
            file.new_path = None;
        } else if let Some(from) = line.strip_prefix("rename from ") {
            file.status = Change::Renamed;
            file.old_path = Some(from.to_string());
        } else if let Some(to) = line.strip_prefix("rename to ") {
            file.new_path = Some(to.to_string());
        } else if let Some(from) = line.strip_prefix("copy from ") {
            file.status = Change::Added;
            file.old_path = Some(from.to_string());
        } else if let Some(to) = line.strip_prefix("copy to ") {
            file.new_path = Some(to.to_string());
        } else if let Some(p) = line.strip_prefix("--- ") {
            if let Some(p) = named(p, "a/") {
                file.old_path = Some(p);
            }
        } else if let Some(p) = line.strip_prefix("+++ ") {
            if let Some(p) = named(p, "b/") {
                file.new_path = Some(p);
            }
        } else if line.starts_with("Binary files ") || line == "GIT binary patch" {
            file.binary = true;
        }
    }
    files
}

/// "a/x b/x" → ("x", "x"): the split where both halves agree (a name with spaces), else the
/// first " b/". A rename's halves are set again by its `rename from` and `rename to` lines.
fn git_header_paths(rest: &str) -> (String, String) {
    let rest = rest.strip_prefix("a/").unwrap_or(rest);
    let mut first = None;
    for (i, _) in rest.match_indices(" b/") {
        let (left, right) = (&rest[..i], &rest[i + 3..]);
        if left == right {
            return (left.to_string(), right.to_string());
        }
        first.get_or_insert((left.to_string(), right.to_string()));
    }
    first.unwrap_or_else(|| (rest.to_string(), rest.to_string()))
}

/// A `---`/`+++` line's path: without its prefix and the tab git adds after a name with
/// spaces; None for /dev/null.
fn named(p: &str, prefix: &str) -> Option<String> {
    p.trim_end_matches('\t')
        .strip_prefix(prefix)
        .map(str::to_string)
}

/// "-10,3 +12,4 @@ fn x() {" (after "@@ "); a missing length is 1.
fn parse_hunk_header(rest: &str) -> Option<Hunk> {
    let rest = rest.strip_prefix('-')?;
    let (old, rest) = rest.split_once(" +")?;
    let (new, rest) = rest.split_once(" @@")?;
    let range = |s: &str| -> Option<(u32, u32)> {
        match s.split_once(',') {
            Some((a, b)) => Some((a.parse().ok()?, b.parse().ok()?)),
            None => Some((s.parse().ok()?, 1)),
        }
    };
    let ((old_start, old_len), (new_start, new_len)) = (range(old)?, range(new)?);
    Some(Hunk {
        old_start,
        old_len,
        new_start,
        new_len,
        context: rest.trim().to_string(),
        lines: Vec::new(),
    })
}

/// An untracked file as a new file's diff, so the panel shows it like any other (git has no
/// diff for it): every line added.
pub fn new_file_diff(path: &str, text: &str) -> String {
    let lines: Vec<&str> = text.split_inclusive('\n').collect();
    let mut out = format!(
        "diff --git a/{path} b/{path}\nnew file mode 100644\n--- /dev/null\n+++ b/{path}\n@@ -0,0 +1,{} @@\n",
        lines.len()
    );
    for line in lines {
        out.push('+');
        out.push_str(line);
        if !line.ends_with('\n') {
            out.push_str("\n\\ No newline at end of file\n");
        }
    }
    out
}

/// An untracked binary file as a new file's diff.
pub fn new_binary_diff(path: &str) -> String {
    format!(
        "diff --git a/{path} b/{path}\nnew file mode 100644\nBinary files /dev/null and b/{path} differ\n"
    )
}
```

```rust
/// Past this many tokens on a side the lines are marked whole: the table is tokens × tokens.
const CAP: usize = 400;

/// The byte ranges of `old` and of `new` that differ.
pub fn changed(old: &str, new: &str) -> (Vec<Range<usize>>, Vec<Range<usize>>) {
    let (a, b) = (tokens(old), tokens(new));
    if a.len() > CAP || b.len() > CAP {
        return (whole(old), whole(new));
    }
    let (n, m) = (a.len(), b.len());
    // lcs[i][j]: the longest common subsequence of a[i..] and b[j..].
    let mut lcs = vec![vec![0u16; m + 1]; n + 1];
    for i in (0..n).rev() {
        for j in (0..m).rev() {
            lcs[i][j] = if old[a[i].clone()] == new[b[j].clone()] {
                lcs[i + 1][j + 1] + 1
            } else {
                lcs[i + 1][j].max(lcs[i][j + 1])
            };
        }
    }
    let (mut common_a, mut common_b) = (vec![false; n], vec![false; m]);
    let (mut i, mut j) = (0, 0);
    while i < n && j < m {
        if old[a[i].clone()] == new[b[j].clone()] {
            common_a[i] = true;
            common_b[j] = true;
            i += 1;
            j += 1;
        } else if lcs[i + 1][j] >= lcs[i][j + 1] {
            i += 1;
        } else {
            j += 1;
        }
    }
    (ranges(&a, &common_a), ranges(&b, &common_b))
}

fn whole(s: &str) -> Vec<Range<usize>> {
    if s.is_empty() {
        Vec::new()
    } else {
        vec![0..s.len()]
    }
}

/// The tokens that aren't common, adjacent ones merged.
fn ranges(tokens: &[Range<usize>], common: &[bool]) -> Vec<Range<usize>> {
    let mut out: Vec<Range<usize>> = Vec::new();
    for (t, &c) in tokens.iter().zip(common) {
        if c {
            continue;
        }
        match out.last_mut() {
            Some(last) if last.end == t.start => last.end = t.end,
            _ => out.push(t.clone()),
        }
    }
    out
}

#[derive(PartialEq)]
enum Class {
    Word,
    Space,
    Other,
}

fn tokens(s: &str) -> Vec<Range<usize>> {
    let class = |c: char| {
        if c.is_alphanumeric() || c == '_' {
            Class::Word
        } else if c.is_whitespace() {
            Class::Space
        } else {
            Class::Other
        }
    };
    let mut out: Vec<Range<usize>> = Vec::new();
    let mut last: Option<Class> = None;
    for (i, c) in s.char_indices() {
        let k = class(c);
        let end = i + c.len_utf8();
        match out.last_mut() {
            Some(t) if k != Class::Other && last.as_ref() == Some(&k) => t.end = end,
            _ => out.push(i..end),
        }
        last = Some(k);
    }
    out
}
```

```rust
    ) -> Result<WorkingDiff, GitError> {
        let mut unstaged = self.side_diff(false, ignore_whitespace, whole)?;
        for e in status
            .entries
            .iter()
            .filter(|e| e.unstaged == Some(Change::Untracked))
        {
            unstaged.push(self.untracked_diff(&e.path));
        }
        let staged = self.side_diff(true, ignore_whitespace, whole)?;
        let mut all = WorkingDiff { unstaged, staged };
        for file in all.unstaged.iter_mut().chain(all.staged.iter_mut()) {
            self.count(file);
        }
        Ok(all)
    }

    fn side_diff(
        &self,
        staged: bool,
        ignore_whitespace: bool,
        whole: &[(bool, String)],
    ) -> Result<Vec<FileDiff>, GitError> {
        // quotePath off: a name with non-ASCII letters comes as itself, not as "caf\303\251".
        let mut args = vec!["-c", "core.quotePath=false", "diff", "--no-color", "-M"];
        if staged {
            args.push("--cached");
        }
        if ignore_whitespace {
            args.push("-w");
        }
        let mut files = parse_diff(&self.text(&args)?, DIFF_LIMIT);
        for (_, path) in whole.iter().filter(|(s, _)| *s == staged) {
            let Some(i) = files.iter().position(|f| f.path() == path) else {
                continue;
            };
            let mut args = args.clone();
            args.push(WHOLE);
            args.push("--");
            if files[i].status == Change::Renamed
                && let Some(from) = files[i].old_path.as_deref()
            {
                args.push(from);
            }
            args.push(path);
            if let Some(file) = parse_diff(&self.text(&args)?, DIFF_LIMIT).pop() {
                files[i] = file;
            }
        }
        Ok(files)
    }

    /// An untracked file as a new file's diff: its text as added lines; binary, or too large
    /// past `DIFF_LIMIT` (not read).
    fn untracked_diff(&self, path: &str) -> FileDiff {
        let full = self.root.join(path);
        let size = std::fs::metadata(&full).map_or(0, |m| m.len());
        if size > DIFF_LIMIT as u64 {
            let mut file = FileDiff::empty();
            file.new_path = Some(path.to_string());
            file.status = Change::Added;
            file.too_large = true;
            return file;
        }
        let bytes = std::fs::read(&full).unwrap_or_default();
        let text = if bytes.iter().take(8 * 1024).any(|b| *b == 0) {
            diff::new_binary_diff(path)
        } else {
            diff::new_file_diff(path, &String::from_utf8_lossy(&bytes))
        };
        parse_diff(&text, DIFF_LIMIT).pop().expect("one file")
    }

    /// The working file's size and line count: the file row's "12 KB", and the fold after
    /// its last hunk.
    fn count(&self, file: &mut FileDiff) {
        let Some(path) = &file.new_path else {
            return;
        };
        let full = self.root.join(path);
        let Ok(meta) = std::fs::metadata(&full) else {
            return;
        };
        file.bytes = Some(meta.len());
        if file.binary || file.too_large || meta.len() > DIFF_LIMIT as u64 {
            return;
        }
        // ponytail: reads every changed file on each poll to count its lines; cache by mtime
        // if a tree with many large changed files stalls the background executor.
        if let Ok(bytes) = std::fs::read(&full) {
            let n = bytes.iter().filter(|b| **b == b'\n').count()
                + usize::from(!bytes.is_empty() && !bytes.ends_with(b"\n"));
            file.lines = Some(n as u32);
        }
    }
}
```

```rust
/// One file in the panel: in the Changes section (unstaged, untracked too) or in Staged.
#[derive(Clone, Debug, PartialEq, Eq)]
pub(crate) struct Shown {
    pub staged: bool,
    pub diff: FileDiff,
}

impl Shown {
    /// What the folded, large-shown and whole sets are keyed by.
    pub fn key(&self) -> (bool, String) {
        (self.staged, self.diff.path().to_string())
    }

    /// Digits of the largest line number shown, for the number columns.
    pub fn digits(&self) -> usize {
        let last = self.diff.hunks.last().map_or(1, |h| {
            (h.old_start + h.old_len).max(h.new_start + h.new_len)
        });
        last.max(1).to_string().len()
    }

    /// The first hunk's first line on the new side: where Open in editor goes.
    pub fn first_line(&self) -> u32 {
        self.diff
            .hunks
            .first()
            .map_or(1, |h| h.new_start.max(1))
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub(crate) enum Row {
    /// "Changes · 3 files" or "Staged · 1 file".
    Section { staged: bool, files: usize },
    File { file: usize },
    Hunk { file: usize, hunk: usize },
    Line { file: usize, hunk: usize, line: usize },
    /// "⋯ 40 unchanged lines": before the first hunk, between two, after the last.
    Fold { file: usize, lines: u32 },
    Note { file: usize, note: Note },
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(crate) enum Note {
    Binary,
    TooLarge,
    /// Large or generated: folded until Show diff.
    Large,
    Mode,
}

impl Row {
    /// The file the row belongs to; None for a section heading.
    pub fn file(&self) -> Option<usize> {
        match self {
            Row::Section { .. } => None,
            Row::File { file }
            | Row::Hunk { file, .. }
            | Row::Line { file, .. }
            | Row::Fold { file, .. }
            | Row::Note { file, .. } => Some(*file),
        }
    }
}

/// The rows for `files`: each section's heading, then each file's row and, unless folded, what
/// it holds. A section with no file is left out.
pub(crate) fn rows(
    files: &[Shown],
    folded: &HashSet<(bool, String)>,
    large_shown: &HashSet<(bool, String)>,
) -> Vec<Row> {
    let mut rows = Vec::new();
    for staged in [false, true] {
        let in_section: Vec<usize> = files
            .iter()
            .enumerate()
            .filter(|(_, s)| s.staged == staged)
            .map(|(i, _)| i)
            .collect();
        if in_section.is_empty() {
            continue;
        }
        rows.push(Row::Section {
            staged,
            files: in_section.len(),
        });
        for file in in_section {
            rows.push(Row::File { file });
            let shown = &files[file];
            if folded.contains(&shown.key()) {
                continue;
            }
            let d = &shown.diff;
            if d.too_large {
                rows.push(Row::Note { file, note: Note::TooLarge });
                continue;
            }
            if d.binary {
                rows.push(Row::Note { file, note: Note::Binary });
                continue;
            }
            if d.mode.is_some() {
                rows.push(Row::Note { file, note: Note::Mode });
            }
            if d.large() && !large_shown.contains(&shown.key()) {
                rows.push(Row::Note { file, note: Note::Large });
                continue;
            }
            // The last old line a hunk showed: the gap to the next hunk is folded.
            let mut shown_to = 0;
            for (hunk, h) in d.hunks.iter().enumerate() {
                let gap = h.old_start.saturating_sub(shown_to + 1);
                if gap > 0 {
                    rows.push(Row::Fold { file, lines: gap });
                }
                rows.push(Row::Hunk { file, hunk });
                rows.extend((0..h.lines.len()).map(|line| Row::Line { file, hunk, line }));
                shown_to = h.old_start + h.old_len.saturating_sub(1);
            }
            if let (Some(last), Some(total)) = (d.hunks.last(), d.lines) {
                let end = last.new_start + last.new_len.saturating_sub(1);
                if total > end {
                    rows.push(Row::Fold { file, lines: total - end });
                }
            }
        }
    }
    rows
}
```

```rust
pub(crate) fn row_height(z: f32) -> f32 {

/// A line row as it was last painted: its shaped text and where the text starts, so the

pub(crate) struct Shaped {
    pub line: ShapedLine,
    pub x: Pixels,

pub(crate) struct DiffPanel {
    /// The files shown, Changes then Staged (an Rc: the list's closure holds them).
    pub files: Rc<Vec<Shown>>,
    pub rows: Rc<Vec<Row>>,
    /// Files whose row alone shows.
    pub folded: HashSet<(bool, String)>,
    /// Large or generated files the user asked to see.
    pub large_shown: HashSet<(bool, String)>,
    /// Files read with every line as context (a fold was clicked).
    pub whole: Vec<(bool, String)>,
    /// `git diff -w`.
    pub ignore_ws: bool,
    pub scroll: UniformListScrollHandle,
    /// The row height when the list was last drawn (`keep_list_rows`).
    pub last_row: Cell<f32>,
    /// The line rows painted in the last frame, by row index.
    pub shaped: Rc<RefCell<HashMap<usize, Shaped>>>,
    /// Diffs taken so far (the tests count them).
    pub reads: u64,
}

impl DiffPanel {
    pub fn new() -> DiffPanel {
        DiffPanel {
            files: Rc::new(Vec::new()),
            rows: Rc::new(Vec::new()),
            folded: HashSet::new(),
            large_shown: HashSet::new(),
            whole: Vec::new(),
            ignore_ws: false,
            scroll: UniformListScrollHandle::new(),
            last_row: Cell::new(0.0),
            shaped: Rc::new(RefCell::new(HashMap::new())),
            reads: 0,
        }
    }

    /// Takes a read. False when it equals what is shown: nothing changes, so the scroll, the
    /// selection and the colors stay (the spec's data flow).
    pub fn set(&mut self, diff: WorkingDiff) -> bool {
        let files: Vec<Shown> = diff
            .unstaged
            .into_iter()
            .map(|diff| Shown {
                staged: false,
                diff,
            })
            .chain(diff.staged.into_iter().map(|diff| Shown { staged: true, diff }))
            .collect();
        if *self.files == files {
            return false;
        }
        let keys: HashSet<(bool, String)> = files.iter().map(Shown::key).collect();
        self.folded.retain(|k| keys.contains(k));
        self.large_shown.retain(|k| keys.contains(k));
        self.whole.retain(|k| keys.contains(k));
        self.files = Rc::new(files);
        self.rebuild();
        true
    }

    /// The rows again: after a fold, a Show diff.
    pub fn rebuild(&mut self) {
        self.rows = Rc::new(rows(&self.files, &self.folded, &self.large_shown));
    }

    pub fn is_empty(&self) -> bool {
        self.files.is_empty()
    }

    /// The row of a file's heading.
    pub fn row_of(&self, staged: bool, path: &str) -> Option<usize> {
        self.rows.iter().position(|r| {
            matches!(r, Row::File { file }
                if self.files[*file].staged == staged && self.files[*file].diff.path() == path)
        })
    }

    /// Where Open in editor goes for a file shown.
    pub fn first_line(&self, staged: bool, path: &str) -> Option<u32> {
        self.files
            .iter()
            .find(|s| s.staged == staged && s.diff.path() == path)
            .map(Shown::first_line)
    }

    /// "Working changes · 4 files · +120 −30".
    pub fn title(&self) -> String {
        let added: u32 = self.files.iter().map(|s| s.diff.added()).sum();
        let removed: u32 = self.files.iter().map(|s| s.diff.removed()).sum();
        let paths: HashSet<&str> = self.files.iter().map(|s| s.diff.path()).collect();
        format!(
            "Working changes · {} · +{added} −{removed}",
            files_word(paths.len())
        )
    }

    /// The file whose rows are at the top of the scroll: the sticky title.
    pub fn top_file(&self, row_h: f32) -> Option<usize> {
        let base = self.scroll.0.borrow().base_handle.clone();
        let top = (-f32::from(base.offset().y) / row_h).floor().max(0.0) as usize;
        self.rows.get(top.min(self.rows.len().checked_sub(1)?))?.file()
    }
}

        "1 file".to_string()
    } else {
        format!("{n} files")
    }
}
```

```rust
/// Paints one line: its background, the changed words, the selection, the numbers, the sign
/// and the text. Returns the shaped text and where it starts.
pub(super) fn paint_line(
    p: &LinePaint,
    bounds: Bounds<Pixels>,
    window: &mut Window,
    cx: &mut App,
) -> (gpui_kit::ShapedLine, Pixels) {
    let (x0, y) = (bounds.origin.x, bounds.origin.y);
    // Columns: [1][old][1][new][1][sign][1][text].
    let col = |c: usize| x0 + px(p.cw * c as f32);
    let text_x = col(2 * p.digits + 5);
    if let Some(bg) = p.bg {
        window.paint_quad(fill(bounds, bg));
    }
    let runs = runs(&p.text, &p.colors, &p.font, p.ui.title);
    let line = window
        .text_system()
        .shape_line(p.text.clone(), px(p.size), &runs, None);
    let span = |r: &Range<usize>| {
        let (a, b) = (line.x_for_index(r.start), line.x_for_index(r.end));
        Bounds::new(point(text_x + a, y), size(b - a, bounds.size.height))
    };
    for r in p.marks.iter() {
        window.paint_quad(fill(span(r), p.mark));
    }
    if let Some(r) = p.selection.as_ref().filter(|r| r.start < r.end) {
        window.paint_quad(fill(span(r), p.ui.selection));
    }
    let mut dim = |s: String, at: usize| {
        let s: SharedString = s.into();
        let run = TextRun {
            len: s.len(),
            font: p.font.clone(),
            color: p.ui.title_dim,
            background_color: None,
            underline: None,
            strikethrough: None,
        };
        let l = window.text_system().shape_line(s, px(p.size), &[run], None);
        let _ = l.paint(point(col(at), y), px(p.row_h), TextAlign::Left, None, window, cx);
    };
    if let Some(n) = p.old_no {
        dim(format!("{n:>w$}", w = p.digits), 1);
    }
    if let Some(n) = p.new_no {
        dim(format!("{n:>w$}", w = p.digits), p.digits + 2);
    }
    if p.sign != ' ' {
        dim(p.sign.to_string(), 2 * p.digits + 3);
    }
    let _ = line.paint(point(text_x, y), px(p.row_h), TextAlign::Left, None, window, cx);
    (line, text_x)
}

/// Text runs covering `text`: `colors` where they fall, `default` between them.
fn runs(text: &str, colors: &[(Range<usize>, Hsla)], font: &Font, default: Hsla) -> Vec<TextRun> {
    let run = |len: usize, color: Hsla| TextRun {
        len,
        font: font.clone(),
        color,
        background_color: None,
        underline: None,
        strikethrough: None,
    };
    let mut out = Vec::new();
    let mut at = 0;
    for (r, color) in colors {
        let (start, end) = (r.start.max(at), r.end.min(text.len()));
        if start >= end {
            continue;
        }
        if start > at {
            out.push(run(start - at, default));
        }
        out.push(run(end - start, *color));
        at = end;
    }
    if at < text.len() {
        out.push(run(text.len() - at, default));
    }
    out
}
```

```rust
/// text; and the changed words of a removed line paired with an added one.
#[derive(Default)]
pub(crate) struct HunkColors {
    pub lines: Vec<Vec<(Range<usize>, Hsla)>>,
    pub marks: Vec<Vec<Range<usize>>>,
}

#[derive(Default)]
pub(crate) struct Highlights {
    /// One highlighter per language: building one is a tree-sitter parser and its queries.
    by_lang: HashMap<&'static str, SyntaxHighlighter>,
    /// By (file, hunk), until the diff changes.
    hunks: HashMap<(usize, usize), Rc<HunkColors>>,
}

impl Highlights {
    /// The diff changed: every hunk is colored again on its next draw.
    pub fn clear(&mut self) {
        self.hunks.clear();
    }

    /// The colors of hunk `hunk` of file `file` (`shown`), built the first time.
    pub fn of(
        &mut self,
        file: usize,
        hunk: usize,
        shown: &Shown,
        theme: &HighlightTheme,
    ) -> Rc<HunkColors> {
        if let Some(c) = self.hunks.get(&(file, hunk)) {
            return c.clone();
        }
        let lang = lang_of(Path::new(shown.diff.path()));
        let hl = self
            .by_lang
            .entry(lang)
            .or_insert_with(|| SyntaxHighlighter::new(lang));
        let h = &shown.diff.hunks[hunk];
        let texts: Vec<String> = h.lines.iter().map(|l| display(&l.text)).collect();
        let mut colors = HunkColors {
            lines: vec![Vec::new(); h.lines.len()],
            marks: vec![Vec::new(); h.lines.len()],
        };
        // The old side is the context and removed lines; the new side the context and added
        // ones. Context lines take the new side's colors.
        for side in [Kind::Removed, Kind::Added] {
            let members: Vec<usize> = (0..h.lines.len())
                .filter(|&i| matches!(h.lines[i].kind, Kind::Context) || h.lines[i].kind == side)
                .collect();
            let fragment = members
                .iter()
                .map(|&i| texts[i].as_str())
                .collect::<Vec<_>>()
                .join("\n");
            let rope = Rope::from_str(&fragment);
            hl.update(None, &rope, None);
            let styles = hl.styles(&(0..fragment.len()), theme);
            let (mut start, mut j) = (0, 0);
            for &i in &members {
                let end = start + texts[i].len();
                let mut line = Vec::new();
                // ponytail: a style that spans lines (a long string) is seen by each line it
                // crosses; a style starting inside such a span is skipped for that line.
                while j < styles.len() && styles[j].0.start < end {
                    let (r, style) = &styles[j];
                    let (a, b) = (r.start.max(start), r.end.min(end));
                    if a < b && let Some(color) = style.color {
                        line.push((a - start..b - start, color));
                    }
                    if r.end <= end {
                        j += 1;
                    } else {
                        break;
                    }
                }
                if side == Kind::Added || h.lines[i].kind == Kind::Removed {
                    colors.lines[i] = line;
                }
                start = end + 1;
            }
        }
        for (r, a) in h.pairs() {
            let (old, new) = changed(&texts[r], &texts[a]);
            colors.marks[r] = old;
            colors.marks[a] = new;
        }
        let colors = Rc::new(colors);
        self.hunks.insert((file, hunk), colors.clone());
        colors
    }
}
```

```rust
use std::ops::Range;

use super::rows::{Row, Shown};

/// A place in the panel: a row, and a byte of its display text.
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord)]
pub(crate) struct Pos {
    pub row: usize,
    pub col: usize,
}

/// From where the mouse went down to where it is.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(crate) struct Selection {
    pub anchor: Pos,
    pub head: Pos,
}

impl Selection {
    /// The start and the end, whichever way it was dragged.
    pub fn ordered(&self) -> (Pos, Pos) {
        if self.anchor <= self.head {
            (self.anchor, self.head)
        } else {
            (self.head, self.anchor)
        }
    }

    pub fn is_empty(&self) -> bool {
        self.anchor == self.head
    }

    /// The selected bytes of row `row`, whose display text is `len` bytes; None when the
    /// row isn't in the selection. A row in the middle is selected whole, an empty one too.
    pub fn range_in(&self, row: usize, len: usize) -> Option<Range<usize>> {
        let (a, b) = self.ordered();
        if row < a.row || row > b.row {
            return None;
        }
        let start = if row == a.row { a.col.min(len) } else { 0 };
        let end = if row == b.row { b.col.min(len) } else { len };
        Some(start..end)
    }
}

/// The bytes of `text` that `display(text)[range]` came from: a tab is 4 display bytes.
pub(crate) fn to_source(text: &str, range: Range<usize>) -> Range<usize> {
    let text = text.strip_suffix('\r').unwrap_or(text);
    let map = |target: usize| -> usize {
        let mut shown = 0;
        for (i, c) in text.char_indices() {
            if shown >= target {
                return i;
            }
            shown += if c == '\t' { TAB.len() } else { c.len_utf8() };
        }
        text.len()
    };
    map(range.start)..map(range.end)
}

/// The word around byte `col` of `display` (letters, digits and '_'), else the one character
/// there, else `col..col`.
pub(crate) fn word_at(display: &str, col: usize) -> Range<usize> {
    let word = |c: char| c.is_alphanumeric() || c == '_';
    let col = col.min(display.len());
    let start = display[..col]
        .char_indices()
        .rev()
        .take_while(|(_, c)| word(*c))
        .last()
        .map_or(col, |(i, _)| i);
    let end = display[col..]
        .char_indices()
        .take_while(|(_, c)| word(*c))
        .last()
        .map_or(col, |(i, c)| col + i + c.len_utf8());
    if start < end {
        start..end
    } else {
        let next = display[col..].chars().next().map_or(0, char::len_utf8);
        col..col + next
    }
}

/// The selected text: the line rows in the selection, their source text, joined with '\n'.
pub(crate) fn selected_text(rows: &[Row], files: &[Shown], sel: &Selection) -> String {
    let (a, b) = sel.ordered();
    let mut out: Vec<String> = Vec::new();
    for (ix, row) in rows.iter().enumerate().take(b.row + 1).skip(a.row) {
        let Row::Line { file, hunk, line } = row else {
            continue;
        };
        let text = &files[*file].diff.hunks[*hunk].lines[*line].text;
        let shown = display(text);
        let Some(r) = sel.range_in(ix, shown.len()) else {
            continue;
        };
        let r = to_source(text, r);
        out.push(text.strip_suffix('\r').unwrap_or(text)[r].to_string());
    }
    out.join("\n")
}
```

```rust
    /// The mouse went down on a line row: one click starts a selection there, two select the
    /// word, three the line.
    pub(crate) fn diff_press(
        &mut self,
        id: BlockId,
        row: usize,
        x: gpui_kit::Pixels,
        clicks: usize,
        cx: &mut Context<Self>,
    ) {
        use crate::git_block::diff_view::select::{Pos, Selection, word_at};
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        let p = &mut git.panel;
        let Some(col) = p.col_at(row, x) else {
            return;
        };
        let text = p.display_of(row).unwrap_or_default();
        let (a, b) = match clicks {
            2 => {
                let r = word_at(&text, col);
                (r.start, r.end)
            }
            n if n >= 3 => (0, text.len()),
            _ => (col, col),
        };
        p.selection = Some(Selection {
            anchor: Pos { row, col: a },
            head: Pos { row, col: b },
        });
        p.dragging = clicks == 1;
        cx.notify();
    }

    /// The mouse moved over a line row with the button down: the selection's head follows.
    pub(crate) fn diff_drag(
        &mut self,
        id: BlockId,
        row: usize,
        x: gpui_kit::Pixels,
        cx: &mut Context<Self>,
    ) {
        use crate::git_block::diff_view::select::Pos;
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        let p = &mut git.panel;
        if !p.dragging {
            return;
        }
        let (Some(col), Some(sel)) = (p.col_at(row, x), p.selection.as_mut()) else {
            return;
        };
        sel.head = Pos { row, col };

    pub(crate) fn diff_release(&mut self, id: BlockId, cx: &mut Context<Self>) {
        let Some(git) = self.space.git_mut(id) else {
            return;
        };
        git.panel.dragging = false;
        if git.panel.selection.is_some_and(|s| s.is_empty()) {
```

```rust
/// The rows are whole pixels at every zoom step, 1.5 × the text: the panel scales like a photo,
/// as an editor's rows do.
#[gpui_kit::test]
fn the_rows_are_whole_pixels_at_every_zoom(cx: &mut TestAppContext) {
    use templum_canvas::{Camera, ZOOM_STEPS};
    let repo = committed_repo();
    std::fs::write(repo.path().join("a.txt"), "zero\none\n").unwrap();
    let (handle, ws) = open(cx);
    let id = open_git(handle, &ws, cx, repo.path());
    let row = line_row(&ws, cx, id, "zero");
    let rect = ws.read_with(cx, |ws, _| ws.space.canvas.get(id).unwrap().rect);
    for zoom in ZOOM_STEPS {
        let height = cx
            .update_window(handle, |_, window, cx| {
                ws.update(cx, |ws, _| {
                    // The block's corner near the view's: on screen at any zoom.
                    ws.space.canvas.camera = Camera::at(Point::new(rect.x - 10.0, rect.y - 10.0), zoom);
                    ws.space.flight = None;
                });
                window.render_frame(cx);
                f32::from(window.find(("git-line", row)).bounds().size.height)
            })
            .unwrap();
        let want = crate::git_block::diff_view::row_height(zoom);
        assert_eq!(height, want, "at {zoom}");
        assert_eq!(want, want.round(), "whole pixels at {zoom}");
    }
}
```

```rust
/// `--bench-git`: see the module's doc.
pub(crate) fn run_git(window: AnyWindowHandle, ws: Entity<Workspace>, cx: &mut App) {
    let repo = match bench_repo() {
        Ok(repo) => repo,
        Err(e) => {
            eprintln!("templum: --bench-git: {e}");
            cx.quit();
            return;
        }
    };
    let _ = cx.update_window(window, |_, window, cx| {
        ws.update(cx, |ws, cx| {
            let startup: Vec<_> = ws.space.canvas.blocks().iter().map(|b| b.id).collect();
            for id in startup {
                ws.close(id, window, cx);
            }
            ws.add_git_at(&repo, Point::new(0.0, 0.0), window, cx);
        })
    });
    cx.spawn(async move |cx| {
        // Let the block find the repository and read its diff.
        cx.background_executor().timer(Duration::from_secs(3)).await;
        let idle_rss = rss_mb();
        let _ = cx.update_window(window, |_, window, cx| {
            ws.update(cx, |ws, cx| {
                ws.space.pristine = false;
                let id = ws.space.canvas.top().expect("the Git block");
                let rect = ws.space.canvas.get(id).expect("the block").rect;
                let vp = ws.viewport(window);
                ws.space.canvas.camera = Camera::at(
                    Point::new(
                        rect.x + rect.w / 2.0 - vp.w / 2.0,
                        rect.y + rect.h / 2.0 - vp.h / 2.0,
                    ),
                    1.0,
                );
                ws.space.flight = None;
                let step_of = |z: f32| ZOOM_STEPS.iter().position(|&s| s == z).expect("a step");
                let (low, high) = (step_of(0.5), step_of(2.0));
                measure(ws, idle_rss, move |ws, window, cx, t| {
                    // The panel scrolls 400 rows a second, wrapping around.
                    if let Some(git) = ws.space.git(id) {
                        let rows = git.panel.rows.len().max(1);
                        git.panel.scroll.scroll_to_item(
                            (t * 400.0) as usize % rows,
                            gpui_kit::ScrollStrategy::Top,
                        );
                    }
                    // The zoom glides between 50% and 200%, 4 steps a second.
                    let span = high - low;
                    let k = (t / 0.25) as usize % (2 * span);
                    let target = low + if k <= span { k } else { 2 * span - k };
                    let step = target as i32 - ws.space.canvas.camera.zoom_index() as i32;
                    if step != 0 {
                        let pivot = ws.center(window);
                        ws.zoom_to(step, pivot, cx);
                    }
                });
                cx.notify();
            })
        });
    })
    .detach();
}

/// A repository in the temp folder: 5 files of 2,000 lines committed, then every 4th line of
/// each changed (500 removed and 500 added per file: a 5,000-line diff with context).
fn bench_repo() -> Result<PathBuf, String> {
    let dir = std::env::temp_dir().join("templum-bench-git");
    let _ = std::fs::remove_dir_all(&dir);
    std::fs::create_dir_all(dir.join("src")).map_err(|e| e.to_string())?;
    let repo = templum_git::Repo::init("git", &dir).map_err(|e| e.to_string())?;
    for args in [
        ["config", "user.name", "Bench"].as_slice(),
        &["config", "user.email", "bench@example.com"],
        &["config", "commit.gpgsign", "false"],
    ] {
        repo.run(args).map_err(|e| e.to_string())?;
    }
    let names: Vec<String> = (0..5).map(|i| format!("src/file{i}.rs")).collect();
    let text = |changed: bool| -> String {
        (0..2000)
            .map(|i| {
                let value = if changed && i % 4 == 0 { i + 1 } else { i };
                format!("fn line_{i}() -> u32 {{ {value} }}\n")
            })
            .collect()
    };
    for name in &names {
        std::fs::write(dir.join(name), text(false)).map_err(|e| e.to_string())?;
    }
    let paths: Vec<&str> = names.iter().map(String::as_str).collect();
    repo.stage(&paths).map_err(|e| e.to_string())?;
    repo.commit("bench", false).map_err(|e| e.to_string())?;
    for name in &names {
        std::fs::write(dir.join(name), text(true)).map_err(|e| e.to_string())?;
    }
    Ok(dir)
}
```
